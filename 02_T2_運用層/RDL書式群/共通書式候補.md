# 共通書式候補
*T2：運用層（メタ／書式レイヤー） / OP / ACTIVE v0.1*
*依存：版記録書式 / SILN分解記述書式 / siln分解の数理フレームワーク / SILN_解説・SILN_動態 / T0_構造 [GATE]*

---

## ■ 0. この文書の位置

RDLの各書式文書から、特定の書式に固有でない**汎用の芯**が染み出してきている。版記録書式のカード記法、SILN分解記述書式のステータス記法（U/ST/DT）などである。

本書式は、それらを**抜き出し候補として集めて観察する台帳**である。

重要なのは、これが「確定した共通フォーマット集」ではないこと。ここに並ぶのは、複数の書式で使えそうに**見えている**候補であって、その多くは実適用先がまだ一つしかない。一例から基本形を立てて独立書式化するのは早すぎる確定化（U-SILNを一個見てST化するのと同じ）。だから本書式の性格は、確定集ではなく——

> **抜き出し候補が、いまどの検査段にあるかを記録する観察ノート**

である。各候補の検査段は、SILN分解記述書式 ■2.5 のステータス記法（U/ST/DT）をそのまま自己適用して示す。候補が複数の適用先で実際に使われ、項の過不足が見えてから、初めて独立書式へ抜き出す。

本書式は書式レイヤーの**二号**である（一号＝版記録書式）。一号が具体的な書式なのに対し、本号はメタ目録（書式群を見渡す係）にあたる。

## ■ 1. 候補一覧

各候補に、適用先・現状の検査段・汎用度の観察・抜き出し条件を添える。すべて暫定である。

### 候補① カード記法

```
記法    : Δv / B / M_B / ξ / H↓ / guard の一行カード
適用先  : 版記録書式（Δv＝文書改訂）── 実例1
検査段  : U（横断の床として運用中。複数適用での検証＝破壊検査はまだ）
汎用度  : 高い。一つの思考ステップ（設計判断・議論の一手・実験の一回）なら
          何にでも乗る。SILN語彙への依存は B・M_B・ξ の三項のみで、
          残り（Δv・H↓・guard）は語彙非依存。
抜き出し条件 : 版記録以外の適用先が一つ出て、項の過不足が確認できたら、
              独立の「カード書式」へ抜き出し、版記録書式をその一適用例に。
```

### 候補② ステータス記法（U/ST/DT）

```
記法    : U（把持・運用中）/ ST（外部が強固とする未検査）/ DT（破壊検査済）
          ＋裸印禁止＋測定条件添付（いつ・どのBで・どこまで）
適用先  : SILN分解記述書式（分解の確からしさ段）── 実例1
検査段  : U（SILN分解で運用中。他対象での検証はまだ）
汎用度  : 高い。「分解」に固有ではなく、確からしさを問えるもの
          （主張・設計・コード・モデル・命題）なら何にでも添えられる。
          検査段ラベルであって、SILN語彙には依存しない。
抜き出し条件 : SILN分解以外で確からしさ段を付ける適用先が出たら、
              独立の「ステータス記法」へ抜き出す。
注      : 本書式自身が候補①②③の検査段表示にこの記法を自己適用している
          （＝二例目の萌芽だが、台帳内利用は適用先一つと数えるか保留）。
```

### 候補③ 5スロット

```
記法    : ラベル / B / M_B / ξ / 破綻地点
適用先  : SILN分解記述書式（対象を分解して書く基本形）── 実例1
検査段  : U
汎用度  : 低め。M_B・ξ という SILN 語彙への依存が深く、①②ほど
          語彙非依存ではない。「対象を項目分解する」汎用形と見ることも
          できるが、その読みは薄く広がりやすい（何でも汎用に化ける）。
抜き出し条件 : 保留度高め。SILN語彙を使わない対象でこの5項が機能する例が
              出てから検討。現時点では SILN固有寄りの候補として観察に留める。
```

## ■ 2. 共通前提（候補ではなく底）

抜き出し候補とは別に、**全書式が踏む下限**がある。これは特定書式から染み出したものではなく、RDL全体の底（T0由来）なので、抜き出し対象ではない。

```
[GATE]＝確定化したら対象外
  : どの書式で何を書こうと、「○○が実在する／真の姿は○○だ／ξ=0」と畳み、
    引き直しを拒んだものは [GATE] の外＝対象外。
  : これは候補①②③すべてに共通の前提であって、候補の一つではない。
    毎回判定する関門ではなく、確定化へ滑ったときだけ効く道標（版記録書式・
    SILN分解記述書式 ■0.5 と同じ扱い）。
```

---

## ■ 3. 抜き出しの作法

候補を独立書式へ抜き出すのは、**二例目以降が出て項の過不足が見えてから**である。一例からの抽出は早すぎる確定化として禁じる。

```
観察中（U）     : 適用先一つ。台帳で候補として運用。
抜き出し可（ST→）: 適用先が複数出て、項が安定。独立書式化を検討。
抜き出し済（DT） : 独立書式として立て、複数適用で破壊検査済。
```

抜き出したら、その候補は本台帳から「抜き出し済」として独立文書へ移り、台帳には参照だけ残す。本台帳は候補が出入りする動的な目録であって、固定された共通フォーマット集ではない。

---

## ■ 4. 超圧縮

> **汎用に見える書式の芯（カード記法・ステータス記法・5スロット）を、確定集ではなく候補の観察ノートとして集める。**  
> **各候補の検査段は U/ST/DT を自己適用して記録し、二例目が出て項が安定してから独立書式へ抜き出す。一例からの抽出はしない。**
