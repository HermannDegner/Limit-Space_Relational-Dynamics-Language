# SILN分解記述書式
*T2：運用層 / OP / ACTIVE v0.12*
*依存：siln分解の数理フレームワーク / siln係数抽出手順 / SILN_解説 / SILN_動態 / 仮設という操作 / 構造破壊学_前提文書（■0.5）/ T0_構造 [GATE]・限界空間的構造破壊ゲート解説（■0.5下限）*

---

## ■ 0. この文書の位置

RDLには、SILN分解の**手順**を定める文書が二つある。

```
siln分解の数理フレームワーク : 何をするか（②B仮定→③状態展開→④構造仮設→⑤動性追跡→⑥引き直し）
siln係数抽出手順             : どう詰めるか（Step 0〜12：ネットワーク描画〜係数群定義）
```

しかし、その分解結果を**どう書き下すか**——成果物の体裁——は、どちらも定めていない。

この空席が、繰り返し同じ事故を生む。

> **「連続 ＝ 感覚SILN」**  
> **「知性 ＝ SILN」**  
> **「貨幣 ＝ SILN」**

このような**等号貼り**は、SILN分解ではない。SILN_解説 ■2 が戒めるとおり、なんでもSILNと呼べる以上、呼ぶだけでは何も言っていない（貼るだけは空虚）。手順を踏んでいても、書き下しが等号一行なら、読者には「分解したのか／貼っただけか」が区別できない。

本書式は、その区別を**書き下しの体裁レベルで強制する**ための規約である。手順そのものは数理フレームワーク・係数抽出手順に従う。本書式が定めるのは出力の形だけである。

## ■ 0.5 この書式の射程：軽い側（仮止め）

本書式は**軽い側**である。すなわち、思考の自由度を保ったまま複数領域を粗いBで一旦束ねて場を回す、**思考横断の仮止め**としてのSILNの使い方を支える。構造を仮設して先へ進むための書式であり、その構造を実際に壊しにはいかない。

ここで構造破壊学 5節の分業が効く。

```
SILN分解（軽い側・本書式）   : 構造を仮設する操作。
                              [破綻地点] は「どこで壊れそうか」を一行マークするだけ。
構造破壊学（重い側・別書式）  : 仮設された構造に作用を当て、誤差が許容域を超える
                              実用境界を実測する。破断・残存・移植まで追う。
```

この差は対象SILNの硬度に対応する。

```
低硬度・仮止めSILN  : ξが粒度の浅いところにある。
                     軽い書式の5スロット（特に[破綻地点]の一行マーク）で足りる。
強固SILN（高硬度）  : ξが粒度の下に深く潜っている（SILN_解説 ■3）。
                     浅い記述では破断点に届かない。作用を当てて壊し、
                     V_B/Λ_B・スケール差・破綻条件（係数抽出 Step 4〜8）まで
                     降りる重い書式が要る。これは構造破壊学の領分。
```

したがって、本書式で強固SILNを扱おうとして [破綻地点] が一行で埋まらない・[ξ] が深くて書けないと感じたら、それは書式を間違えたサインである。軽い書式の役目は「ここは強固だ、破壊検査が要る」と**マークして次へ渡す**ことであって、その場で割ることではない。

重い側の記述書式は本書式の射程外であり、別途・構造破壊学側で定める（数理モデルに従属しない前提文書本体ではなく、係数抽出 Step群を破壊検査用に束ねる実務書式として）。本書式はその接続点だけを残す。

### ● 上限と下限

■0.5 はここまで**上限**——強固すぎるSILNは重い書式へ渡す——を引いた。対になる**下限**が [GATE] である。ただし [GATE] は毎回判定する関門ではなく、確定化へ滑ったときだけ効く道標である。

RDLで扱えている時点で、それは引き直しうる仮設として保持されている。したがって通常は [GATE] 通過済みと見てよい。問題になるのは、「○○が実在する／真の姿は○○だ／ξ=0」と畳み、[ξ] を埋める気がなくなったときだけである（[ξ] が書けない理由のうち、Bが粗いだけなら具体化で回復するが、確定化はそもそも対象外）。

したがって本書式の射程は、上を強固SILN（重い書式へ）、下を確定化（[GATE]の外）で挟まれた帯である。

## ■ 1. 禁止：等号貼り

```
禁止 ：ラベル ＝ SILN
禁止 ：ラベル ＝ ○○SILN
禁止 ：ラベル ＝ M_B
```

「○○はSILNである」「○○はSILNとして扱える」と**断定して止める**書き方を禁じる。

理由は、等号がSILN_動態 性質4（分解しないと意味を持たない）に正面から反するからである。等号は中身ゼロのまま記述を閉じてしまう。閉じた瞬間、引き直しの余地（[HYP]・追従運用）も消える。

許されるのは、断定ではなく**操作提案**としての書き方である。

```
可 ：ラベルは、○○というBのもとで △△というM_Bとして分解できる
可 ：ラベルを ○○SILNとして分解すると、以下が出る（→ スロット）
```

「である」ではなく「分解できる／分解すると出る」。等号ではなく、中身の展開を伴う矢印。

## ■ 2. 必須スロット

ある対象をSILN分解として記述するなら、以下の**5スロットがすべて埋まって初めて一項**として認める。一つでも空なら、それは分解ではなく貼り付けである。

```
[ラベル]    : 何を分解しているか（対象定義）
[B]         : どの境界・スケール・評価関数を引いたか（観測者のBを含む）
[M_B]       : そのBのもとで仮設した整合慣性（中身）
[ξ]         : そのBが粒度の下に沈めた／こぼした残り
[破綻地点]  : このM_Bがどの負荷で支えきれなくなるか
```

各スロットの要件：

- **[ラベル]** ── 分解対象。ラベル自体がSILN（ラベル運用の整合慣性）であることに注意（係数抽出 Step 1）。
- **[B]** ── 最重要スロット。空間／時間スケール、評価関数、用途を明示する。そして**そのBを引いたのは誰か**を書く。観測者自身もM_Bであり、純粋に外側からBを引く観測者は存在しない（数理フレームワーク ②補足）。「生存有利」「自然」などを世界側の客観属性のように書いたら、それはBの記入漏れである。
- **[M_B]** ── 「抽出した」ではなく「仮設した」と書く。直接観測できず、行動・出力・反応のパターンからの推定にすぎない（数理フレームワーク 概要）。可能なら V_B（安定方向）・Λ_B（強度）まで。
- **[ξ]** ── このスロットが、等号貼りと分解を分ける決め手。B を引いて何を捨てた／粒度以下に沈めたかを書く。ξ が書けないなら、まだ B を具体的に引けていない。
- **[破綻地点]** ── M_B が安定して見えるのは ξ が粒度以下に潜っているからにすぎない（SILN_解説 ■3）。どの負荷・どのスケール逸脱でその潜りが浮上するか（SILN_解説 ■4／跳躍条件 H>θ+ξ への接近）。

### 任意スロット

静的スナップショット一枚なら5枠で足りる。動態まで回すなら以下を足す。

```
[EFP/F]     : 素流圧と作用解釈（F=interp(M_B,EFP)。EFPは逆算物・直接観測不能）
[E/H]       : 慣性誤差と熱（追従運用で動性を追うとき）
[相状態]    : M_act / M_lat / M_Δ / M_B'（再編を追うとき）
[引き直し]  : どのトリガーで①〜④を再実行するか（部分更新で可）
```

任意スロットは「書けるなら書く」。書けないこと自体が情報になる（例：Fは持てるがEFPは逆算しかできない、という非対称の明示）。

## ■ 2.5 分解ステータス

5スロットが埋まっても、その分解が**まだ未検査の仮設か／破壊チェックを通った耐久確認済みか**は、それだけでは区別できない。同じ充足でも、[破綻地点] を一行マークしただけのもの（■0.5 の軽い側）と、実際に作用を当てて実用境界を実測したもの（重い側・構造破壊学）が、見た目で同じになってしまう。

そこで、分解には**ステータス略号**を添える。略号は三つ（U / ST / DT）。

```
U-SILN  (Undecomposed)        : 明示分解前SILN。5スロットにはまだ書き出していないが、
                               直感的にはB・M_B・ξらしきものを把持しており、
                               思考横断の仮止めとして運用中のもの。
                               （把持すらない手つかず・等号貼りはUではなく対象未満・■1）
ST-SILN (Stable-Tagged)        : RDLとしては未検査だが、外部（現在の科学・確立した
                               理論体系）が強固として扱っているSILN。
                               例：標準模型、熱力学第二法則、確立した理論体系。
DT-SILN (Destruction-Tested)   : RDLが作用を当て、有効範囲・破断条件・残存構造を
                               測ったSILN（構造破壊学 7節）。現時点では自己検査を指す。
```

※ DT は検査主体で補記できる：自分なら DT-self、外部の独立破壊検査機関なら DT-ext。ただし DT-ext に該当する機関は現時点で存在しないため、いまの DT は実質すべて DT-self（自己検査）である。DT-ext は将来のための仮想スロットとして名前だけ確保しておく。

### ● U と宣言することの意味

U と宣言できる時点で、対象はすでに仮止めの床として踏まれている。つまり、B・M_Bらしき安定・ξの気配を暗黙に把持している。まだ5スロットに書き出していないだけで、完全な手つかずではない。

ただし、把持は明示分解ではない。5スロットへ書き出すと、Bの曖昧さやξの言えなさが露呈することがある。U→明示分解の価値は、その暗黙の穴を表に出す点にある。

等号貼りは把持を放棄して記号で閉じるが、U は把持したまま仮設として保持する。だから U ≠ 等号貼り（■1）。

U と ST はどちらも RDL の破壊検査前だが、**安定タグの貼り主**が違う（U は把持の床、ST は外部で精緻に分解されていることもある）。

```
U  : RDL自身が把持して粗く置いた仮タグ。軽い・すぐ剥がせる・自分で貼った・運用中。
ST : 外部（科学共同体）が強固と貼ったタグ。重い・剥がしにくい・他者が貼った。
```

### ● ST の扱い

ST は外部タグを仮設として扱うための名であり、「科学が認めたのだから確定」と畳むことを防ぐ。ST として扱う限り [GATE] 内だが、ST を確定化すれば [GATE] の外へ出る（■0.5）。

ST は終着点ではない。外部タグが付くぶん分解の動機が削がれるリスク（構造破壊学 2節の内側の前提化リスク）が U より強く、重要判断の土台にするなら DT へ回して有効範囲を測るのが筋である。

### ● 進行

```
U-SILN ──（5スロットで明示分解＋RDL破壊検査）──→ DT-self
ST-SILN ─（RDLが作用を当て破壊検査）──────────→ DT-self
        （外部タグSTは外れない。RDL側の検査深度が上がり、ST かつ DT-self 併記もありうる）
U-SILN でとどめるのも正規（軽い横断はこのまま。■0.5 の射程選択）
```

ST から DT へ進んでも、外部の安定タグ（科学が強固としている事実）が消えるわけではない。RDL が独自に破壊検査を通したという深度が加わるだけで、`ST かつ DT-self`（外部も強固とし、RDLでも有効範囲が見えた）という併記が自然に起こる。

### ● 強度は単調ではない

これらは一直線の強さ順ではない。評価軸が二つ——外部の安定評価（ST）か、RDLの破壊検査（DT-self）か——あるためで、STとDT-selfのどちらが「強い」かは目的でどちらの軸を重く見るかで変わる。両軸を満たすのは外部機関による破壊検査（DT-ext）だけだが、それは不在の仮想スロットである。だから `ST かつ DT-self`（外部権威＋自己検査）を最上位と取り違えないこと——それは外部の破壊検査ではない。

### ● DT の裸の印を禁じる

DT-SILN（self / ext いずれも）は確定の印ではない。裸の「✓」「済」で書くことを禁じる。

```
禁止 ：DT-SILN ✓
禁止 ：このSILNは耐久確認済み
```

DT は**そのBのもとで、その負荷範囲まで耐久を測った**という意味であって、ξが消えた・正しい・確定した、ではない。裸の印は「検査済＝確定」という読みを呼び、確定化（[GATE]の外）に化ける。したがって DT には、必ず**いつ・どのBで・どこまで測ったか**を添える。

```
可 ：[DT-self / B=○○スケール / 負荷△△まで / 実用境界=□□で破断 / 測定t=…]
```

DT-ext には警告を二重に効かせる。外部の破壊検査機関を通っても、それはその機関のBで・その負荷まで測っただけであり、ξは残り追従運用で古くなる。外部権威がつくぶん「機関が認めたのだから確定」という確定化の誘惑は ST 同様に強い。DT-ext も「外部検査は確定を意味しない」（ST の警告と同型）を必ず併記する。

測定条件が動性で古くなれば（B劣化・観測者のM_B変化・スケール逸脱）、DT は U（または ST）へ**戻す**。DT は一度きりの到達点ではなく、追従運用の中で更新される断面である（係数抽出 Step 10／数理フレームワーク ⑥引き直し）。

### ● 仮止めは劣位ではない

U-SILN は「未完成な DT」ではない。すべてを DT へ上げる必要はなく、**強固で、かつ破断点を知る必要が生じたものだけ**を破壊検査へ回す。U のまま置くのは正規の運用であって、手抜きではない（横断の仮止めとしての役割は ■0.5）。

## ■ 3. 形は問わない

5スロットさえ埋まれば、**散文でも表でも箇条書きでもよい**。本書式が縛るのは「何が埋まっているか」であって「どう並べるか」ではない。

```
散文型   : 流れの中でラベル・B・M_B・ξ・破綻地点が順に展開される
          （例：連続と離散.md §10 の連続感の扱い）
表型     : スロットを列にした対応表
          （例：係数抽出 Step 9 のネットワーク比較配置）
カード型 : 1ラベル＝1ブロックでスロットを縦に並べる
```

散文型でも、読み返して5スロットが拾えるかを自己チェックする。拾えないスロットがあれば、そこが記入漏れである。

## ■ 4. 自己チェック（記述後に通す）

```
□ 確定化へ畳んでいないか（「科学的真理だから確か」「実在する」等。扱えている限り[GATE]は自動通過済み・■0.5）
□ 等号で断定して止めていないか（■1）
□ [B] に観測者自身のBが入っているか（世界側の客観属性に化けていないか）
□ [ξ] が具体的に書けているか（書けないならBがまだ粗い／曖昧）
□ [破綻地点] が「安定して見える理由」とセットで書けているか
□ M_B を「抽出した」ではなく「仮設した」と書いたか
□ この記述自体が固定化していないか（追跡装置にもκ＝自己修正可能性が要る）
□ ステータス略号（U / ST / DT）を添えたか。DT-SILNを裸の印で書いていないか（■2.5）
```

最後の項が効く。本書式に従って書いた分解も、それ自体がSILN（記述運用の整合慣性）であり、揺れる。書式を「正解の型」として静止運用すると、係数抽出 Step の規範化リスク（辞書を正解の記録として運用する転落）と同じ轍を踏む。書式もまた追従運用される近似である。

## ■ 5. 適用例の参照

本書式を満たす実例として、連続と離散.md §10 の連続感の扱いがある。そこでは——

```
[ステータス] : U-SILN（仮止め運用。破綻地点は予想の一行マーク）
[ラベル]   : 連続感
[B]        : 知覚の担体（受容体・スパイク・更新粒度）＋生存フレーム（分析者が引いた）
[M_B]      : 離散入力・補間・予測が滑らかに現れている感覚M_B（粗いBで細部をξに沈めた安定相。未明示分解）
[ξ]        : 生存に無関係な細かい離散構造（個々のスパイク・フレーム境界・受容体の粒）
[破綻地点] : 仮現運動・フリッカー融合・知覚的充填（粗いBが負荷で支えきれない点）
```

——が散文の流れの中で展開されており、等号貼り（「連続感＝感覚SILN」）ではなく「感覚SILNとして分解できる」という操作提案にとどめている点が、本書式の ■1・■2 に合致している。

ステータスは U-SILN（宣言した時点で明示分解前・把持済み・仮止め運用中の意）である。[破綻地点] は「仮現運動などで壊れそう」という**予想の一行マーク**であって、どの刺激条件・どの提示速度で連続知覚が実際に破断するかを実測したわけではない（■2.5）。これを DT-self へ上げるには、心理物理の作用を当てて実用境界を測る——たとえば「フレーム間隔が何 ms を超えると仮現運動が連続知覚へ統合されなくなるか」を実測し、[破綻地点] を予想から実測値へ書き換える——という重い側の操作が要る。連続と離散.md §10 の目的（連続/離散の哲学的整理）には U で足りるため、上げていない。これは手抜きではなく射程選択である（■2.5 末尾）。

## ■ 6. 超圧縮

> **SILN分解の記述は、等号で貼らず、ラベル・B・M_B・ξ・破綻地点の5スロットを埋めて初めて一項になる。**  
> **形は問わない。空いたスロットが、貼り付けと分解を分ける。**  
> **そして U（明示分解前・把持済み・仮止め運用中）/ ST（外部が強固とする未検査）/ DT（破壊検査済。現時点では自己検査。外部機関による DT-ext は仮想スロット）のどれかをステータスとして示す。DTは裸の印で書かず、いつ・どのBで・どこまで測ったかを添える（添えなければ確定化に化ける）。**
