# 版記録書式
*T2：運用層（メタ／書式レイヤー） / OP / ACTIVE v0.3*
*依存：SILN分解記述書式 / siln分解の数理フレームワーク / SILN_解説・SILN_動態 / T0_構造 [GATE]*

---

## ■ 0. この文書の位置

RDL文書は改訂を重ねる。その履歴を残すのが版記録である。

従来の版記録は散文だった——「v0.7：○○を△△へ修正。理由は…」。これは書けるが、版が増えると読み返しに負荷がかかり、各版が「何を防ぐために動いたのか」を横断して追いにくい。

本書式は、版記録を**SILN分解の語彙で書く**ための共通規約である。これは飾りではない。版が動くという出来事それ自体が、SILN分解だからである（■1）。

本書式は**書式レイヤーの一号**である。RDLには書式を扱う文書が育ちつつあり（SILN分解記述書式など）、それらが揃った段階で共通フォーマットへ統合しうる。本書式はその束の最初の住人であって、いま全体を確定するものではない。

---

## ■ 1. なぜ版記録はSILN分解なのか

文書のある版は、その時点での記述構造＝M_Bである。版が動くのは、

```
旧M_B（前の版の記述構造）が、運用の中で負荷を受けて揺れる
  ↓
どこかでBを引き直す（語を変える・節を割る・射程を切り直す）
  ↓
新M_B（次の版の記述構造）へ再編する
  ↓
その際、何かをξ（残存・誤読・未処理）として残し、
何かのH（読解負荷・矛盾熱）を下げ、何かの確定化をguardする
```

という運動である。これはSILN分解そのもの（数理フレームワーク ②B→③状態展開→⑥引き直し）であり、対象が「外界のSILN」ではなく「文書自身の記述構造」になっただけである。

したがって版記録は、SILN分解の5スロットに対応する項で書ける。これは比喩ではなく構造的対応である。

---

## ■ 2. 記法

各版を一行カードで書く。先頭に凡例を置く。

```text
Δv     : 版更新（何をした版か、短く）
B      : どの境界を引き直したか
M_B    : どの記述構造へ再編したか
ξ      : 何を残存・誤読・未処理として扱ったか
H↓     : 何の読解負荷・矛盾熱を下げたか
guard  : 何の確定化・誤用を防いだか
```

書き方：

```text
v0.7 `Δv: ○○ / B=… / M_B=… / ξ=… / H↓=… / guard=…`
```

- 新しい版を上、古い版を下に積む（最新が先頭）。
- 一つの版で独立した判断が二つあれば、同じ版番号で二行に分ける（例：`v0.7 Δv:A…` と `v0.7 Δv:B…`）。
- 各項は短く。詳細が要るなら本文側の該当節に書き、版記録は索引に徹する。

---

## ■ 3. 各項の要点

- **Δv** ── その版の見出し。「簡素化」「○○再定義」「△△新設」など、後から探せる語にする。
- **B** ── 改訂の起点。前の版の何を境界として引き直したか。「分解有無→破壊検査有無」のように、どこを動かしたかを差分で書く。
- **M_B** ── 再編後の到達点。新しい定義・新しい節・新しい区別。
- **ξ** ── この版が**残したもの**。直しきれなかった残存、起こりうる誤読、保留した未処理。ξを空にしないこと——「完璧に直した」と書く版は、版記録自身の確定化である（■4）。
- **H↓** ── この版が下げた負荷。読みにくさ、概念衝突、矛盾熱のうち何が軽くなったか。
- **guard** ── この版が立てた歯止め。どの確定化・誤用・誤読を防ぐ改訂だったか。guard列を縦に読むと、その文書が「何を防ぐために育ってきたか」が一望できる。

---

## ■ 4. 書式自身へのguard

本書式を「全RDL文書で必須の唯一の型」として固めないこと。それは確定化（この型でなければ版記録と認めない＝引き直し拒否）であり、[GATE] の外へ出る。

```
推奨 ：RDLのSILN語彙文書の版記録は、この記法で書くと横断しやすい。
過剰 ：この記法でない版記録は無効だ／全文書を今すぐこの型に揃えよ。
```

したがって：

- 項は**足し引きしてよい**。動態を多く扱う文書なら E/H や相状態の項を足す、軽い文書なら ξ・guard だけ、など文書ごとに調整する。
- 射程は**RDLのSILN語彙で回る文書**である。SILN・B・ξ を使わない文書に無理に適用すると項が浮く。そういう文書は素の散文版記録でよい。
- 本書式もまた追従運用される近似であり、書式レイヤーに二号・三号が揃えば、共通フォーマットへ再編されうる（そのとき本書式は旧M_Bとして引き直される）。

なお、このカード記法自体が版記録専用ではない——思考ステップ一般に乗る汎用形であり、版記録はその一適用先（Δv＝文書改訂）にすぎない。抜き出し候補としての観察は 共通書式候補 ①に集約してある（一例からの抽出は早すぎる確定化として保留）。

---

## ■ 5. 準拠例

SILN分解記述書式 の ■7 版記録が、本書式の最初の準拠例である。凡例ブロック＋一行カード（v0.11→v0.1、独立判断は同版二行）で書かれており、guard列を縦に読むとその文書が確定化・裸印・手つかず誤読・制度論逸脱などを順に防いできた跡が追える。

---

## ■ 6. 超圧縮

> **版が動くのは、旧M_Bが揺れてBを引き直し新M_Bへ再編する運動であり、SILN分解そのものである。**  
> **だから版記録は Δv / B / M_B / ξ / H↓ / guard で書ける。ξを空にせず、この型自体を必須化しない。**  
> **このカード記法は版記録専用ではなく、思考ステップ一般に乗る汎用形（抜き出し候補）。版記録はその一適用先である。**

```text
ξ      : 何を残存・誤読・未処理として扱ったか
H↓     : 何の読解負荷・矛盾熱を下げたか
guard  : 何の確定化・誤用を防いだか
```
