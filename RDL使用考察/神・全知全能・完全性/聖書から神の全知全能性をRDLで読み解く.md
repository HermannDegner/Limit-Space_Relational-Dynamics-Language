# 聖書から神の全知全能性をRDLで読み解く

*RDL使用考察 / META / DRAFT v0.3*  
*依存：RDL_Core*  
*シリーズ：神・全知全能・完全性 / 第I部：観測編*

---

## シリーズ上の位置

本稿は、シリーズ「神・全知全能・完全性」の**第I部：観測編**である。

ここではまず、聖書本文を観測記録として固定し、そこから神の能力についてどこまでを硬く仮設できるかを検査する。全知・全能という属性の論理的定義そのものを最終確定することは本稿の役割ではない。本文から残った能力境界の ξ は、第II部で「全知全能」という概念自体の破壊検査へ送る。

---

## ■ 0. 問い

キリスト教圏では、神はしばしば「全知全能」と表現される。

では、この「全知全能」は、聖書本文からそのまま得られる性質なのだろうか。

それとも、

- 非常に広い知識
- 非常に高い作用能力
- 未来に関する高い予測・実現能力
- 人間には理解困難な現象

といった複数の記述を束ね、その境界を拡張することで成立した高次ラベルなのだろうか。

本稿では、神が実在するか否かを先に決めない。

また、「全知全能である」「全知全能ではない」のいずれも入力条件に置かない。

関係力学言語は、本物・作り物、真・偽を入口で決定せず、観測後の硬度として扱う。観測者が持てるのは世界そのものではなく、自身に現れた作用 \(F\) である。

したがって本稿の問いは、

> **聖書という観測記録から、神の能力についてどこまでを硬く仮設でき、どこから先に ξ が残るのか**

である。

```text
B_Bible :=
  「聖書本文に現れる神の能力記述から、
    全知・全能という能力境界を逆算する」

{ 全知, 全能 } ∉ 入力
{ 全知らしさ, 全能らしさ, 能力境界 } ∈ 出力
```

## ■ 1. まず四つの層を分離する

「聖書では神は全知全能だ」と言うとき、実際には異なる種類の情報が混ざっている。

少なくとも次の四層は分離した方がよい。

### L0：行動・現象

神が何をしたと物語られているか。

### L1：神自身の自己申告

神が自分の能力について何を語ったか。

### L2：他者による神の評価

預言者、詩人、使徒、物語の語り手などが、神について何を述べているか。

### L3：後世の神学的統合

複数の記述を束ね、

- omniscience
- omnipotence
- omnipresence

などの抽象属性として体系化したもの。

```text
F_narrative
  ≠ F_self-report
  ≠ F_author-evaluation
  ≠ M_B(theological synthesis)
```

この区別をしないと、たとえば「聖書の著者が神はすべてを知ると書いた」ことと、「神自身が自分の全知性を証明した」ことが同一視される。

## ■ 2. 全知性を強く支持する記述

聖書には、神の知識能力が人間を大きく超えることを示す記述が多数ある。

特に強いのがイザヤ書46章である。ここでは神自身が、初めから後のことを告げ、自らの計画を実現すると語る。これは少なくとも、未来について非常に強い知識または予測・制御能力を自己申告している。

さらに新約のヨハネの手紙一3:20には、著者側から神について「すべてを知っている」に相当する、かなり直接的な普遍表現が存在する。

したがって、

```text
K_YHWH >> K_human
```

だけでなく、聖書内部には実際に

```text
K_YHWH → universal
```

へ向かう強い記述が存在する。

この点から、「全知は完全に後世の神学者が付け加えた概念である」とするのも粗い。

**全知というラベルを生成するための強い材料は、すでに本文内部に存在する。**

ただし、

```text
「すべてを知る」という自然言語表現
```

と、

```text
∀p [ Truth(p) → Know_God(p) ]
```

という哲学・論理学的に厳密化された全知定義が完全に同一であるかは別問題である。

ここに最初の ξ が残る。

## ■ 3. 一方で「観測して知る」神も描かれる

創世記18章では、ソドムとゴモラについて、ヤハウェは訴えが実態通りなのか「降って見て」確認するという形で語る。本文を表面的に読む限り、

```text
情報受領
  ↓
現地確認
  ↓
判断
```

という情報取得手続きが描写されている。

これは、

```text
K(t0) < K(t1)
```

と読める余地を残す。

創世記22章にも、アブラハムの行動の後に「今、知った」に相当する表現がある。ただしここで発話しているのは「ヤハウェの使い」であり、これをそのままヤハウェ自身の認識状態と同一視することには追加解釈が必要である。

したがって、こちらは証拠強度を一段落とすべきである。

```text
Genesis 18 : ξ_K candidate = strong
Genesis 22 : ξ_K candidate = weaker
             because speaker = angel of YHWH
```

重要なのは、これらが「神は全知ではない」と証明するわけではないことである。

全知神学側からは、

- 人間向けの擬人的表現
- 確認行為であって情報取得ではない
- 物語上の表現
- 神が時間内で行動する際の表現形式

など、複数の再解釈が可能である。

しかしRDL的には、それらは**本文そのものではなく、本文を保存するために追加された \(B\)** として区別して保持した方がよい。

```text
F_text
      ↓
M_B1 = 「神は確認して知った」
M_B2 = 「全知だが確認という形を取った」

F_text alone → 一意決定不能
```

## ■ 4. 全能性を支持する記述

全能についても、聖書本文には非常に強い表現がある。

マタイ19:26では、イエスが人間には不可能でも神にはすべてが可能であると述べる。

さらに黙示録1:8では、「主なる神」が自身を「全能者」と呼ぶ明示的な自己宣言が存在する。

したがって全能については、

```text
「後世が勝手に無限化しただけ」
```

とすることも難しい。

少なくとも聖書内部に、

```text
P_God → universal
```

と読める非常に強い自己・他者記述が存在する。

ただし、ここでも自然言語としての「すべて」と、後世の哲学が定義する

```text
論理的に可能なすべての事態を実現できる
```

という精密な全能概念との間には距離がある。

聖書本文そのものは、

```text
Can(God, x) = true   ∀ logically_possible(x)
```

という形式定義を提示してはいない。

したがって、

```text
非常に強い普遍能力主張 = 硬い
哲学的に完全定義された全能 = ξ残
```

となる。

## ■ 5. 未来を「知る」と「作る」は分離できるか

イザヤ46章は特に興味深い。

神は未来を告げるだけでなく、そのすぐ近くで、自分の計画は成立し、自分がそれを実行すると語る。

すると、

```text
未来を知る能力
```

と

```text
未来を実現する能力
```

が混ざる。

たとえば非常に強い主体が、

```text
Prediction + Intervention
```

を同時に持っていれば、

```text
予言 → 実現
```

という外形を作ることができる。

したがって、

```text
ProphecySuccess
```

だけから、

```text
PerfectFutureKnowledge
```

を一意に逆算することはできない。

RDL的には、

```text
F = 「予告された未来が実現した」
```

に対して、

```text
EFP候補A = 完全予知
EFP候補B = 高精度予測
EFP候補C = 強力な介入による自己実現
EFP候補D = B + C
EFP候補E = 物語形成
...
```

が並立する。

RDLでは EFP は直接観測不能であり、観測者が持つのは解釈された作用 \(F\) である。

## ■ 6. 方針変更・後悔という記述

神の不変性・完全予知を考える上で、さらに重要なのが「後悔」「思い直し」に相当する記述である。

創世記6:6では、人間を造ったことについてヤハウェが悔いた・悲しんだと描写される。

サムエル記上15章では、ヤハウェ自身がサウルを王にしたことを悔いると語る。一方、同じ章の中でサムエルは、神は人間のように心を変える存在ではないとも語る。さらに章末では再び、ヤハウェがサウルを王にしたことを悔いたと記述される。

つまり同一章内に、

```text
Change(YHWH) = true
```

と読める記述と、

```text
Change(YHWH) = false
```

と読める記述が隣接している。

RDLでは、これをすぐ矛盾として消去する必要はない。

たとえば、

```text
M_core = 高耐久な目的・性質
M_policy(t) = 状況依存の局所方針
```

と分ければ、

```text
M_core : stable
M_policy : adaptive
```

という構造として読むこともできる。

さらにエレミヤ18章では、人間集団の行動変化に応じて、神が予定していた災いや恩恵を変更する条件構造が明示される。

したがって聖書中の神は、少なくとも物語表現としては、

```text
入力に関係なく固定出力を返す主体
```

ではなく、

```text
HumanAction(t)
      ↓
Evaluation
      ↓
DivineAction(t+1)
```

という応答系としても描かれている。

## ■ 7. 「実能力」と「神に見える能力」は同じではない

ここからは聖書本文そのものではなく、RDLによる思考実験である。

観測者が持つのが作用 \(F\) だけなら、

```text
実際に全知である
```

ことと、

```text
全知であるように観測される
```

ことは原理的に分けて考える必要がある。

たとえば仮想的に、

- 広範な監視
- 高度な情報収集
- 個人行動の予測
- 強力な環境制御
- 選択的な情報提示

を持つ主体を考える。

その主体が本当には有限でも、

```text
K_real < ∞
```

観測対象者からは、

```text
K_perceived → ∞
```

に近く見える可能性がある。

同様に、

```text
高精度予測
+
強い介入力
```

によって、

```text
未来を完全に知る存在
```

のように振る舞うことも理論上可能である。

したがって四層をさらに分離できる。

```text
A_real
  = 実際の能力

A_display
  = 表出された能力

A_observed
  = 観測者が推定した能力

A_theology
  = 後世に体系化された能力
```

一般には、

```text
A_real
≠ A_display
≠ A_observed
≠ A_theology
```

である。

これは「聖書の神は高度技術を持つ有限存在だった」という主張ではない。

その仮説を支持する直接的証拠は、本稿のBからは得られない。

重要なのは、

```text
奇跡として記録された
      ≠
技術的再現が原理的に不可能
```

であり、

```text
全知全能に見える
      ≠
全知全能であることの証明
```

だということである。

## ■ 8. 全知性を最終確定できるか

ここも聖書本文から直接得られる命題ではなく、全知概念そのものへのRDL的破壊検査である。

ここでは、次の二つを分離する必要がある。

```text
A. 観測者が、ある主体について
   「この主体は全知である」と最終確定できるか

B. 定義上の全知者自身が、
   自分の全知性を知り得るか
```

この二問は同一ではない。

まずAについて考える。

観測者がある主体の知識集合を、

```text
K_subject
```

として把握したとする。

その主体を全知と最終確定するには、少なくとも、

```text
Truth \ K_subject = ∅
```

すなわち、その主体の知識域外に真理が残っていないことまで確定する必要がある。

しかし観測者にとって、

```text
「未知が存在しない」
```

ことと、

```text
「未知を検出できていない」
```

ことは同じではない。

固定された有限領域や、外延が明示された対象領域であれば、完全走査や構造的証明によって不存在を示せる場合もある。

したがって問題は、

```text
不存在証明一般
```

にあるのではない。

RDL的に問題になるのは、

```text
「真理の絶対的全域」
```

まで境界非依存に閉じ、その全域について未知不存在を最終確定しようとする操作である。

```text
B_truth
   ↓
Truth_B
   ↓
K_subject ⊇ Truth_B ?
```

はB内では検査できる。

しかし、

```text
Truth_absolute
```

を観測者が完全に確定し、その全域について

```text
K_subject = Truth_absolute
```

まで閉じようとすると、`B_max` 問題が侵入する。

一方、B――定義上の全知者自身が自分の全知性を知れるか――については、RDLだけから不可能とは言えない。

たとえば全知を、

```text
「すべての真なる命題を知る」
```

と定義し、

```text
「私は全知である」
```

という命題が真かつその対象領域に含まれるなら、その自己知識まで定義に含める立場は構成可能である。

したがって、以前のように、

```text
K(K = 全知)
```

そのものを一般的な破断とみなすのは強すぎる。

RDLから比較的硬く残るのは、むしろ、

> **観測者が、ある主体の「全知」という属性を境界非依存の絶対域について最終確定しようとすると、ξが残る。**

という点である。

これは全知者の存在を否定する証明ではない。
また、全知者の自己知識を否定する証明でもない。

破断候補は、全知という存在そのものより、**観測者による絶対的な全知判定の閉包操作**にある。

## ■ 9. 聖書から硬く残るもの

以上から、聖書の神について比較的硬く残るのは次の構造である。

```text
M_Bible(God) = {
    人間を大幅に超える知識能力,
    人間を大幅に超える作用能力,
    未来についての非常に強い発言,
    自身の計画を実現する強い能力,
    人間内部への高い認識能力,
    状況に応答する動的行動,
    「すべてを知る」「全能者」等の普遍表現
}
```

したがって、

```text
God_Bible = 高能力主体
```

はかなり硬い。

さらに、

```text
God_Bible ≈ 全知全能
```

を支持する本文上の材料も強い。

特に新約には「すべてを知る」「全能者」「神にはすべてが可能」という直接的な普遍表現が存在するため、全知全能概念を単純に「後世だけの追加」とすることはできない。

しかし、

```text
K_God = ∞
P_God = ∞
```

という厳密な能力上限まで聖書本文だけから確定しようとすると、

```text
ξ_K = {
    観測して知る描写,
    試験後に知る描写,
    未来予知と未来形成の識別不能性,
    観測者による絶対的全知判定の閉包問題
}

ξ_P = {
    「すべて」の意味領域,
    自己制約と能力限界の識別,
    技術的・自然的・物語的代替機構,
    論理的不可能事態を含むか
}
```

が残る。

## ■ 10. RDL的結論

聖書から直接得られる神像を、

```text
全知全能
```

か、

```text
非全知全能
```

かの二択に落とす必要はない。

より情報量を保存した表現は、

```text
              ┌─ 非常に強い知識記述
              ├─ 非常に強い作用記述
God_Bible ────┼─ 普遍性を示す自己・他者表現
              ├─ 観測・試験・応答
              ├─ 後悔・方針変更
              └─ ξ_max
```

である。

したがって現段階では、

```text
硬い：
  聖書の神は非常に高い能力を持つ存在として描かれる。

かなり硬い：
  聖書自身に全知・全能へ向かう普遍的表現が存在する。

未確定：
  その能力が哲学的意味で厳密な無限・完全性を持つか。

さらに未確定：
  その能力を生み出す実在的機構が何であるか。
```

となる。

最も短く圧縮するなら、

```text
F_Bible
   ↓
M_B = 「極めて高能力であり、
       全知全能を示唆する強い普遍記述を持つ神」
   +
ξ = 「能力の真の上限・機構・絶対的全知判定の閉包」
```

である。

ここで重要なのは、ξ を「神が存在しない証拠」にすることでも、「信仰で埋めるべき穴」にすることでもない。

**分からない場所を、分からない形のまま保存する。**

RDLでは硬さを測るために引いた境界そのものにも ξ が残り、最後の判定を出さない。

したがって「全知全能」は否定されない。

同時に、無条件にも確定されない。

聖書本文から見えるのは、

> **極めて強い能力の勾配と、その先に引かれた「全知全能」という境界である。**

---

## ■ 11. 破断条件

本稿の読みが破断する条件を以下とする。

1. 聖書本文中に、哲学的に厳密な全知・全能定義が明示されていることが確認された場合
2. 「観測して知る」「後悔する」等の原語が、能力・認識変化を意味しないことが文献学的に強く確定した場合
3. RDLの `B → M_B + ξ` または観測者 `hold = F only` の前提が更新された場合
4. 「全知全能」という語の検査対象を、聖書本文ではなく特定宗派の神学定義へ変更した場合

その場合、本稿の B を引き直す。

## ■ 12. 残存構造

本稿が破断しても、次の区別は残る。

```text
実能力
≠ 自己申告能力
≠ 観測された能力
≠ 解釈された能力
≠ 神学的に体系化された能力
```

また、

```text
非常に高い
≠ 無限
```

という区別も残る。

これは神についてだけの問題ではない。

人間、国家、AI、科学理論、権威、未来予測など、

> **観測された高い能力から、観測されていない無限の能力へ境界を伸ばすとき**

一般に発生する構造である。
