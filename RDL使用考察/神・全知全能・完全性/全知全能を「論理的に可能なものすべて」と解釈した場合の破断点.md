# 全知全能を「論理的に可能なものすべて」と解釈した場合の破断点

*RDL使用考察 / META / DRAFT v0.5*
*依存：RDL_Core*
*シリーズ：神・全知全能・完全性 / 第II部：破壊検査編*
*関連稿：聖書から神の全知全能性をRDLで読み解く（自己完全性の確証問題と、本稿の絶対域確定問題は類似する境界問題として接続）*

---

## シリーズ上の位置

本稿は、シリーズ「神・全知全能・完全性」の**第II部：破壊検査編**である。

第I部では、聖書本文から「極めて高能力であり、全知全能を示唆する強い普遍記述を持つ神」までは比較的硬く残る一方、その能力上限・機構・自己完全性には ξ が残ることを確認した。

本稿ではその ξ を引き継ぎ、聖書本文から一度離れて、「論理的に可能なものすべて」という全能定義そのものがどこまで安定するかを検査する。ここで得られた破断構造は、第III部で「絶対完全性を置かずに、なお極めて強い主体をどう記述するか」という再構成へ送られる。

---

## ■ 0. 問い

全能をめぐる代表的な整理の一つに、次のような定義がある。

```text
Omnipotence :=
  「論理的に可能なすべての事態を実現できる能力」
```

この定義は、たとえば「四角い円を作れるか」「持ち上げられない石を作れるか」といった全能パラドックスに対して、論理的に成立しない対象を能力評価の外へ置くことで、全能概念を安定させようとする。

しかしRDLから見ると、ここで新しい問いが発生する。

> **「論理的に可能なすべて」とは、どの境界における『すべて』なのか。**

論理には、公理・定義・推論規則・対象領域などの前提が必要である。
その前提にも、さらに前提または採用理由が必要になる。

したがって本稿では、

```text
「神は論理的に可能なすべてを行える」
```

を真または偽と先に決めず、

```text
B_omni :=
  「論理的可能性を全能の定義域として採用したとき、
    その定義がどこまで安定し、どこで破断するかを見る」
```

と置く。

本稿の検査対象は神の実在ではない。
また、全能そのものの否定でもない。

検査対象は、

> **「論理的に可能なものすべて」という全能の定義形式**

である。

本稿は、姉妹稿「聖書から神の全知全能性をRDLで読み解く」の■8（「全知者は、自分が全知だと確証できるか」）で現れた自己完全性の確証問題とも接続する。ただし、両者を同一の論理定理として扱うわけではない。異なる入口（本文の観測記録 / 定義の演繹的検査）から、**境界を越えて完全性を最終確定しようとすると未確定部分が残る**という類似した構造が現れるかを検査する。

---

## ■ 1. 「論理的可能」は無前提ではない

ある事態 x が論理的に可能である、と判定するには、少なくとも何らかの論理体系が必要になる。

```text
L := {
  公理,
  定義,
  推論規則,
  対象領域,
  同一性条件,
  矛盾判定規則,
  ...
}
```

したがって、単純な

```text
Possible(x)
```

では情報が足りない。

RDL的には、より正確には、

```text
Possible_B(x)
```

と書く必要がある。

ここで B は、何を論理体系として採用し、何を対象とし、何を矛盾とみなすかを切り出す境界である。

```text
B_logic
   ↓
M_logic
   ↓
{ possible / impossible }
+
ξ_logic
```

ここで `ξ_logic` は、論理体系・論理境界に固有の未確定部分を強調するための表記である。以降、文脈上その由来が明らかな場合は、RDLの一般表記に合わせて単に `ξ` と略記する。

つまり「論理的に可能」は、境界を必要としない絶対属性ではなく、少なくとも観測者が扱う限り、ある B の内部で成立する判定になる。

さらに、この判定を精密化するには、

```text
Provable_B(x)  ＝ B内で可能と証明・構成できる
True(x)        ＝ 実際に可能である（B非依存）
```

を区別しておく必要がある。以降の節で見るように、この二つは一致するとは限らない。

## ■ 2. 全能定義は B 内完全能力へ変形する

全能を、

```text
∀x [ Possible(x) → Can(God, x) ]
```

と定義したとする。

しかし前節より、Possible は B 依存である。
すると式は、

```text
∀x [ Possible_B(x) → Can_B(God, x) ]
```

へ変形される。

集合として書けば、

```text
P_B := { x | Possible_B(x) }

Omnipotence_B :=
  ∀x ∈ P_B : Can_B(God, x)
```

となる。

このとき得られるのは、

```text
絶対的全能
```

ではなく、

```text
B によって定義された可能空間内での完全作用能力
```

である。

したがって最初の破断点は、

```text
「すべて」
      ↓
「B内のすべて」
```

への縮退として現れる。

---

## ■ 3. 「最大」も境界を要求する

全能を「最大能力」と言い換えても問題は消えない。

```text
MaxPower(God)
```

と書くには、少なくとも次が必要になる。

```text
何を能力と数えるか
どの対象集合を比較するか
どの尺度で比較するか
どの時間範囲を取るか
何を実現成功とみなすか
```

したがって、

```text
max
```

は単独では成立せず、実際には、

```text
Max_B(Power | domain, metric, t, criterion)
```

となる。

RDLでは、絶対最大を主張するには比較空間全体を閉じる必要がある。
しかし、

```text
B → M_B + ξ
B_max ∉ 観測者
```

を置くなら、観測者は最終的な比較空間を保持できない。

したがって、

```text
観測範囲内で最大
```

と、

```text
存在可能な全範囲で絶対最大
```

は分離される。

この `B_max ∉ 観測者` という前提は、後段（■8）で「境界非依存の絶対的不可能性」を語る場合にも関係する。ただし、問題は全称量化そのものではない。固定された比較空間や明示的に定義された対象クラスなら、最大値や全称命題を扱える場合はある。ここで問題になるのは、**比較空間そのものを境界非依存の絶対域として確定しようとする操作**である（■8末尾で回収する）。

## ■ 4. 論理の前提を掘ると、どこで止まるか——対角化・不動点という補助線

論理体系 L を採用したとする。

すると、次の問いが発生する。

```text
なぜその公理なのか
なぜその推論規則なのか
なぜその矛盾概念なのか
なぜその対象領域なのか
```

その理由を別の体系 L2 で与えるなら、今度は L2 の前提が問われる。

```text
L0
 ↓ 根拠
L1
 ↓ 根拠
L2
 ↓
...
```

この連鎖は、少なくとも次のいずれかに落ちる。

```text
A. 公理として止める
B. 別体系へ依存し続ける
C. 複数体系が相互に支える
D. 無限後退する
```

RDLでは、A を絶対基底とは呼ばない。

```text
「ここから先は、この操作では問わない」
```

という B の仮設として扱う。

B・C・Dについても、最終的な無前提地点を直接与えるものではない。

### 4.1 ゲーデルの不完全性定理が与える具体例

この一般論に対して、ゲーデルの不完全性定理は一つの重要な具体例を与える。

典型的な第二不完全性定理では、十分な算術的表現力と適切な形式化条件を持つ整合的な形式体系 T について、

```text
T ⊬ Con(T)
```

すなわち、T 自身の標準的に形式化された無矛盾性を、T 内部だけで証明できないという制約が現れる。

ただし、ここから直ちに、

```text
自己言及できる系
=
自分の完全性を証明できない系
```

と一般化してはならない。

ゲーデルの定理には適用条件があり、弱い体系や異なる形式化では事情が変わる。したがって本稿では、ゲーデルを「自己言及構造一般の定理」として使用しない。

### 4.2 Lawvere 型不動点定理との接続

Lawvere 型の不動点定理は、ゲーデル・カントール等に現れる対角化を、より抽象的な構造の上で捉えるための強い補助線になる。

ここから安全に取り出せるのは、

```text
自己記述
+
対角化
+
不動点
```

に関係する複数の限界結果が、**共通する構造パターンを持ち得る**という点である。

しかし、

```text
ゲーデル不完全性
=
自己言及・不動点を持つ系一般の不完全性
```

という同一性主張ではない。

RDL的には、

```text
ある B_logic が
自己記述・対角化・不動点を可能にする条件を満たす
        ↓
その条件に応じた閉じなさが現れる可能性
```

までを補助線として保持する。

重要なのは、本稿の主線がこの補助線に依存していないことである。

```text
Possible
↓
Possible_B
↓
Omnipotence_B
↓
B_logic 自体をどう扱うか
↓
絶対版の定義域が閉じない
```

という流れは、ゲーデルやLawvereを使わなくても成立する。

したがって本節は、全能定義の境界問題に現れ得る**自己記述・対角化系の追加的な破断候補**を示す節として位置づける。

## ■ 5. 第一破断：論理境界を神は変更できるか

ここで最も強い破断候補が現れる。

問いは単純である。

> **神は、全能の定義に使われている論理境界 B_logic 自体を変更できるか。**

### Case A：変更できない

```text
Can(God, ΔB_logic) = false
```

なら、神には変更不能な構造が存在する。

```text
God ⊂ constraint(B_logic)
```

となり、全能は明示的に B_logic の下位へ置かれる。

これは必ずしも神学的全能を否定しない。
しかし、

```text
「何にも拘束されない絶対能力」
```

という直観的全能像からは離れる。

### Case B：変更できる

```text
Can(God, ΔB_logic) = true
```

なら、今度は、

```text
Possible_B
```

そのものが変更可能になる。

すると、

```text
「論理的に可能なすべて」
```

という全能の定義域が、全能主体自身によって書き換え可能になる。

したがって、

```text
Omnipotence_B
```

を**境界非依存の固定定義**として保持できない。

### Case A と Case B から硬く残るもの

ここで、Case B を選べば必ずゲーデル的問題が一段上で再現される、とまでは言えない。

新しい体系 B_logic' がゲーデル的不完全性定理等の適用条件を満たすなら、類似した制約が再び現れる場合はある。しかし、それは B_logic' の具体的構造に依存する。

本稿の主線に必要なのは、そこまで強い主張ではない。

```text
Case A：
  B_logic を変更できない
  → 能力には少なくとも一つの外部制約が残る

Case B：
  B_logic を変更できる
  → 「可能なすべて」の定義域自体が可変になる
```

したがって第一破断は、

> **論理境界を固定すれば境界内全能になり、論理境界まで能力対象に含めれば全能の定義域そのものが動く。**

という形で残る。

この二分岐だけで、絶対全能を単一の静的定義として保持することの難しさは十分に示される。

## ■ 6. 第一破断の内部分岐：能力対象に「定義域の変更」を含めるか

前節の Case B をさらに分解する。

全能が、

```text
P_B 内のすべてを実現できる
```

能力だとする。

では、

```text
x = 「P_B 自体を変更する」
```

は P_B に含まれるか。

### 含まれない場合

```text
ΔP_B ∉ P_B
```

神は定義域外操作を行えない。

したがって、

```text
境界内完全
≠
境界超越的完全
```

となる。

### 含まれる場合

```text
ΔP_B ∈ P_B
```

なら、P_B の内部に「P_Bを書き換える操作」が含まれる。

すると、実行後には、

```text
P_B → P_B'
```

となり、元の全能定義が参照していた集合自体が変化する。

これは単純な論理矛盾とは限らない。
しかし、全能ラベルの定義域が自己変更を含むため、静的な M_B としては保持しにくくなる。

### 固定B内の問題と、絶対域の問題を分ける

ここでは、

```text
「自己言及構造を持たない」
```

ことが一般に証明不能だとは置かない。

固定された B_logic の内部で、

- 対象領域が有限である
- 構文上の制約が明示されている
- 構造定理によって存在不能が示せる

などの条件があれば、特定構造の不存在を証明できる場合は普通にある。

RDL側で問題になるのは、より強い主張である。

```text
この B_logic では自己言及構造がない
```

ではなく、

```text
境界の外側まで含む
「あらゆる可能な論理体系」において、
その種の構造は存在しない
```

と絶対化するときである。

このとき問題になるのは「不存在証明そのもの」ではなく、

```text
「あらゆる可能な論理体系」
```

という対象領域を、境界非依存にどう確定するかである。

この問題は■8で改めて分離する。

## ■ 7. 第二破断：「あらゆる論理体系」を取れば解決するか

単一の B_logic に依存するのが問題なら、

```text
すべての論理体系を対象にすればよい
```

という応答が考えられる。

すなわち、

```text
P_all-logic := ⋃ P_Bi
```

とする。

しかし、ここでも問題が残る。

### 7.1 「すべての論理体系」の境界

何を論理体系として数えるのか。

```text
Classical logic
Intuitionistic logic
Paraconsistent logic
Modal logic
...
```

既知の体系を列挙することと、

```text
存在可能な全論理体系
```

を確定することは同じではない。

したがって、

```text
AllLogic
```

を作るためにも別の B が必要になる。

### 7.2 体系間で可能性判定が一致しない

ある命題 x が、

```text
Possible_B1(x) = true
Possible_B2(x) = false
```

となることもあり得る。

すると、

```text
「論理的に可能」
```

という単一ラベルが再び分解される。

つまり、論理体系を増やせば B 依存性が消えるのではなく、B のネットワークが増える。

## ■ 8. 第三破断：「絶対に論理的不可能」をどう確定するか

ある事態 x について、

```text
Impossible(x)
```

を絶対的に主張するには、

```text
どの論理体系を対象に含めるか
```

を先に定める必要がある。

たとえば、明示的に定義された論理体系のクラス ℒ に対して、

```text
∀B_logic ∈ ℒ : Impossible_B(x)
```

を証明すること自体は原理的に可能である。

有限個を検査してもよいし、ℒ 全体に対する一般定理によって一括して示してもよい。

したがって、

```text
全称命題
→ B_max が必要
```

でも、

```text
不存在証明
→ B_max が必要
```

でもない。

問題は、

```text
ℒ = 「存在可能なすべての論理体系」
```

と置いた瞬間に発生する。

この ℒ が明示的な定義域ではなく、

```text
既知・未知を問わず
境界の外側まで含めた
絶対的な全論理空間
```

を意味するなら、その外延を観測者がどう確定するかが問われる。

RDLの

```text
B_max ∉ 観測者
```

を採用する限り、ここには ξ が残る。

したがって、

```text
このBでは不可能
```

や、

```text
明示的に定義された論理クラス ℒ では不可能
```

は強く言えても、

```text
境界非依存のあらゆる論理において絶対不可能
```

へ移ると、対象領域そのものの確定問題が発生する。

### P11：固定B内の不存在証明と、絶対域の不存在確定を分離する

■4・■6で扱った「自己言及構造を構成できるか」という問題にも、この区別を適用する。

固定された B_logic に対して、

```text
¬∃x : SelfReference_B(x)
```

を証明できる可能性はある。

したがって、

```text
「構造を持つ」は示せる
「構造を持たない」は示せない
```

という一般的な非対称性は採用しない。

RDL的に残るのは次の区別である。

```text
固定された B または
明示的に定義されたクラス ℒ 内での不存在証明
        → 可能

境界非依存の「全可能論理空間」において
未知の自己言及構造まで存在しないと最終確定
        → ℒ_absolute の外延確定に ξ
```

ここで B_max 問題が侵入するのは、否定命題だからではない。

> **「何についての全称なのか」という対象領域そのものを、絶対域として固定しようとするためである。**

これは姉妹稿「聖書から神の全知全能性をRDLで読み解く」■8の、

```text
「未知が存在しない」
      ≠
「未知を検出できていない」
```

という問題と類似する。

ただし両者を完全に同型とは置かない。

共通しているのは、

```text
固定された B 内での確証
```

から、

```text
B の外側を含む絶対的完全性の確証
```

へ移るときに、境界そのものの確定問題が現れるという点である。

したがって、■3の「絶対最大」、本節前半の「絶対不可能」、P11の「絶対域での不存在」は、

> **全称量化そのものの不可能性ではなく、境界非依存の対象領域を確定しようとする同系統の問題**

として回収する。

## ■ 9. 「論理的に可能なすべてができる」は論理的に不可能か

ここで、強い言い方を検査する。

```text
「論理的に可能なすべてができる」
という能力自体が論理的に不可能なのではないか。
```

RDLからは、現段階でそこまでは言えない。

理由は、ある B_logic を固定すれば、

```text
∀x ∈ P_B : Can(God, x)
```

というモデル自体は構成できるからである。

したがって破断は、

```text
命題が直接矛盾する
```

という形より、

```text
絶対化したときに定義域が閉じない
```

という形で現れる。

より正確には、

```text
局所版：
  「B_logic 内で可能なすべてができる」
  → 構成可能

絶対版：
  「あらゆる論理的可能性を完全に覆い、
    その全域に作用できる」
  → 定義域の完全確定に ξ が残る
```

となる。

したがってRDL的な破断判定は、

> **「論理的に可能なすべてができる」は偽と確定されるのではなく、絶対的全能の定義としては閉じない。**

である。この結論は■12のP10と対応する。

## ■ 10. 全知にも同じ問題が侵入する

全知を、

```text
Omniscience :=
  「知ることが論理的に可能なすべての真理を知る」
```

と定義した場合も、同様の問題が起こる。

```text
Truth_B
Knowable_B
Possible_B
```

の境界が必要になる。

すると、

```text
∀p ∈ Truth_B : Know(God, p)
```

は B 内全知としては記述できる。

しかし、

```text
Truth_all
```

または、

```text
すべての可能な論理体系における全真理
```

を完全に閉じるには、再び B_max 問題が出る。

さらに、神自身が B_logic を変更できるなら、

```text
Truth_B → Truth_B'
```

となり得るため、

```text
「神が知るべき全真理の集合」
```

そのものも静的ではなくなる。

したがって、全知と全能は別々の属性でありながら、

```text
「論理的可能性」
```

を共通基盤に置いた瞬間、同じ境界問題を共有する。

これは、姉妹稿の中心主題であった K(K=全知)——知識体系が自己の完全性を確証する操作——とも比較できる。ただし、同一の定理や同一のテスト構造とは置かない。両者に共通して注目するのは、**固定された境界内の確証から、境界の外側を含む絶対的完全性の確証へ拡張する地点**である。

## ■ 11. 決定論との距離

「論理的に可能なすべて」を能力空間として採用すると、未来は必ずしも一本の決定済み経路として扱われない。

```text
Future_B = { f1, f2, f3, ... }
```

のような可能状態空間として扱う余地が生まれる。

すると神は、

```text
決定済み未来を完全に読む主体
```

だけではなく、

```text
可能空間から状態を選択・実現できる主体
```

としても記述される。

この場合、

```text
全知
全能
自由
未来確定性
```

は独立した最大属性ではなく、相互拘束する変数になる。

たとえば、神自身の未来行動について、

```text
God knows at t0 that God chooses A at t1
```

としたとき、t1 に A 以外を選べるのか、という問題が生じる。

```text
選べない
→ 全知が自己行動を拘束する

選べる
→ t0 の未来知識の完全性が揺れる
```

したがって、論理的可能性による全能定義は、決定論を強化するというより、むしろ可能空間と選択能力の問題を前面化する場合がある。

*本節は、本稿の主線（B_logic依存性から定義域の閉じなさへ至る論証）に対しては派生的な観察であり、■12の破断点一覧には直接対応する項目を持たない。姉妹稿の未来知識・後悔の記述（■5〜6）と接続する予知/実現分離の問題として、独立の検討課題に位置づける。*

## ■ 12. 破断点一覧

以上を圧縮すると、主要な破断点は次の通りである。

```text
【前提】

P1：論理的可能性は B_logic を必要とする（■1）

P2：「すべて」は P_B 内のすべてへ縮退する（■2）

P3：「最大」は比較空間・尺度・対象境界を必要とする（■3）

P4：論理の基礎づけには停止点・依存先・採用境界が必要になる。
    ゲーデル／Lawvereは、特定条件下で生じる
    対角化・不動点由来の閉じなさを示す補助線であり、
    自己言及系一般への定理としては使わない（■4）

【狭義の破断】

P5：神が B_logic を変更できないなら、
    全能は B_logic に拘束された境界内全能になる（■5 Case A）

P6：神が B_logic を変更できるなら、
    「論理的に可能なすべて」の定義域そのものが可変になる（■5 Case B）

P7：定義域変更を能力対象に含めると、
    全能定義は自己変更構造を持つ（■6）

P8：「すべての論理体系」を対象にしても、
    何をその全体へ含めるかというメタ境界が必要になる（■7）

P9：明示的な論理クラス内での不可能性証明は可能だが、
    「境界非依存の全論理空間で絶対不可能」とするには
    その絶対域の外延確定に ξ が残る（■8前半）

P11：固定B内で「自己言及構造が存在しない」と証明することは可能。
     ただし、境界非依存の全可能論理空間にまで不存在を拡張するなら、
     対象領域そのものの確定に B_max 問題が入る（■8後半）

※ P番号は改訂履歴との対応を保つため、現在の配列順とは一致しない。
   P11は後から追加された検査項目であり、結論P10の前に配置している。

【結論】

P10：絶対版全能は偽と証明されるより、
     境界非依存の定義域を固定しようとした地点で閉じなくなる（■9）

     ※ P3・P8・P9・P11に共通するのは
        「全称量化は不可能」ということではなく、
        境界非依存の絶対域を確定する操作の問題である。
```

## ■ 13. 硬く残るもの

この検査から比較的硬く残るのは、次の区別である。

```text
論理的可能
≠ 無前提の可能性

境界内完全
≠ 境界超越的完全

B内最大
≠ 絶対最大

観測済み上限
≠ 存在可能な全域上限

ある論理体系で不可能
≠ 境界非依存のあらゆる論理で絶対不可能

固定B内の不存在証明
≠ 絶対域そのものを閉じた上での不存在確定
```

特に重要なのは、

```text
不存在証明
```

そのものを弱く扱わないことである。

固定された B や、明示的に定義された対象クラスの内部なら、不存在は通常の数学的・論理的手続きによって証明可能である。

RDLが ξ を残すのは、

```text
その B の外側まで含めた
境界非依存の絶対域
```

へ主張を拡張するときである。

したがって、

```text
「論理的に可能なすべてができる」
```

という全能定義から硬く取り出せるのは、現段階では、

```text
M_B =
  「採用された論理境界内で、
    可能と分類された全事態に対して
    完全な作用能力を持つ」
```

までである。

その外側には、

```text
ξ = {
  B_logic の選択理由,
  論理体系の完全な外延,
  定義域変更可能性,
  絶対最大の比較空間,
  未知の論理体系,
  B_max,
  論理そのものを能力対象に含めるか,
  「全可能論理空間」というメタ境界の外延
}
```

が残る。

## ■ 14. RDL的結論

「論理的に可能なすべてを行える」と全能を定義すると、全能パラドックスの一部は処理できる。

しかしその代わりに、能力境界の問題は、

```text
何ができるか
```

から、

```text
何を「論理的に可能」と数えるか
```

へ移動する。

さらにそこを掘ると、

```text
どの論理か
↓
どの前提か
↓
なぜその前提か
↓
その境界を能力主体は変更できるか
↓
変更できないなら境界内全能
↓
変更できるなら可能空間そのものが可変
↓
では「あらゆる可能な論理体系」を対象にするか
↓
その「あらゆる」の対象領域をどう定めるか
↓
境界非依存の絶対域を要求すると B_max 問題
```

となる。

したがって、RDLでは、

```text
Omnipotence_absolute
```

をそのまま保持するより、

```text
Omnipotence_B
=
「B_logic が生成する可能空間内における完全作用能力」
```

として保持した方が情報量が多い。

最短に圧縮すれば、

```text
「論理的に可能なすべてができる」

        ↓ RDL

B_logic
   ↓
P_B = possible states under B
   ↓
∀x ∈ P_B : Can(God, x)
   +
ξ = 「Bそのものの上限・根拠・変更可能性・
      全可能論理空間を絶対域として固定できるか」
```

となる。

ここでの破断は、

```text
「全能は存在しない」
```

ではない。

また、

```text
「論理的に可能なすべてができる」という命題は論理矛盾である
```

とも限らない。

破断するのは、

> **ある B 内で定義された完全能力を、Bそのものの外側まで含む境界非依存の絶対属性として固定しようとする操作である。**

ゲーデルやLawvereは、この主線を成立させるための必須前提ではない。

それらは、特定条件下で自己記述・対角化・不動点が別種の閉じなさを生むことを示す、追加の破壊検査として残る。

この結論は、姉妹稿の

> 「全知」という属性を観測者が最終確定する操作には、自己参照的な ξ が残る

という指摘とも接続する。

ただし、両者を同一の論理構造とは固定しない。

共通して硬く残るのは、

> **局所的・境界内の完全性から、境界非依存の絶対完全性へ拡張する地点で、境界そのものの確定問題が現れる。**

という構造である。

---

## ■ 15. 破断条件

本稿の読みが破断する条件を以下とする。

1. 境界・前提に依存しない単一の絶対論理体系、または「存在可能な全論理体系」の境界非依存な外延が観測者に確定可能であることが示された場合
2. `B → M_B + ξ` または `B_max ∉ 観測者` がRDLから除去・更新された場合
3. 「論理的可能」の定義を、特定の形式体系内部に限定すると明示した場合
4. 全能の対象から、論理・定義域・自己変更操作を明示的に除外した場合
5. 本稿の検査対象を「絶対的全能」ではなく、特定宗派・特定哲学体系内の技術的定義へ変更した場合

なお、■4のゲーデル／Lawvere接続が不適切であることが示された場合、その補助線は撤回する。

しかし、

```text
Possible
↓
Possible_B
↓
Omnipotence_B
↓
B_logic の固定／変更
↓
絶対域の外延問題
```

という本稿の主線は、それだけでは破断しない。

## ■ 16. 残存構造

本稿の個別議論が破断しても、次の構造は残る。

```text
能力を測るには定義域が必要

最大を語るには比較空間が必要

可能・不可能を語るには判定規則が必要

判定規則を置けば、その採用境界が生じる

境界内完全 ≠ 境界外を含む絶対完全

固定された対象領域では不存在証明も可能

固定された対象領域での不存在
≠
境界非依存の絶対域における不存在
```

これは神の全能だけの問題ではない。

```text
AIは何でもできる
国家はすべてを把握できる
数学はすべての真理を記述できる
科学は原理的にすべてを説明できる
完全なシミュレーションが可能である
```

といった、

> **有限な定義域内の完全性を、定義域そのものを含む絶対的完全性へ拡張するとき**

一般に現れる構造である。

さらに自己記述能力を持つ系では、条件次第で対角化・不動点・自己整合性に関する追加の限界が現れることがある。

ただし、それは本稿の境界問題と比較可能な**追加構造**として扱い、自己記述系一般に同じ定理が成立するとまでは置かない。
