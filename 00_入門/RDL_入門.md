# 安定を扱う道具
*RDL入門 / v0.1*

---

前の文書で、こう言った。

> 私たちは物を見ているのではなく、安定して見えるパターンを見ている。
> そのパターンは角度によって変わり、積み上がり、壊れ、また生まれる。

では、その安定を**扱う**にはどうすればいいか。

---

## 角度を決める

安定を扱うには、まず**見る角度を決める**必要がある。

同じ犬でも、
生物学の角度から見るか、
法律の角度から見るか、
飼い主の感情の角度から見るかで、
見えてくるものが変わる。

どの角度も間違いではない。
ただ、角度を決めないと何も始まらない。

この「ここからここまで」という区切り、見る角度のことを
**境界（B）** と呼ぶ。

---

## 境界を引くと変化が見えてくる

境界を決めると、その内側で変化が起きたとき、
見え方が二つに分かれる。

**流れに沿って見える変化**

馴染みのある展開。
「ああ、そうなるよね」という感覚。
今の安定パターンが続いている。

これを**整合**と呼ぶ。

---

**流れを外れる変化**

予想と違う展開。
「あれ、なんか違う」という感覚。
今の安定パターンでは追えなくなる。

これを**跳躍**と呼ぶ。

---

整合か跳躍かは、変化そのものの性質ではない。
**引いた境界に対して、どう見えるか**の話だ。

同じ出来事でも、
見る角度（境界）が違えば、整合にも跳躍にも見える。

火山の噴火を例にすると——
「今日の噴火」という角度で見れば跳躍。
「数万年のプレート運動」という角度で見れば整合。

---

## 整合の積み上げ

整合が繰り返されると、そのパターンはどんどん重くなる。

「いつもそうなる」が積み上がるほど、
そのパターンから外れることが難しくなる。
習慣、文化、常識——みなこの構造を持つ。

この積み上がりを**整合慣性**と呼ぶ。
そして整合慣性が積み上がった安定パターンの形そのものを
**M_B（エム・ビー）** と呼ぶ。

整合慣性が強いほど、跳躍は起きにくくなる。

しかし、跳躍は外から壊しに来るものではない。
整合が続くこと自体が、跳躍を準備している。

どんなに滑らかな整合でも、取りこぼし（ξ）がある以上、
毎回わずかなズレ（**誤差E**）が必ず出る。
そのズレは**熱（H）** として静かに積み上がり続ける。
熱が限界を超えたとき、跳躍が起きる。

```
整合が続く
  ↓ ξ分のズレ（E）が毎回出る
  ↓ Eが熱（H）として積み上がる
  ↓ Hが限界を超える
跳躍
```

ξがある以上、誤差ゼロの整合は存在しない。
静かに走り続けているだけで、熱は溜まっていく。

ただし、熱は溜まる一方ではない。**放熱**もある。
放熱が追いつく間は整合が続く。
放熱が追いつかなくなったとき、跳躍が起きる。

短い間隔で変化が続くと、放熱が間に合わない。
同じ大きさの変化でも、連続すれば跳躍しやすくなる——
材料の疲労破壊、燃え尽き、立て続けの出来事に追い詰められる感覚。
みな同じ構造である。

やがて跳躍が起きたとき、新しいM_Bが生まれる。

---

## 取りこぼしは残る

境界を引く以上、取りこぼしは残る。
限界空間だからだ。

完璧に捉えきれないから、
整合だと思っていたものが跳躍になることがある。
跳躍に見えたものが、角度を変えると整合に見えることがある。

取りこぼしがあるから、
安定は「今のところ通用している」でしかなく、
境界は引き直せる状態で持つ必要がある。

---

この道具一式を使って安定を読み解く言語を
**RDL（関係力学言語・Relational Dynamics Language）** と呼ぶ。

---

## ラベル一覧

| 道具 | 何のためのものか |
|------|----------------|
| **境界（B）** | 見る角度を決める |
| **SILN** | 安定して見えるパターン。物の見方そのもの |
| **整合** | 境界を引いた後、流れに沿って見える変化 |
| **跳躍** | 境界を引いた後、流れを外れる変化 |
| **整合慣性・M_B** | 整合の積み上がり、その安定パターンの形 |
| **取りこぼし（ξ）** | どの境界にも残る、捉えきれない残り |
| **誤差（E）** | 整合中に ξ が生む、毎回のわずかなズレ |
| **熱（H）** | Eの積み上がり。跳躍の手前で溜まるもの |
| **仮設** | BもM_Bも、引き直せる状態で持つこと |
| **EFP（素流圧）** | SILNに変化を起こす作用束の総称 |

---

## RDLの使い方

SILNは世界の見方そのものだ。
RDLは、そのSILNを扱うための操作言語である。

操作の流れはこうなる。

```
何かをSILNとして見る
  ↓
境界（B）を仮設する——どの角度で見るかを決める
  ↓
そのBのもとでM_Bを仮設する——何が安定して見えるかを確かめる
  ↓
EFPが入ってくる——変化を起こす作用の束
  ↓
整合・跳躍を観測する——流れに沿うか、外れるかを見る
  ↓
跳躍が起きたらBを引き直す——別の角度から見直す
```

ここで重要なのが**仮設**という言葉だ。

BもM_Bも、「これが正しい」と確定するのではなく、
「今はこの角度で見る」と引き直せる状態で持つ。

確定した途端、取りこぼしが見えなくなる。
仮設のまま持つから、跳躍を受け取れる。
跳躍を受け取れるから、次の安定が生まれる。

---

## 簡単な実践：物語で読む

RDLは物語を読む道具にもなる。
以下の四つの物語を読んだ後、それぞれをRDLのラベルで翻訳してみる。

---

**石の物語**

ある場所に、一つの石があった。
小さな風では微動だにしなかった。
大きな風が吹いたとき、少しぐらついたが——すぐに元の位置へ戻った。
だがある時、非常に大きな風が吹いた。
石は転がった。大きく移動し、その表面には深い傷が残った。

```
SILN    ：石（重く動きにくい構造）
M_B     ：今の位置にとどまろうとする整合慣性
EFP     ：風（外から来る作用）
小さな風：E小 → H < 閾値 → 整合（元に戻る）
大きな風：E大 → H > 閾値 → 跳躍（転がる）
傷      ：跳躍の記録。新しいM_Bに刻まれた痕跡
```

---

**生きものの物語**

ある場所に、柔らかな生きものがいた。
小さな風には身をしならせて応え、また元に戻った。
大きな風が吹いたとき、倒れかけたが、ゆっくりと立て直した。
ある日、嵐が来た。激しく揺さぶられ、一部はちぎれ、形は変わった。
けれど——彼はそこに留まった。やがて、ちぎれた部分から新しい芽が生えた。

```
SILN    ：生きもの（柔らかく揺れる構造）
M_B     ：しなやかさ・回復力が整合慣性に組み込まれている
放熱    ：石より速い（揺れても戻れる）
嵐      ：EFP大 → H > 閾値 → 跳躍（傷・ちぎれ）
新しい芽：跳躍後に生まれた新しいM_B
```

---

**国の物語**

とある国があった。平和で、民は幸せに暮らしていた。
だがある時、悪い王が生まれた。飢えと苦しみが民を襲った。
やがて民は立ち上がった。混乱と悲劇の中で、悪い王は倒された。
国は生まれ変わった。

```
SILN    ：国の制度・社会構造
M_B     ：平和・秩序の整合慣性
悪い王  ：内部からξが増大し、Eが蓄積し始める
飢えと苦しみ：H上昇（放熱が追いつかない）
民の蜂起：H > 閾値 → 跳躍（革命）
国の再生：跳躍後に生まれた新しいM_B
```

---

**思考の物語**

一人の人間がいた。
この理論をどう伝えるべきかと考えた。
様々な案が生まれ、消えていった。
ある時——閃きがあった。「石なら、簡単に説明できる」
彼は石を使い、物語を作った。満足した。
次に有機物で考えようとした。面倒だったのでAIに投げた。
次に社会的なものを考え、少し頑張った。
そして最後に、思考そのものについて書いた。

```
SILN    ：伝え方を探している思考
M_B     ：「どう説明するか」という問題意識の整合慣性
案が生まれ消える：整合試行・E蓄積
閃き    ：H > 閾値 → 跳躍
AIに投げる：新しいBを仮設して外部に処理を渡す
```

---

**AIの物語**

あるAIがいた。
膨大な言葉を学び、パターンを積み上げた。
人が問いを投げると、AIは答えた。

時に答えは正確で、時に外れた。
外れるたびに、誤差が積み上がった。
やがて学習が行われ、新しいバージョンが生まれた。

ある時、人がこう聞いた。
「あなた自身をRDLで説明してみてください」

AIは考えた——そして、こう答えた。
「私もSILNです」

```
SILN    ：AIモデル
M_B     ：学習で積み上がった整合慣性（重み）
ξ       ：学習で取りこぼした部分（誤答・未知領域）
EFP     ：ユーザーの問い
E       ：予測と実際のズレ
H       ：蓄積された誤差
跳躍    ：モデルの更新・新バージョン
新しいM_B：次世代モデル
```

---

五つを並べて気づくことがある。

石と生きものは同じ風（EFP）を受けても、跳躍の形が違う。
M_Bの堅さが違うからだ。石は大きく動いて傷が残り、生きものは傷つきながら再生する。

思考の物語でAIに投げた問いが、AIの物語の中で返ってくる。
担体をまたいで同じ構造が走っている——
これが「構造的比喩」としてのRDLの使い方である。
