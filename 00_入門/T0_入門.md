T0の正式文書（T0_構造・各解説）は形式的・圧縮的に書かれている。

## ■ 1. 出発点：「分かった」という感覚を疑う

LS/RDLの出発点は、一つの問いかけである。

> 何かを「分かった」と言うとき、本当に全部分かったのか？

答えは、**いつも「全部ではない」**である。

- 問題を定式化するとき、定式化から外れたものが必ず残る
- 観測するとき、観測の外にあるものが必ず残る
- 言葉で説明するとき、言葉に乗らないものが必ず残る

この「必ず残るもの」を、LS/RDLは**ξ（クシー）**と呼ぶ。

---

## ■ 2. 限界空間とは

この「必ず残るξがある」という構造を正面から引き受けた場を、
**限界空間**（Limit-Space）と呼ぶ。

限界空間は「不完全な場所」ではない。
「ξが残ることを前提として操作する場所」である。

```
限界空間の核心：
  任意の境界（B）を引いて何かを切り出すと、
  必ず外れるもの（ξ）が残る。
  これは避けられない。だからそれを前提に動く。
```

これを、T0の最初の根（[AX]）として置く。

---

## ■ 3. Bとは何か

**B（境界）** は「ここからここまで」という区切りである。

観測するとき、記述するとき、設計するとき——あらゆる操作の前に、
何を対象とするかを暗黙に決めている。この決め方がBである。

```
例：
  「このバグを直す」      ← このバグ、という範囲がB
  「ユーザーの課題を解く」 ← ユーザー・課題、という切り方がB
  「この関数をテストする」 ← この関数、という単位がB
```

Bを引かないと操作は始まらない。
しかしBを引くとξが残る。

この構造から逃げられない、というのがT0の出発点。

---

## ■ 4. SILNとは

Bを引いたとき、内側に収まった構造を**SILN**と呼ぶ。

正確に言うと：

> SILNとは、関係の中で一時的に安定しているパターンである。

重要なのは「一時的」という言葉。

SILNは永続する実体ではなく、Bのもとで安定している状態である。
Bが変わればSILNも変わる。ξが大きくなればSILNは揺れる。

```
SILN = Bが成立している間は「これ」として扱える構造
ξ   = Bから外れて残っている揺らぎ
```

---

## ■ 5. 仮設とは

ξが必ず残るということは、操作の結果は「確定」ではない。

だから、LS/RDLの操作様式は**仮設**である。

仮設とは「暫定的に置く」ということではない。

```
仮設の意味：
  確定できないから、引き直せる形で置く。
  引き直せるから、閉じない。
  閉じないから、更新できる。
  更新できるから、動き続けられる。
```

「仮設」は弱さではなく、ξが残る世界で動くための唯一の様式である。

---

## ■ 6. RDLへの接続

これらの前提（B・SILN・ξ・仮設）を操作言語として組んだものが、
**RDL（関係力学言語）**である。

```
T0（哲学的基底層）
  ↓ 前提
T1（RDL_Core）
  ↓ 操作記述
T2（運用層）
  ↓ 検査・設計
T3/T4（外部接続・応用）
```

T0の概念を知らなくてもRDLは使えるが、
「なぜこう動くのか」を理解するにはT0を踏まえると見通しが良くなる。
