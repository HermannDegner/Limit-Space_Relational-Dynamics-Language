## ■ 0. 運用規則

本文書は T0 の構造（規範 claim）だけを置く、システムのヘッダファイルである。

**三段構成。** 根 → 定理 → 便利な定義。

```text
根          ：irreducible な claim。これ以上分解しない（限界空間・SILN）
定理        ：操作しようとすると強制的に出る claim（純論理の演繹ではない）
便利な定義  ：claim を書くための term。仮設すると便利な語彙（定義本体は T-D）
```

- **claim と term を分ける。** 根＋定理＝claim（真・強制される主張）。便利な定義＝term（主張を書く語彙）。例：「観測には B が要る」は claim、「B」という語は term。
- **定理は「操作しようとすると出る」。** 純論理で導かれるのではなく、実際に B を引く／分解する／記述する瞬間に強制的に立ち上がる。RDL は演繹せず、仮設＋分解＋翻訳で動く（→ T5 記述メタファー運用考察）。
- **[GATE] 限界空間的構造破壊ゲート（最根源規則）。** あらゆるラベルは「仮設として運用できるか＝引き直せる／反例で更新されるか」の一点で濾される。通れば限界空間内、通れなければ（＝絶対化・確定化されれば）形而上空間へ移る（[MET]）。これは [AX] から直接出る調整不可能な原初フィルタ＝RDL の原初的構造破壊学であり、用途で重さを調整できる T2 構造破壊学（破断条件・残存・移植・有効範囲…）の祖型・最下層にあたる。形而上／限界の境界は物の種類ではなくラベルの扱い方であり、上下ではなく所属の区分。
  *[GATE] を観測者が自分自身に連続的・自覚的にかける運用フォーム（人間担体での実行形）＝限界観照姿勢。その原理面が憲章 [CHARTER]（RDLも例外でない＝[GATE]を通る、の自己拘束宣言）。[GATE]（機構）・憲章（原理）・姿勢（実践）は RDL の自己適用の三相で相互作用する。→ RDL憲章と限界観照姿勢.md*
- **参照はラベル ID で行う。** 下流はファイル名でも見出しでもなく ID（[AX] 等）を引く。ID が安定する限り、tier やレイアウトは自由に変えてよい。
- **便利な定義は T-D に置き、本文書は参照する。** ■3 は manifest（どの語を使うか・解像度の目安・定義の所在）であって定義本体ではない。
- 本構造自体、T0 を B＝ヘッダ用途で分解した M_B であり、追従運用で引き直す。反例が出たら割り当て側を更新する。

## ■ 1. 根（irreducible・二項）

**[AX] 限界空間**
任意の境界 B による閉包操作に対して、必ず未回収関係 ξ が残る。
*解説→ 限界空間_解説.md*

**[SILN] SILN**
構造は、関係の中で一時的に安定したパターン（M_B）である。
SILN ＝ *Survival-biased Integration of Local Linear approximations in a Nonlinear Network*（非線形ネットワークにおける局所線形近似の生存バイアス的積分）。M_B は SILN を B 下で扱うために仮設された整合慣性、すなわち B 依存の操作表現である。
*解説→ SILN_解説.md*

> 二根は相補。[AX]＝漏れる側（ξ・任意の B が取りこぼす・限界）、[SILN]＝保つ側（M_B・整合慣性・安定）。B は両者を生む共通の操作であり、irreducible な動詞（根の名詞ではない）。
> [SILN] の "Nonlinear Network" は [AX] を内包する非線形な関係構造を指す。これは世界を消す変更ではなく、RDL から見た世界を、固定容器ではなく相互接続された関係ネットワークとして記述する精度更新である。

## ■ 2. 定理（操作しようとすると出る）

操作（B を引く・分解する・記述する）を試みた瞬間、根から強制的に立ち上がる claim。

**[P1]** 観測＝B 設定。観測・認識・記述には、対象・範囲・尺度・語彙・差異の選択（B）が要る。B なしに観測は成立しない。

**[EQ]** B 設定 → M_B ＋ ξ。B を引くと、捕れた分（M_B：SILN の B 依存的な操作表現）と捕れない残差（ξ）が同時に出る。局所線形近似で非線形ネットワークをパッチする以上、剰余は必ず残る。

**[RMB]** 関係性最小基底。記述可能な最小単位は孤立実体ではなく、B が切り出した関係構造（＋ξ）である。操作の最小＝B 設定（irreducible）、記述単位の最小＝関係性。本基底も弱い暫定普遍。

**[HYP]** 仮設。対象に直接到達できないため、限界空間内の操作（観測・認識・記述・分類・計算など）はどれも対象到達ではなく F からの逆算であり、その出力は確定ではなく仮設としてのみ安定運用できる。仮設は観測や計算と並ぶ別操作ではなく、あらゆる操作が走る様式である。確定できない → 仮設する → 引き直せる → 閉じない → 生きている。

**[MET]** 形而上空間＝限界空間的構造破壊ゲート（[GATE]）を通れないラベルの移動先。[GATE] の判定は「そのラベルは仮設として運用できるか＝引き直せる／反例で更新されるか」。限界空間ではあらゆるラベル（ξ・EFP・𝒦・F・M_B …）が解像度の差はあれ仮設として扱え、[GATE] を通る。あるラベルを絶対化・確定化した瞬間、それは引き直しを拒否し、[GATE] を通れず形而上空間へ移る。ゆえに形而上空間は特定の物の置き場ではなく、確定化されたラベルが移る先＝[GATE] の補集合である（[AX] が禁じるのは ξ=0 という物ではなく、確定化という操作）。限界空間と形而上空間は上下ではなく所属の区分で、形而上は劣位ではない（扱えないだけ）。
同じラベルでも扱い方で所属が変わる：ξ を仮設として運用する（残差を仮置きして場を回す）のは限界空間内のど真ん中の作業だが、「ξ=0 だ／ξ をゼロにできる」と確定した瞬間（＝完全閉包の主張）は形而上へ移る。移るのは ξ という物でも ξ を使うことでもなく、ξ=0 という確定操作。絶対基底・全知全能・実体は、確定が語義に焼き付いて仮設へ戻せない縮退ケースで、書いた時点で既に形而上側にある。

**[DOC]** 文書性。文書＝多次元関係構造の線形圧縮であり、全文書は近似ラベル。これは [AX] の言語担体での断面（ξ残存性・SILN 分解の再帰性と同一構造）。

> 吸収：旧 [P2]（任意の B に ξ が残る）＝[AX]、旧 [P3]（構造は M_B）＝[SILN]。両者は根に畳まれた。

*解説：[P1][EQ][RMB] → 限界空間_解説.md ／ [HYP] → 仮設_解説.md ／ [MET]・[GATE]（確定化判定・形而上は従属節） → 限界空間的構造破壊ゲート解説.md ／ [DOC]（補完循環・三者認知系） → 文書性_解説.md*

## ■ 3. 便利な定義（term・仮設すると便利・定義本体は T-D）

T0 の claim が書かれる語彙。発見された定義ではなく、仮設すると操作が成立する posit。すべて仮設として運用され（解像度は異なる）、限界空間内にある。確定化したラベルは形而上空間へ移る（[MET]）。定義本体は T-D 語句定義にあり、ここは manifest（使用語・解像度の目安・所在）。

```text
仮設ラベル（解像度の差はあれ全て仮設・限界空間内）：
  B（境界＝irreducible な操作）, M_B（整合慣性＝SILN の B 依存操作表現）, F（作用解釈）,
  E（慣性誤差）, H（熱・派生量）, 相状態{M_act/M_lat/M_Δ/M_B'},
  ξ（揺らぎ・閉じなさ）, EFP（素流圧）, 𝒦（関係保存則の不変量）
  ※ いずれも仮設としての運用は限界空間内。絶対化・確定化した扱い
    （例：ξ=0 と置く／「客観的」＝観測者非依存の絶対視点を主張する）
    だけが形而上空間へ移る。固定属性ではなく扱い方。
```

*定義本体・展開→ T-D 限界空間的語句定義*
