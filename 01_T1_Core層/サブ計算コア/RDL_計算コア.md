## ■ 1. 次元削減（局所近似）

```
M_B(t) ≈ V_k Λ_k V_k^T
dΛ_k/dt = f(Λ_k, V_k^T F(t), V_k^T ξ(t))
D[V_k^T ξ] = 𝒦 / ||Λ_k||
```

---

## ■ 2. 跳躍の共鳴条件

```
F(t) · H(t) > θ_leap
```

素流圧と蓄積熱の内積的共鳴が閾値を超えると M_Δ 相へ遷移。

---

## ■ 3. SILNネットワーク拡張

```
dM_B^(i)/dt = f(M_B^(i), F^(i) + Σⱼ W_{ij} M_B^(j), ξ^(i))
D[ξ^(i)] = 𝒦^(i) / ||M_B^(i)||
```

跳躍定着条件：

```
M_B'^(i) が隣接 M_B^(j) と共鳴
→ より広い B で安定パターンとして定着
→ 𝒦^(i) が上位 SILN へ引き継がれる
```

---

## ■ 4. RDL-GR（大スケール・幾何構造）

```
ℛ[R_{μν}] + Λ_R R_{μν}
= λ J^{(M_B)}_{μν} + η J^{(ξ)}_{μν} + ζ J^{(F)}_{μν}

J^{(M_B)}_{μν} : 整合慣性分布
J^{(ξ)}_{μν}   : 揺らぎ分布
J^{(F)}_{μν}   : 素流圧流束
```

アインシュタイン方程式は J^{(ξ)} 項を無視した近似。

---

## ■ 5. NAM（安定・低負荷近似）

適用条件：

```
D[ξ] ≈ 0 / H << θ / M_Δ 遷移なし / 関係構造ほぼ平坦
```

基本式：

```
m d²x/dt² + γ dx/dt = F(x,t)
```

GR → NAM 還元：

```
弱歪み・低速・低揺らぎ条件：
Φ(x) ≈ ||M_B(x)||
m d²x/dt² = -∇Φ(x)
```

---

## ■ 6. モジュール切替指針

```
大スケール・幾何効果が支配的 → RDL-GR（■9）
D[ξ] < ε かつ H << θ       → NAM（■10）
それ以外                    → Base Model（■1-5）
```
