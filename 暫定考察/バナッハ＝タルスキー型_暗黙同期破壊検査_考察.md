## ■ 0. この文書の位置づけ

本稿は、バナッハ＝タルスキーのパラドックスそのものを数学的に証明・再構成する文書ではない。

目的は、同パラドックスに現れる構造をRDL的に抽出し、

**「通常は一体として扱われている複数の性質を、極端な境界条件によって分離する構造破壊検査」**

として利用できないかを考察することである。

現段階では検査法として確立していないため、正式な構造破壊学モジュールではなく、道具化前の案として保持する。

---

## ■ 1. 出発点

バナッハ＝タルスキーのパラドックスでは、数学的な三次元球を有限個の集合へ分割し、それらを回転・平行移動によって再配置することで、元の球と同じ大きさの球を二つ構成できる。

ここで重要なのは、

```text
球1個
→ 物理的に切断
→ 材料が増加
→ 球2個
```

という現象ではない。

使用される分割片には通常の体積を割り当てられないものが含まれる。

したがって、

```text
部分の体積を加算
=
全体の体積
```

という通常成立している操作そのものが、その分割に対して適用不能になる。

---

## ■ 2. RDL的な第一読解

通常、われわれが「球」と呼ぶ対象には複数の性質が重なっている。

```text
X_ball := {
  集合としての球,
  幾何学的形状としての球,
  体積を持つ対象,
  部分の体積の和が全体になる対象,
  剛体移動によって体積が保存される対象
}
```

日常的・通常数学的な範囲では、これらは非常に強く同期している。

そのため、

```text
集合として同じ対象
≈
体積を持つ対象
≈
加法的に測定可能な対象
```

として一つの概念に圧縮されやすい。

しかしバナッハ＝タルスキー型の条件では、この同期が外れる。

```text
集合として扱える
∧
剛体移動できる
∧
再構成できる

しかし

通常の体積を割り当てられる
= false
```

したがって、

```text
「球」という単一概念の破綻
```

というより、

```text
「球」の内部で暗黙に同期していた
複数のM_Bの分離
```

として読むことができる。

---

## ■ 3. Bによる表現

通常の体積操作が成立する境界を仮に、

```text
B_vol :=
  通常の測度によって体積を扱える対象領域
```

とする。

その内部では、

```text
M_Bvol := {
  体積の存在,
  有限加法性,
  剛体移動による不変性,
  部分と全体の整合
}
```

が比較的強く同期する。

しかし境界を拡張し、非可測集合を許すと、

```text
B_vol → B_ext
```

となり、

```text
集合操作可能性      : survive
剛体移動可能性      : survive
再構成可能性        : survive
通常測度による体積  : break
```

という分離が生じる。

RDLの基底形、

```text
B → M_B + ξ
```

から見るなら、これは

```text
通常のBでは背景化していたξが、
Bの拡張によって構造差として露出した
```

例として扱える可能性がある。

## ■ 4. 中心仮設

本稿で抽出する中心仮設は次である。

> **パラドックスの一部は、世界そのものの矛盾ではなく、通常状態では同期しているため同一視されていた複数の構造が、境界条件の変更によって分離した結果として現れる。**

圧縮すると、

```text
通常：
P1 ≈ P2 ≈ P3 ≈ ... ≈ Pn

B → B'

↓

P1 survive
P2 survive
P3 break
...

↓

暗黙同期の分離
```

である。

ここで重要なのは、

```text
Pi = 同一
```

だったのではなく、

```text
Corr_B(Pi, Pj) ≫ 0
```

だった可能性である。

---

## ■ 5. 暗黙同期

仮に対象 `X` が次の属性束を持つとする。

```text
X_B = {P1, P2, ... , Pn}
```

通常環境では、

```text
Corr_B(Pi, Pj) ≈ high
```

であるため、観測者は

```text
Pi ≈ Pj
```

あるいは

```text
Pi ⇒ Pj
```

として扱いやすい。

しかし、この関係が

```text
必然的結合
```

なのか、

```text
通常環境で壊れにくいだけの同期
```

なのかは、通常条件だけを観測していても判別しにくい。

そこで、意図的に `B` を変形する。

```text
B → B_extreme
```

その結果、

```text
Pi survives
Pj breaks
```

ならば、

```text
Pi ≠ Pj
```

かつ、

```text
Pi → Pj
```

も無条件には成立しないことが露出する。

## ■ 6. 暗黙同期破壊テスト

この構造を一般化すると、暫定的に次の検査形式を置ける。

### Step 1：概念束を抽出する

対象 `X` に対して、通常まとめて扱われている性質を列挙する。

```text
X_B = {P1, P2, ... , Pn}
```

---

### Step 2：暗黙同期を探す

明示的な定義ではないにもかかわらず、

```text
P1なら当然P2
P2なら当然P3
```

と扱われている接続を抽出する。

```text
W_ij := apparent-coupling(Pi, Pj)
```

---

### Step 3：Bを極端化する

通常状態では成立しにくい条件を導入する。

```text
B → B'
```

目的は対象を壊すことそのものではなく、

```text
PiとPjの結合が
本当に不可分なのか
```

を検査することにある。

---

### Step 4：残存性を比較する

```text
Survive(Pi, B')
Break(Pj, B')
```

を観測する。

結果を、

```text
維持
弱化
再定義必要
適用不能
破断
```

などへ分類する。

---

### Step 5：W_ijを引き直す

分離可能だった場合、

```text
W_ij : 必然
```

としていた接続を、

```text
W_ij : B依存
```

へ降格する。

あるいは、

```text
Pi
  ↓
Pk
  ↓
Pj
```

のような隠れた媒介SILNを追加する。

---

### Step 6：ξとして保持する

なぜ通常状態では強く同期していたのか説明できない場合、それを無理に補完しない。

```text
ξ_sync := 未解明な同期条件
```

として保持する。

## ■ 8. 構造破壊学との関係

本検査は、対象そのものを直接破壊するというより、

```text
対象について
「同じものだと思っていた関係」
```

を破壊対象とする。

したがって、

```text
通常の破壊検査：
  Xの耐久性を見る

暗黙同期破壊：
  Xを構成する属性間W_ijの耐久性を見る
```

という違いがある。

特に、

```text
X survives
but
W_ij breaks
```

を検出できる可能性がある。

これは対象全体が壊れる前に、

```text
概念内部の結合誤認
```

を検出する操作として利用できる。

## ■ 9. 圏論的構造破壊検査との暫定的差異

既存の圏論的構造破壊検査が、

```text
合成可能性
可換性
関手保存
自然変換
極限
```

など、構造間の写像・接続保存を見る検査だとすれば、

本検査は、

```text
一つの概念内部で
暗黙に束ねられていた属性を
分離可能か検査する
```

ことを主目的とする。

したがって両者は競合せず、

```text
暗黙同期破壊
    ↓
属性を分離

圏論的構造破壊
    ↓
分離後の関係・写像を検査
```

という連携も考えられる。

ただし、この接続は現段階では仮設である。

## ■ 12. 禁止補完

現段階では、以下を主張しない。

```text
× バナッハ＝タルスキーをRDLが説明した

× RDLからバナッハ＝タルスキーが導出できる

× すべてのパラドックスは暗黙同期破壊で説明できる

× 非可測集合 = ξ である

× 数学的Bと物理的Bは同一である
```

特に、

```text
ξ
```

と数学上の非可測性を同一視してはならない。

本稿で行っているのは、

```text
非可測性が露出する構造
```

をRDL操作の着想源として借用することである。

## ■ 13. 破断条件

本仮設は、少なくとも次の場合に破断または再設計を必要とする。

### B1

属性分離を行っても、新しい情報が一切得られず、

```text
通常の定義展開
```

以上の機能を持たない場合。

### B2

どの対象にも任意に属性を設定できるため、

```text
何でも分離できる
```

だけの空操作になった場合。

### B3

`B → B'` の選択が恣意的すぎて、検査結果を任意に作れる場合。

### B4

既存の構造破壊学・圏論的構造破壊検査によって完全に代替可能であり、独立した操作価値を持たない場合。

### B5

「暗黙同期」という概念自体が観測可能な操作単位として定義できない場合。
