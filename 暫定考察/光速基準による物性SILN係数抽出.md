## ■ 0. 目的と位置づけ

本稿は、水、鉄、空気などの物性をRDL語彙へ翻訳し、比較・係数探索・シミュレーションへ渡すための暫定的な係数抽出形式を考察する。

光速 \(c\) は、各物質の運動速度を表すためではなく、異種の物性を同じ無次元座標へ配置するための共通参照として借用する。

ただし、ここで構成する量の一部は、既存無次元数の速度尺度を \(c\) に置き換えた形と重なる。本稿の新規性候補は、個々の無次元数そのものではない。

> \(c\) 基準の共通座標を、ノード・接続・動態からなるRDL三層係数へ再配置し、各係数に**由来**を付け、残差を**階層化**して \(\xi\) 候補と既知構造を分離すること

にある。

```text
既存物性
    ↓ RDL語彙への翻訳
c基準の共通座標
    ↓ 由来タグ付与
[層1] ノード係数
[層2] 接続係数
[層3] 動態係数
    ↓ 残差階層化
ξ候補の分離
    ↓
物質SILNの比較・探索・移植
```

本稿は、旧考察「光速基準による物性RDL係数化」で見つかった破断点を受け、三層構造を中心に新規作成したものである。旧考察を置換せず、思考履歴として並置する。

## ■ 1. 観測境界と状態変数

物性値は、物質に固定された単一値ではない。

温度、圧力、相状態、周波数、観測時間、代表長さ、結晶方向、測定モードなどによって変化する。そこで、観測境界 \(B\) に属する状態変数をまとめて、

\[
S_B
:=
(T,P,\phi,\omega,\tau,L_B,\mathbf n,m,\ldots)
\]

と置く。

ここで、

- \(T\)：温度
- \(P\)：圧力
- \(\phi\)：相状態
- \(\omega\)：観測周波数
- \(\tau\)：観測時間尺度
- \(L_B\)：代表長さ
- \(\mathbf n\)：結晶方向・観測方向
- \(m\)：波動・変形などの観測モード

である。

以後、物質 \(X\) の係数は、

\[
\mathfrak C_B(X;S_B)
\]

として記述する。

```text
物性値 = 物質ラベルだけでは決まらない
物性値 = F(X, B, S_B)
```

## ■ 2. 光速 \(c\) の位置づけ

本稿における \(c\) は、限界空間の外部に置かれた絶対基準ではない。

\[
c
:=
\text{相対論SILN（ST）が与える、広域的に共有可能な参照係数}
\]

とする。

相対論SILNは極めて硬い物理記述として働くが、RDLの外部にある最終基底ではない。したがって、\(c\) 自体も適用範囲と破断条件を持つ仮設ラベルとして扱う。

\(c\) 基準の役割は、新しい情報を物性へ加えることではなく、次の操作を可能にすることにある。

1. 異種物性を同じ無次元座標へ配置する  
2. 単位系・シミュレーションごとの基準選択を減らす  
3. 各物質の絶対位置と、物性間の内部関係を分離する  
4. 係数形式を異なる実装間で移植しやすくする  
5. 既存無次元数群を、共通座標の異なる射影として比較する  

成分間の比を取れば、\(c\) が消える場合がある。これは欠陥とは限らない。

```text
cが残る     ：共通空間における絶対位置
cが消える   ：物質SILN内部の相対関係
```

したがって、\(c\) は物性間の関係を直接生成する係数ではなく、関係を載せる座標の基準として働く。

## ■ 3. 物性値のRDL語彙への暫定翻訳

| 物理特性 | RDL的な読み |
|---|---|
| 密度 \(\rho\) | 状態変更に対する慣性量 |
| 体積弾性率 \(K\) | 圧縮変形に対する整合回復結合 |
| 剛性率 \(G\) | せん断変形に対する整合回復結合 |
| ヤング率 \(E\) | 長さ方向の関係維持強度 |
| 粘度 \(\eta\) | 差分を散逸・熱化する抵抗 |
| 動粘度 \(\nu\) | 運動差分の再配分速度 |
| 熱拡散率 \(a_T\) | 熱差分の再配分速度 |
| 表面張力 \(\gamma\) | 境界 \(B\) を縮小・維持する結合傾向 |
| 降伏応力 \(\sigma_y\) | 既存構造を保った可逆・準可逆変形の限界 |
| 破壊応力 \(\sigma_f\) | 既存結合網が維持不能となる閾値 |
| 融点・沸点 | \(M_B\rightarrow M_\Delta\rightarrow M_B'\) の相転移条件 |
| 波動速度 \(u_m\) | 観測モード \(m\) における局所整合伝播速度 |

この翻訳は同一性主張ではない。

たとえば、弾性率をそのまま \(W_{ij}\) と同一視するのではなく、観測境界内で抽出された「整合回復結合の指標」として扱う。

## ■ 4. 三層係数構造

物質SILNの係数記述を、次の三層に分ける。

\[
\boxed{
\mathfrak C_B(X;S_B)
=
\left\langle
\mathcal N_B,\,
\mathcal W_B,\,
\mathcal D_B
\right\rangle
\ ;\ \xi_B
}
\]

ここでセミコロンは、\(\xi_B\) が三層係数と同じ座標空間の成分ではないことを示す。

```text
𝒩_B ：ノードが現在持つ係数
𝒲_B ：係数間・構成要素間の接続
𝒟_B ：係数の変化・蓄積・跳躍
ξ_B ：この記述へ収まらない残存構造
```

### 4.1 [層1] ノード係数

物質 \(X\) の現在状態を表す暫定ベクトルを、

\[
\mathcal N_B(X;S_B)
=
\left(
\frac{u_m}{c},
\frac{K}{\rho c^2},
\frac{G}{\rho c^2},
\frac{E}{\rho c^2},
\frac{\sigma_y}{\rho c^2},
\frac{\sigma_f}{\rho c^2},
\frac{\eta}{\rho cL_B},
\frac{\nu}{cL_B},
\frac{a_T}{cL_B},
\frac{\gamma}{\rho c^2L_B}
\right)
\]

と置く。略記として、

\[
\kappa_{u,m}:=\left(\frac{u_m}{c}\right)^2,\qquad
\kappa_K:=\frac{K}{\rho c^2},\qquad
\kappa_G:=\frac{G}{\rho c^2},\qquad
\kappa_E:=\frac{E}{\rho c^2}
\]

を用いる。

これは物質SILN全体ではなく、ある時点・ある条件におけるノード係数群である。

各成分は独立とは限らない。等方弾性体では \(\{K,G,E\}\) のうち独立なのは二つであり、

\[
E=\frac{9KG}{3K+G}
\]

が成り立つ。したがって \(\kappa_E\) は他成分から算出できる。独立性・依存関係の記述は層2が担う。

### 4.2 由来タグ（v0.2 新設）

\(\mathcal N_B\) の各成分には、**その値がどこから来たか**を付す。これがないと、後述する残差階層が構造的に空回りする。

\[
q_i^{[\mathrm{src}]},\qquad
\mathrm{src}\in\{\mathrm{MEAS},\mathrm{DERIV},\mathrm{POSIT}\}
\]

```text
MEAS   ：独立に測定された値
DERIV  ：層2の構成式から他成分を使って算出された値
POSIT  ：当該データへの当てはめで決めた値（仮設係数）
```

**なぜ必要か。**

残差は、二つの経路で得た同じ量を比較して出す。しかし比較する二経路がともに DERIV であれば、両者は同一の構成式に閉じているため、差は恒等的にゼロになる。

```text
MEAS × MEAS   → 情報あり（構成式検査＋測定系統差）
MEAS × DERIV  → 情報あり（構成式そのものの検査）
DERIV × DERIV → 恒等的にゼロ（情報なし）
POSIT を含む  → 循環（■5.3 のガードを要する）
```

例：等方弾性体で \(u_p\) を \(K,G,\rho\) から算出した場合、\(\kappa_{u,p}\) は DERIV となり、後述の一次残差 \(r_p^{(1)}\) は定義上ゼロになる。\(r_p^{(1)}\neq0\) が意味を持つのは \(u_p\) が MEAS のときだけである。

したがって、**由来タグの記録は残差計算の前提条件**であり、任意の付加情報ではない。

```text
釘：由来タグのない 𝒩_B から出した残差は、
    「差がゼロだった」のか「構造的にゼロにしかならない」のかを区別できない
```

### 4.3 [層2] 接続係数

層2は、層1成分の間にある構成関係、依存関係、モード変換を保持する。

\[
\mathcal W_B
=
\left\{
C_{ij},\,
F_m,\,
R_{ij},\,
\partial_{q_j}q_i,\,
\mathrm{dir}_{ij},\ldots
\right\}
\]

- \(C_{ij}\)：構成要素・係数間の接続強度
- \(F_m\)：観測モードごとの構成式
- \(R_{ij}\)：比・拘束・保存関係（無次元不変量を含む）
- \(\partial_{q_j}q_i\)：ある係数変化に対する別係数の感度
- \(\mathrm{dir}_{ij}\)：**導出の向き**（どちらを MEAS とし、どちらを DERIV とするか）

\(\mathrm{dir}_{ij}\) は v0.2 で新設した。層2は「何が何と繋がっているか」だけでなく「**どちらからどちらを算出したか**」を持たないと、由来タグを一貫させられない。

等方弾性体の波動を例にすると、

\[
u_p^2
=
\frac{K+\frac43G}{\rho},
\qquad
u_s^2
=
\frac{G}{\rho}
\]

であるため、\(c\) 基準では、

\[
\kappa_{u,p}
=
\kappa_K+\frac43\kappa_G,
\qquad
\kappa_{u,s}
=
\kappa_G
\]

となる。これは層2の構成式 \(F_m\) であり、同時に \(\mathrm{dir}\) の候補を三通り与える。

```text
dir-A ： K,G を MEAS → u_p,u_s は DERIV
dir-B ： u_p,u_s を MEAS → K,G は DERIV
dir-C ： 両方 MEAS（静的測定と動的測定の独立取得）
```

**残差が取れるのは dir-C だけである。** dir-A・dir-B では \(r^{(1)}\equiv0\)。

また、

\[
\frac{\nu/(cL_B)}{a_T/(cL_B)}
=
\frac{\nu}{a_T}
\]

のように、成分間関係では \(c\) が消える。この比は、共通座標上の位置ではなく、物質SILN内部の接続形状を表す。こうした \(c\) 消去型の不変量は \(R_{ij}\) に属する。

### 4.4 [層3] 動態係数（最小形式）

層3は、状態変数の変化、誤差蓄積、破断、相転移を扱う。記号を並べるだけでは運用できないため、**測定手続きが書ける最小形式**を四要素に絞る。

\[
\boxed{
\mathcal D_B^{\min}
=
\left(
J_B,\;
h_B,\;
\Lambda_B,\;
\mathcal T_B
\right)
}
\]

#### 4.4.1 感度行列 \(J_B\)

\[
J_B
:=
\frac{\partial\mathcal N_B}{\partial S_B}
\]

\(\mathcal N_B\) の各成分を状態変数で偏微分した行列。\(S_B\) を刻んで層1を再取得すれば数値微分で取れる。

由来条件：\(J_B\) は MEAS 成分から取る。DERIV 成分の感度は構成式の微分に過ぎず、新しい情報を持たない。

#### 4.4.2 残差蓄積 \(h_B\)

\[
h_B(t)
:=
\int_0^t \left\|r^{(1)}(t')\right\|\,dt'
\]

層2の構成式が予測する値と実測の差（一次残差、■5.2）の時間積分。

これは RDL_Core の \(H\) 蓄積と同型である。物理担体では、繰り返し負荷下での疲労蓄積・塑性蓄積に対応する。

```text
RDL_Core     ： E の蓄積 → H → 跳躍
物性担体     ： r^(1) の蓄積 → h_B → 破断
```

\(h_B\) は「弾性構成式がまだ成立しているか」を連続的に測る量として読む。

#### 4.4.3 維持限界 \(\Lambda_B\)

\(S_B\) 空間内で、現在の \(\mathcal N_B\) と \(\mathcal W_B\) が維持できなくなる境界。三つの検出窓で捕らえる。

```text
窓1 成分消失 ： ある κ_i → 0（観測モードが失われる）
               例：融解で κ_G → 0、κ_{u,s} が定義不能になる

窓2 感度発散 ： |∂κ_i/∂S_B| → ∞
               例：臨界点近傍での κ_K・κ_γ

窓3 構成式破れ： h_B が既定域を超える／r^(1) が急増する
               例：降伏（弾性構成式の失効・塑性領域への移行）
```

三窓はいずれも層1・層2の量だけで判定でき、外部から閾値を持ち込まない。窓3は層2の残差を層3の駆動量として使う点で、\(\mathcal W_B\) と \(\mathcal D_B\) を接続する。

#### 4.4.4 遷移写像 \(\mathcal T_B\)

\(\Lambda_B\) を越えた前後を結ぶ写像。単一の対応ではなく、成分の三分割として記録する。

\[
\mathcal T_B:\;
\mathcal N_B^-\;\longmapsto\;
\left(
\mathcal N^{\mathrm{keep}},\,
\mathcal N^{\mathrm{lost}},\,
\mathcal N^{\mathrm{new}}
\right)
\]

```text
keep ： 定義も接続も保たれる成分（値は変わってよい）
lost ： 定義が失われる成分
new  ： 遷移後に初めて意味を持つ成分
```

例：固体 → 液体（融解）

```text
keep ： κ_K, κ_{u,p}, κ_{a_T}
lost ： κ_G, κ_{u,s}, κ_{σ_y}, κ_{σ_f}
new  ： κ_η, κ_ν, κ_γ（表面張力が支配的接続として立ち上がる）
```

この三分割は構造破壊学の「破断・残存・移植」と同型である。層3を独自形式にせず、構造破壊学の書式へ返せる形にしてある。

```text
層1：今どの状態か
層2：何が何を支えているか、どちらから算出したか
層3：どのように変わり、どこで跳び、何が残るか
```

## ■ 5. 残差の階層化と \(\xi\) 候補

観測値の差を、直ちに \(\xi\) と同一視してはならない。

差には、単位・モード・既知構成式・状態条件の不一致が含まれる。したがって、残差を段階的に処理する。

### 5.1 生残差

単純な比較差を、

\[
r_m^{(0)}
=
\kappa_{u,m}-\kappa_K
\]

とする。

これは診断の入口にはなるが、異なるモード定義を混ぜている可能性がある。

### 5.2 構成式補正後の一次残差

等方弾性固体の縦波では、

\[
r_p^{(1)}
=
\kappa_{u,p}
-
\left(
\kappa_K+\frac43\kappa_G
\right)
\]

横波では、

\[
r_s^{(1)}
=
\kappa_{u,s}-\kappa_G
\]

とする。

流体では \(G\approx0\) の近似下で \(\kappa_u\approx\kappa_K\) となるため、単純モデル内の差は原理的に小さくなる。

**由来条件（v0.2 明示）**

\[
\boxed{
r^{(1)}\ \text{が情報を持つのは}\ \mathrm{dir}\text{-C（両経路 MEAS）のときに限る}
}
\]

dir-A・dir-B では \(r^{(1)}\equiv0\) であり、これは「差がなかった」ではなく「差が出ない構成になっている」ことを意味する。両者を混同すると、構成式の妥当性を確認したつもりで自分の定義を確認しただけになる。

```text
r^(1) = 0 の二つの読み

(a) dir-C で測って差が出なかった
    → 構成式が当該条件で耐えている（情報あり）

(b) dir-A/B で算出した
    → 恒等式を確認しただけ（情報なし）

由来タグがないと (a) と (b) は区別できない
```

### 5.3 既知要因補正後の二次残差と事前登録ガード

異方性、温度依存、周波数依存、既知の粘弾性、測定系統差など、現在のSTで記述済みの項を、

\[
r_m^{\mathrm{known}}
\]

として差し引く。

\[
\boxed{
r_m^{(2)}
=
r_m^{(1)}
-
r_m^{\mathrm{known}}
}
\]

**ガード（v0.2 新設）**

\(r^{\mathrm{known}}\) を当該データに合わせて当てはめると、\(r^{(2)}\) は任意にゼロへ潰せる。これは ■6 が禁じている「残差の圧殺」が手順の内側に入り込む経路である。文言による禁止では止まらないため、書式で塞ぐ。

```text
r^known に入れてよいもの：
  当該データセットの外で、事前に確定された係数のみ
  （出典・測定条件・確定時点を併記する＝事前登録）

r^known に入れてはいけないもの：
  当該データへのフィットで決めた項
  → r^known ではなく 𝒩_B の POSIT 成分として層1に記録する
  → 「説明した」ではなく「当てはめた」として残す
```

事前登録された \(r^{\mathrm{known}}\) の一覧は、係数セットに添付して移植する。添付がない係数セットの \(\xi^{\mathrm{cand}}\) は、値として比較できない。

### 5.4 \(\xi\) 候補と \(\xi_B\) の関係

二次残差を、

\[
\boxed{
\xi_m^{\mathrm{cand}}
:=
r_m^{(2)}
}
\]

として保持する。

ただし、これは \(\xi\) そのものの確定ではない。現在の \(B\) とSTでは説明できない構造の**候補**である。

さらに、\(\xi^{\mathrm{cand}}\) と \(\xi_B\)（■4 の、この記述へ収まらない残存構造）は同一ではない。

```text
ξ^cand ⊊ ξ_B

ξ^cand ： 現在の B と ST で検出できた ξ_B の影
ξ_B    ： 検出手続きの外に残るものを含む全体

ξ^cand を全て説明しても ξ_B は消えない（[AX]）
```

\(\xi^{\mathrm{cand}}\) がゼロになったとき、それは「この \(B\) の解像度では \(\xi\) が粒度以下に潜った」ことを示すのであって、\(\xi=0\) ではない。後者は確定化であり、[GATE] を通らない。

```text
差がある
    ≠ ξである

既知構造を引いても差が残る
    → ξ候補として保持
    → B・ST・接続係数・由来タグを再検査

ξ候補がゼロになった
    ≠ ξがない
    → 解像度が足りていない可能性を先に見る
```

## ■ 6. 係数探索

未知係数 \(\theta_X\) の探索では、RDL_Coreの \(H\) と衝突しないよう、損失関数には \(\mathcal L\) を用いる。

\[
\theta_X^\ast
=
\arg\min_{\theta_X}
\left[
\mathcal L_{\mathrm{node}}
+
\mathcal L_{\mathrm{connection}}
+
\mathcal L_{\mathrm{dynamic}}
+
\lambda\mathcal L_{\mathrm{complexity}}
\right]
\]

- \(\mathcal L_{\mathrm{node}}\)：物性値そのものの再現誤差
- \(\mathcal L_{\mathrm{connection}}\)：構成式・接続関係の不整合
- \(\mathcal L_{\mathrm{dynamic}}\)：温度変化・破断・相転移軌道の予測誤差（\(J_B\)・\(\Lambda_B\)・\(\mathcal T_B\) の再現）
- \(\mathcal L_{\mathrm{complexity}}\)：過剰な補助係数の導入

探索で決まった \(\theta_X\) は POSIT である。■5.3 のガードにより、これを \(r^{\mathrm{known}}\) へ流用してはならない。

採用する係数は、残差を完全にゼロへ押し込む値ではない。

> 複数条件を横断して三層構造を安定して再現し、説明不能な残差を不自然に圧殺しない値

を暫定係数とする。

## ■ 7. 既存無次元数との関係

本稿のノード係数には、既存無次元数と重なる形が含まれる。

\[
\frac{\nu}{cL_B}
\]

は、速度尺度を \(c\) とした逆Reynolds数型である。

\[
\frac{u}{c}
\]

は、通常のMach数で用いる局所音速を、相対論SILNの参照速度へ置き換えた比である。

\[
\frac{\gamma}{\rho c^2L_B}
\]

は、速度尺度を \(c\) とした逆Weber数型の形を持つ。

したがって、検査では各成分を次の三種に分ける必要がある。

```text
A：既存無次元数と同値
B：速度・長さ尺度をc基準へ置換したもの
C：RDL三層接続によって初めて意味を持つもの
```

現時点での暫定分類：

```text
A ： ν/a_T（Prandtl型・R_ij に属する c消去不変量）
B ： u/c, ν/(cL_B), γ/(ρc²L_B), K/(ρc²) など層1の大半
C ： 由来タグ付き r^(1)、h_B、Λ_B の三窓、𝒯_B の keep/lost/new 三分割
```

本稿の価値が成立するとすれば、主に B と C を統合し、異なる物質・異なる実装の間で同じ係数形式を保持できる点にある。

## ■ 8. 質量スケーリング除去による結合残差の検査仮設

〔ST注意：本節は即席概算に基づく未検証仮設である。数値は代表値であり、独立検証を要する。〕

**層帰属**：本節の \(\Theta_X\) は層1の完成係数ではない。層1の値（\(\kappa_K\)）と外部定数から作られ、層2の結合様式ラベルを探索する量であるため、\(\mathcal W_B\) の \(R_{ij}\) 系（\(c\) を含む定数を消去した不変量）に属する検査係数候補として置く。

### 8.1 規範的縮尺

凝集物質の弾性率が主として電磁的結合に由来すると仮設すると、

\[
K\sim\frac{\mathrm{Ry}}{a^3},
\qquad
\rho\sim\frac{M_X}{a^3}
\]

（\(a\)：代表原子間距離、\(\mathrm{Ry}=\alpha_{\mathrm{fs}}^2m_ec^2/2\)）となるため、

\[
\kappa_K
=
\frac{K}{\rho c^2}
\sim
\frac{\mathrm{Ry}}{M_Xc^2}
=
\frac{\alpha_{\mathrm{fs}}^2}{2}\cdot\frac{m_e}{M_X}
\]

を得る。

ここで **\(a^3\) が比で消える**点が重要である。この規範値は原子間距離に依存しない。したがって、規範値からのズレをサイズ効果として説明することはできず、結合様式・構造配置の側へ帰属せざるを得ない。

### 8.2 検査係数 \(\Theta_X\)

規範的縮尺を除いた残差を、

\[
\boxed{
\Theta_X
:=
\kappa_K
\frac{M_X/m_e}{\alpha_{\mathrm{fs}}^2}
}
\]

と置く。8.1 より、規範値は

\[
\Theta_X\sim\frac12
\]

である。この \(1/2\) は当てはめではなく Rydberg の定義から出る。したがって \(\Theta_X\) が \(0.5\) 近傍に集まることは、一致の観測であって適合の結果ではない。

### 8.3 凝集物質の暫定概算

| 物質 | 相 | \(\kappa_K\)（概算） | \(\Theta_X\) |
|---|---|---:|---:|
| ダイヤモンド | 共有結合固体 | \(1.40\times10^{-9}\) | 0.58 |
| 鉄 | 金属結合固体 | \(2.40\times10^{-10}\) | 0.46 |
| アルミニウム | 金属結合固体 | \(3.13\times10^{-10}\) | 0.29 |
| 水 | 水素結合液体 | \(2.45\times10^{-11}\) | 0.015 |

共有結合・金属結合固体が規範値 \(0.5\) の近傍（0.29〜0.58）に集まり、水素結合液体で約1.5桁下がる。

### 8.4 気体は同じ表に載らない

気体を上表へ加えることはできない。理由は比較可否ではなく、**量の種類が違う**ことにある。

```text
凝集物質： K は結合網が与える。S_B 依存は弱い
気体    ： K = γP。S_B の P が値を全て決める

→ Θ_gas は物質識別量ではなく、S_B 依存量である
→ 同一の列に置くと「Θ が物質を識別する」という読みが崩れる
```

参考値として \(P=1\,\mathrm{atm}\) の空気は \(\kappa_K\approx1.3\times10^{-12}\)、\(\Theta\approx0.0013\) となるが、これは **\(S_B\) 付きでのみ意味を持つ数**であり、上表とは別カテゴリに置く。

### 8.5 未確定項

- \(M_X\) を原子質量・分子質量・式量のどれにするか
- どの弾性率を用いるか（\(K\) か、\(K+\frac43G\) か）
- 温度・圧力・結晶方向を揃えているか
- 多原子構造の「荷重を担う単位」をどう切るか
- 液体・非晶質で \(a\) の消去が同様に成立するか

これらが未確定であるため、\(\Theta_X\) は結合様式の普遍指標ではなく、**探索用の検査係数候補**に留める。

## ■ 9. 実装上の役割

\(c\) 基準の係数は値が極端に小さくなるため、実装時には次の二形式を併用する。

### 9.1 保存形式

\[
q_X^{(c)}
=
\frac{Q_X}{Q_{\mathrm{ref}}(\rho,c,L_B)}
\]

共通参照を保持し、異種物質・異種シミュレーション間の移植に使う。由来タグと事前登録された \(r^{\mathrm{known}}\) 一覧は、保存形式に添付する。

### 9.2 演算形式

\[
z_X
=
\log_{10}q_X^{(c)}
\]

または、目的 \(B\) ごとの局所参照 \(q_{\mathrm{local}}\) を用いて、

\[
\widetilde q_X
=
\frac{q_X^{(c)}}{q_{\mathrm{local}}}
\]

とする。

```text
保存層：c基準の共通座標＋由来タグ＋事前登録一覧
演算層：対数化・局所再基準化
```

この分離により、移植性を保ちながら数値計算上の扱いにくさを減らす。演算形式で由来タグが落ちると残差が読めなくなるため、演算層から保存層への逆参照を維持する。

## ■ 10. 破断条件

本仮設は、次の場合に修正または放棄する。

1. \(c\) 基準を用いても、実装間の係数移植性が改善しない  
2. 既存無次元数への分解だけで全機能が尽くされ、三層化の操作的利得がない  
3. 状態変数 \(S_B\) を変えたとき、係数軌道が再現不能になる  
4. モード不一致や既知項を \(\xi\) と誤認する運用が避けられない  
5. 層2・層3が抽出できず、層1の物性表に留まる  
6. \(\Theta_X\) が条件を統一したデータで結合様式を識別しない  
7. \(c\) が共通参照ではなく絶対基底として固定化される  
8. 由来タグを付けても実データが dir-A/dir-B しか構成できず、\(r^{(1)}\) が構造的にゼロのまま残る（v0.2 追加）  
9. 事前登録された \(r^{\mathrm{known}}\) が実務上入手できず、ガードが空文化する（v0.2 追加）  
10. \(\Lambda_B\) の三窓が、どの物質でも発火しないか、逆に常時発火して弁別しない（v0.2 追加）  
11. \(\Theta_X\) が規範値 \(1/2\) の再導出に尽き、規範からのズレが結合様式ではなく測定条件差で説明し切られる（v0.2 追加）  

### 残存構造

本仮設が破断しても、次は残る。

- 物性値を \(B\) と状態変数 \(S_B\) 付きで扱う必要
- ノード・接続・動態の三層分離
- **係数に由来（MEAS / DERIV / POSIT）を付す操作**
- **構成式の導出方向 \(\mathrm{dir}_{ij}\) を層2に持たせる設計**
- 生残差・一次残差・二次残差と \(\xi\) 候補を区別する手順
- **\(r^{\mathrm{known}}\) の事前登録ガード**
- **\(\Lambda_B\) の三窓（成分消失・感度発散・構成式破れ）**
- **\(\mathcal T_B\) の keep / lost / new 三分割（構造破壊学の破断・残存・移植と同型）**
- 保存形式と演算形式を分ける設計
- 異種物質を共通中間表現へ翻訳する目的

## ■ 12. 暫定結論

光速 \(c\) は、物質の物性を直接導出する係数ではない。

また、成分間の関係へ必ず新しい情報を加えるわけでもない。

その役割は、

\[
\boxed{
c
=
\text{相対論SILNから借用した、物性係数の広域共通参照}
}
\]

として、異種物性を同じ座標へ配置することにある。

その上で物質SILNを、

\[
\boxed{
\mathfrak C_B
=
\langle
\mathcal N_B,\mathcal W_B,\mathcal D_B
\rangle
\ ;\xi_B
}
\]

として記述すれば、単なる物性ベクトルでは扱えなかった接続・蓄積・破断・相転移を同じ係数抽出系へ置ける可能性がある。

本仮設の評価点は、\(c\) を使ったこと自体ではない。

> \(c\) 基準の絶対位置と、\(c\) が消える内部関係を分離し、各係数の由来を保持したまま、残差を階層化して三層構造の移植可能な中間表現へ変換できるか

にある。

v0.2 で加えた由来タグ・事前登録ガード・\(\Lambda_B\) の三窓は、いずれも「差が出た」ことを「未知構造がある」と読み替える経路を塞ぐために置いた。塞いだ結果として計算できる残差が残らないなら、それは本仮設の破断条件8・9として作動する。
