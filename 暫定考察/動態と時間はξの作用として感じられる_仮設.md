# 動態と時間はξの作用として感じられる_仮設

---

## ■ 0. この文書の位置

本文書は、動態と時間を **ξ の作用として感じられるもの** として読むための暫定仮設である。

これは Core 数理の改定ではない。`B → M_B + ξ` を前提に、観測者がなぜ「動いている」「時間が流れている」と感じるのかを、RDL の語彙で整理するための考察である。

したがって本文書の主張は、存在論的な確定ではなく、次の仮設に留める。

> **動態感や時間感覚は、ξ残存が後続観測で M_B との差分として露出することで、観測者に感じられるものとして仮設できる。**

---

## ■ 1. 一文定義

> **動態感とは、現在の M_B では吸収しきれない差分が、維持・誤差・再編として観測されることで生じる知覚形式である。**

> **時間感覚とは、順序化された差分列を M_B が統合することで生じる知覚形式である。**

ここで重要なのは、動態や時間を対象そのものの固定属性として置かないことである。本文書が扱うのは、世界に動態が存在する理由そのものではなく、観測者に**動態感**や**時間感覚**が立ち上がる条件である。

以下では、観測された動態を便宜上「動態」と略記する場合がある。ただし存在論的な動態そのものを確定しているわけではない。

対象が「それ自体で動態を持つ」と確定するのではなく、B を引き、M_B が立ち、そこに回収されなかったものが後続観測で差分として露出することで、観測者には動き・差分・遅れ・圧・変化として感じられる。

---

## ■ 2. 基本図式

```text
B を引く
  ↓
M_B が立つ
  ↓
ξ が残る
  ↓
後続観測で ξ残存が差分として露出する
  ↓
F_n と F_{n+1} の差分が感じられる
  ↓
動態感・時間感覚として経験される
```

ここでいう「ξの作用」とは、ξを独立した作用主体として措定することではない。

正確には、

```text
B → M_B + ξ
       ↓
後続観測で、M_B に回収されなかったものが
F / E / H の差分として露出する
```

ということである。`ξ → M_B` という因果矢印を確定するのではなく、ξ残存が M_B の維持・誤差・再編に観測可能な差として現れる、と読む。

---

## ■ 3. 静態感と動態感

静態感と動態感は、対象側の二種類の実体ではない。現在の B で ξ残存による差分がどのように識別されるかの差である。

```text
静態感
= ξ残存による差分が、
  現在の B の識別可能域に露出せず、
  M_B が安定して見えている状態

動態感
= ξ残存による差分が、
  現在の B の識別可能域に露出し、
  M_B の維持・誤差・再編として感じられる状態
```

したがって、静態感とは「ξ がない状態」ではない。ξ残存による差分が今の B では識別されず、M_B の慣性がそれを吸収しているように見える状態である。

逆に動態感とは、ξ残存による差分が露出し、M_B がそれを吸収・補正・再編しようとする過程が観測者に感じられる状態である。

圧縮すれば、次のように置ける。

```text
静態感：
ξ残存による差分 < Bでの識別閾値

動態感：
ξ残存による差分 >= Bでの識別閾値
```

---

## ■ 4. 時間感覚

時間もまた、絶対背景として確定しない。

RDL 的には、時間感覚を次のように仮設できる。

> **時間感覚とは、ξ残存が後続観測で差分として露出し、その差分列を M_B が順序あるものとして統合することで生じる知覚形式である。**

ここで `n` は時間変数ではない。最初は、観測順序・状態列を表す添字として扱う。

```text
F_n
  ↓ M_B による予測・慣性投影
P_n = M_B(F_n)
  ↓
次に観測された F_{n+1}
  ↓
E_n = F_{n+1} - P_n
```

この `E_n` が小さければ、観測者は「同じ流れが続いている」と感じる。

大きければ、「変わった」「ずれた」「跳んだ」「壊れた」と感じる。

この差分が一回だけ現れても、それは単発のズレである。差分が順序化された列として統合されるとき、時間感覚が立ち上がる。

```text
{E_1, E_2, E_3, ...}
      ↓
M_B による統合
      ↓
時間感覚
```

これにより、「時間感覚を説明するために、最初から `t` と `t+Δ` を前提にする」循環を避ける。時間は前提ではなく、順序化された差分列の統合結果として仮設される。

## ■ 5. 整合・跳躍との接続

既存文書 `整合・跳躍の観測的定義` では、整合と跳躍を以下のように置いた。

```text
整合 = 入ってくる F を、現在の M_B の慣性投影の延長として読める
跳躍 = 入ってくる F を、現在の M_B の延長として読めない
```

本仮設では、この二分の下に ξ残存による差分露出を置く。

```text
ξ残存による差分が M_B に吸収される
  → 整合として感じられる

ξ残存による差分が M_B の吸収範囲を超える
  → 跳躍として感じられる
```

したがって整合・跳躍は、ξ残存による差分が M_B に対してどの程度露出したかの観測的ラベルとして読める。

---

## ■ 6. 連続と離散との接続

既存文書 `連続と離散` では、連続を「B を引く前に想定される未分節の流れ」、離散を「B によって切り出された操作単位」とした。

本仮設では、時間感覚をその中間に置く。

```text
未分節の流れ
  ↓ B
離散的な M_B / F の列
  ↓ ξ残存による差分
時間感覚
```

つまり時間は、連続そのものではない。  
また、単なる離散列でもない。

時間感覚とは、離散的に切り出された M_B / F の列のあいだに、ξ残存による差分が感じられ、その差分列が統合されることで立つ知覚形式である。

## ■ 7. 禁止補完

この仮設から、以下を導入してはならない。

```text
禁止：
時間 = ξ と単純同一視する

禁止：
動態感 = ξ と単純同一視する

禁止：
ξ があれば必ず時間が発生すると確定する

禁止：
ξ を M_B に力を加える独立実体として扱う

禁止：
時間を観測者非依存の絶対背景として確定する

禁止：
B → M_B + ξ を変更する
```

正確には、

```text
動態感・時間感覚
= ξ残存が後続観測で M_B との差分として露出し、
  観測者に F / E / H の差分として感じられる断面
```

である。

## ■ 9. 残課題

- Core の `E(t)` を、観測順序ベースの `E_n` とどう接続するか。
- 物理時間・心理時間・記述時間を同じ仮設で扱えるか。
- 夢・集中・退屈・恐怖など、時間感覚が伸縮する現象を M_B / ξ で読めるか。
- 時間感覚密度を、識別された差分量・差分の重要度・記憶への固定率として仮設できるか。
- `動的ξ-design` との接続。ξ を残すだけでなく、時間感覚や動態感をどう設計するか。
