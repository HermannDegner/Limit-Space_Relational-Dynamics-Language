# 動態と時間はξの作用として感じられる_仮設
*T0-T2接続：哲学的基底層↔運用層 / CORE・OP / DRAFT v0.1*

---

## ■ 0. この文書の位置

本文書は、動態と時間を **ξ の作用として感じられるもの** として読むための暫定仮設である。

これは Core 数理の改定ではない。`B → M_B + ξ` を前提に、観測者がなぜ「動いている」「時間が流れている」と感じるのかを、RDL の語彙で整理するための考察である。

したがって本文書の主張は、存在論的な確定ではなく、次の仮設に留める。

> **動態や時間は、ξ が M_B に作用することで観測者に感じられるものとして仮設できる。**

---

## ■ 1. 一文定義

> **動態とは、ξ が現在の B / M_B に対して露出し、維持・誤差・再編として感じられる状態である。**

> **時間感覚とは、ξ の作用を M_B が連続差分として受け取ることで生じる知覚形式である。**

ここで重要なのは、動態や時間を対象そのものの固定属性として置かないことである。

対象が「それ自体で動態を持つ」と確定するのではなく、B を引き、M_B が立ち、そこに回収されない ξ が作用することで、観測者には動き・差分・遅れ・圧・変化として感じられる。

---

## ■ 2. 基本図式

```text
B を引く
  ↓
M_B が立つ
  ↓
ξ が残る
  ↓
ξ が M_B に作用する
  ↓
F(t) と F(t+Δ) の差分が感じられる
  ↓
動態・時間として経験される
```

この図式では、ξ は単なる「外側の余り」ではない。B の外に残りながら、M_B の維持・誤差・再編に影響を与え続ける。

つまり動態は、ξ そのものではなく、

```text
ξ が M_B に作用し、
観測者の F / E / H として現れた断面
```

として扱う。

---

## ■ 3. 静態と動態

静態と動態は、対象側の二種類の実体ではない。現在の B で ξ がどのように感じられるかの差である。

```text
静態
= ξ が現在の B の粒度以下に潜り、
  M_B が安定して見えている状態

動態
= ξ が現在の B に対して露出し、
  M_B の維持・誤差・再編として感じられる状態
```

したがって、静態とは「ξ がない状態」ではない。ξ が今の B では十分に潜っており、M_B の慣性がそれを吸収しているように見える状態である。

逆に動態とは、ξ が露出し、M_B がそれを吸収・補正・再編しようとする過程が観測者に感じられる状態である。

---

## ■ 4. 時間感覚

時間もまた、絶対背景として確定しない。

RDL 的には、時間感覚を次のように仮設できる。

> **時間とは、ξ が M_B に作用し続けることで生じる差分の知覚形式である。**

より操作的には、

```text
F(t)
  ↓ M_B の慣性投影
M_B・F(t)
  ↓ ξ の作用によるズレ
F(t+Δ)
  ↓
E(t) = F(t+Δ) - M_B・F(t)
```

この `E(t)` が小さければ、観測者は「同じ流れが続いている」と感じる。  
大きければ、「変わった」「ずれた」「跳んだ」「壊れた」と感じる。

この差分の連続的な受け取りが、時間として経験される。

---

## ■ 5. 整合・跳躍との接続

既存文書 `整合・跳躍の観測的定義` では、整合と跳躍を以下のように置いた。

```text
整合 = 入ってくる F を、現在の M_B の慣性投影の延長として読める
跳躍 = 入ってくる F を、現在の M_B の延長として読めない
```

本仮設では、この二分の下に ξ の作用を置く。

```text
ξ の作用が M_B に吸収される
  → 整合として感じられる

ξ の作用が M_B の吸収範囲を超える
  → 跳躍として感じられる
```

したがって整合・跳躍は、ξ の作用が M_B に対してどの程度露出したかの観測的ラベルとして読める。

---

## ■ 6. 連続と離散との接続

既存文書 `連続と離散` では、連続を「B を引く前に想定される未分節の流れ」、離散を「B によって切り出された操作単位」とした。

本仮設では、時間感覚をその中間に置く。

```text
未分節の流れ
  ↓ B
離散的な M_B / F の列
  ↓ ξ の作用による差分
時間感覚
```

つまり時間は、連続そのものではない。  
また、単なる離散列でもない。

時間感覚とは、離散的に切り出された M_B / F の列のあいだに、ξ の作用が差分として感じられることで立つ知覚形式である。

## ■ 7. 禁止補完

この仮設から、以下を導入してはならない。

```text
禁止：
時間 = ξ と単純同一視する

禁止：
動態 = ξ と単純同一視する

禁止：
ξ があれば必ず時間が発生すると確定する

禁止：
時間を観測者非依存の絶対背景として確定する

禁止：
B → M_B + ξ を変更する
```

正確には、

```text
動態・時間
= ξ が B / M_B に作用し、
  観測者に F / E / H の差分として感じられる断面
```

である。
