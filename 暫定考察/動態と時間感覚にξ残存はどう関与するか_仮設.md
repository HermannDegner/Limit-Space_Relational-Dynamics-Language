## ■ 0. この文書の位置

本文書は、動態感と時間感覚に **ξ残存がどう関与するか** を読むための暫定仮設である。

これは Core 数理の改定ではない。`B → M_B + ξ` を前提に、観測者がなぜ「動いている」「時間が流れている」と感じるのかを、RDL の語彙で整理するための考察である。

したがって本文書の主張は、存在論的な確定ではなく、次の仮設に留める。

> **動態感は、B を通した相互作用断面の差分 D が、B / M_B 依存の識別閾値を超えることで立ち上がる。**
> **ξ残存は、既知の M_B による閉包を絶対的・最終的なものとして確定できないことを担保する。**

旧題の「動態と時間はξの作用として感じられる」は、v0.3 以降で弱める。ξ は動態や時間の生成主体ではなく、既知構造を絶対閉包として確定できないことを示す残存性として扱う。

## ■ 1. 一文定義

> **動態感とは、B を通した観測者-世界の相互作用断面のあいだに、識別可能な差分 D が立つことで生じる知覚形式である。**

> **時間感覚とは、B 下で先後関係を持つ相互作用断面の差分列 {D_n} を、M_B が統合することで生じる知覚形式である。**

> **ξ残存とは、現在の M_B が全可能性を尽くした絶対閉包だとは確定できないことを担保する残存性であり、観測上は予測誤差 E の増大として露出する候補になりうる。**

ここで重要なのは、動態や時間を対象そのものの固定属性として置かないことである。本文書が扱うのは、世界に動態が存在する理由そのものではなく、観測者に**動態感**や**時間感覚**が立ち上がる条件である。

以下では、観測された動態を便宜上「動態」と略記する場合がある。ただし存在論的な動態そのものを確定しているわけではない。

対象が「それ自体で動態を持つ」と確定するのではなく、B を引き、M_B が立ち、観測者-世界の相互作用断面が B 下で先後関係を持って並び、その差分 D が識別されることで、観測者には動き・差分・遅れ・圧・変化として感じられる。

ただし、この状態差分 D はただちに ξ ではない。時計の秒針のように、D は明確でも M_B がその遷移を十分に予測できる場合がある。

ここでいう `F_n` は、対象そのものの純粋状態ではない。**境界 B を通した観測者-世界の相互作用断面**である。観測＝B 設定であると同時に、観測は相互作用でもある。したがって `F_n`、`D_n`、`E_n` は、対象側だけの量ではなく、B によって切り出された相互作用断面に対する記述である。

## ■ 2. 基本図式

```text
B を引く
  ↓
M_B が立つ
  ↓
B を通した相互作用断面が並ぶ
  ↓
F_n ≺ F_{n+1}
  ↓
相互作用断面差分 D_n = Δ(F_n, F_{n+1}) が識別される
  ↓
動態感として経験される
  ↓
{D_n} が M_B によって統合される
  ↓
時間感覚として経験される
```

ここで `≺` は、計量時間ではなく観測の先後関係である。ただし、この `≺` も B から独立した根源的順序ではない。**先後を識別すること自体が B 下で立つ関係**である。v0.2 では「時間は前提ではない」と書いたが、より正確には、**計量時間 t は前提にしない。ただし B 下で立つ相互作用断面の先後関係 `≺_B` は用いる**。

ここでいう「ξの作用」とは、ξを独立した作用主体として措定することではない。さらに v0.3 では、ξを状態差分 D そのものとも同一視しない。

正確には、

```text
B → M_B + ξ
       ↓
M_B の既知遷移だけで
全可能性が閉じたとは最終確定できない
       ↓
後続観測で、予測誤差 E として露出する候補になりうる
```

ということである。`ξ → M_B` という因果矢印を確定するのではなく、ξ残存が「現在の既知 M_B だけが全可能性である」と最終確定することを不可能にし、その一部が予測外差分として露出する候補になりうる、と読む。

## ■ 3. 静態感と動態感

静態感と動態感は、対象側の二種類の実体ではない。現在の B で、相互作用断面差分 D がどのように識別されるかの差である。

```text
静態感
= 相互作用断面差分 D が、
  現在の B の識別可能域に露出せず、
  M_B が安定して見えている状態

動態感
= 相互作用断面差分 D が、
  現在の B の識別可能域に露出し、
  変化・移動・流れとして感じられる状態
```

したがって、静態感とは「ξ がない状態」ではない。また「D が完全にゼロ」とも限らない。D が今の B / M_B では識別されず、M_B が安定して見える状態である。

逆に動態感とは、D が B の識別可能域に露出し、観測者に変化として感じられる状態である。

圧縮すれば、次のように置ける。

```text
静態感：
D_n < θ_{B,M}

動態感：
D_n >= θ_{B,M}
```

`θ_{B,M}` は固定値ではない。B の粒度、観測者の用途、M_B の整合慣性の深さ、慣れ、注意、記憶、感情負荷によって変動する識別閾値である。

```text
θ_{B,M}
= threshold(B, M_B, 用途, 注意, 記憶, 負荷 ...)
```

M_B が強く安定している領域では、同じ D_n でもノイズとして吸収され、静態感に留まることがある。逆に M_B が揺らいでいる領域では、小さな D_n でも動態感として露出しうる。

ここで重要なのは、D と E を分けることである。

```text
D_n = Δ(F_n, F_{n+1})      // 相互作用断面が変わったか
E_n = Δ(P_n, F_{n+1})      // 予測から外れたか
P_n = M_B(F_n)             // M_B による既知遷移・慣性予測
```

時計の秒針は、D は大きいが E は小さい場合である。つまり「明確に動いている」が「既知の M_B から外れてはいない」。

## ■ 4. 時間感覚

時間もまた、絶対背景として確定しない。

RDL 的には、時間感覚を次のように仮設できる。

> **時間感覚とは、B 下の先後関係を持つ相互作用断面差分列 {D_n} を M_B が順序あるものとして統合することで生じる知覚形式である。**

ここで `n` は計量時間変数ではない。最初は、B 下で識別された観測順序・相互作用断面列を表す添字として扱う。ただし、`F_n ≺_B F_{n+1}` という先後関係は用いる。

```text
F_n ≺_B F_{n+1}
  ↓
D_n = Δ(F_n, F_{n+1})
```

この `D_n` が `θ_{B,M}` 以下なら、観測者には静態感が立つ。

`θ_{B,M}` を超えれば、動態感が立つ。

ただし、この差分が一回だけ現れても、それは単発の変化である。差分が順序化された列として統合されるとき、時間感覚が立ち上がる。

```text
F_a ≺_B F_b ≺_B F_c ...
      ↓
{D_1, D_2, D_3, ...}
      ↓
M_B による統合
      ↓
時間感覚
```

これにより、「時間感覚を説明するために、最初から `t` と `t+Δ` を前提にする」循環を避ける。時間感覚は、計量時間 t ではなく、B 下で立つ先後関係 `≺_B` と差分列の統合結果として仮設される。

## ■ 5. 整合・跳躍との接続

既存文書 `整合・跳躍の観測的定義` では、整合と跳躍を以下のように置いた。

```text
整合 = 入ってくる F を、現在の M_B の慣性投影の延長として読める
跳躍 = 入ってくる F を、現在の M_B の延長として読めない
```

本仮設では、この二分を D ではなく E の側に置く。

```text
D_n = Δ(F_n, F_{n+1})
  → 相互作用断面が変わったか

P_n = M_B(F_n)
E_n = Δ(P_n, F_{n+1})
  → 予測から外れたか
```

```text
E_n 小
  → 整合的な動態

E_n 大
  → 非整合的な動態
  → 跳躍候補
  → ξ露出候補として再検査
```

したがって、D は静態感/動態感の軸、E は整合/非整合/跳躍候補の軸として分ける。

ただし、`E_n` と ξ は同一ではない。`E_n` が大きい場合でも、それは観測ミス、測定誤差、M_B の設定不良、B の設定不良、別 SILN の干渉などでありうる。

```text
E_n 大
  → ξ露出候補
  → 再検査

E_n ≈ 0
  ≠ ξ = 0
```

`E_n ≈ 0` は、現在の観測断面で M_B が十分整合していることを示すにすぎない。ξ が消えたことを示さない。

```text
                E 小
                  │
        予測可能な運動
        時計・公転・歩行
                  │
静態感 ─── D ─── 動態感
                  │
        予測不能な変化
        異常・破断・跳躍
                  │
                E 大
```

## ■ 6. 連続と離散との接続

既存文書 `連続と離散` では、連続を「B を引く前に想定される未分節の流れ」、離散を「B によって切り出された操作単位」とした。

本仮設では、時間感覚をその中間に置く。

```text
未分節の流れ
  ↓ B
離散的な相互作用断面 F の列
  ↓ 相互作用断面差分 D
時間感覚
```

つまり時間は、連続そのものではない。  
また、単なる離散列でもない。

時間感覚とは、離散的に切り出された相互作用断面 F の列のあいだに差分 D が感じられ、その差分列が統合されることで立つ知覚形式である。

ξ残存は、この列が現在の M_B の既知遷移だけで絶対的・最終的に閉包された、と確定することを拒む残存性として関与する。

## ■ 7. ξの役割

v0.3 では、ξ の役割を次のように弱めて精密化する。

```text
ξ ≠ 動態そのもの
ξ ≠ 時間そのもの
ξ ≠ 変化主体
ξ ≠ 創造主体
```

ξ は、既知の M_B だけで世界や状態遷移列が絶対的・最終的に閉じたとは確定できないことを担保する残存性である。

```text
M_B
= 現在の B で既知として回収された整合構造

ξ
= その M_B では回収しきれない残存

したがって
M_B の延長だけでは記述できない方向が
常に残りうる
```

時計の秒針のような予測可能な運動では、D は識別されるが E は小さい。

```text
D_n > 識別閾値
E_n ≈ 0
```

これは「動いているが、ξ が露出しているとは限らない」ケースである。

一方、M_B(F_n) では十分に予測できない F_{n+1} が現れたとき、E が増大する。そのとき、現在の既知構造では回収されなかった方向が観測上露出した候補として読める。

ただし、それはただちに ξ そのものではない。まず B / M_B / 観測手続き / 別 SILN 干渉を再検査する。

```text
既知 M_B
   ↓
ξ残存
   ↓ 露出しうる
未知方向
   ↓ 再編
M_B'
   +
新たな ξ
```

ここで ξ は未知物の固定集合ではない。`M_B'` として回収された瞬間、その一部は既知側に移る。同時に、新たな B / M_B に対して新たな ξ が残る。

## ■ 8. 時間感覚密度

時間感覚密度は、単位物理時間あたりの変化量ではなく、B 下で識別された相互作用断面差分の密度として仮設できる。

```text
時間感覚密度
≈ 識別された D_n の量
  × D_n の重要度
  × 記憶への固定率
  × M_B の統合負荷
```

SILN 的には、これは `θ_{B,M}` と M_B の吸収能力に依存する。

```text
退屈
= D_n が小さい / 重要度が低い / M_B に吸収されすぎる
  → 差分列が平坦に統合される

恐怖
= D_n や E_n が高負荷で露出し、
  M_B の吸収能力を圧迫する
  → 差分列が高密度・高重みで統合される

集中
= D_n の多くが作業 M_B に吸収され、
  時間感覚としての記録固定率が下がる
```

この節も暫定である。時間感覚密度を単一指標に固定せず、B / M_B / 記憶 / 注意 / 負荷の関数として扱う。

## ■ 11. 残課題

- Core の `E(t)` を、観測順序ベースの `E_n` とどう接続するか。
- 状態差分 `D_n` を Core のどこに置くか。基底量ではなく観測補助量として扱うのが妥当か。
- `E_n` 増大を、ξ露出候補・観測ミス・B設定不良・M_B設定不良・別 SILN 干渉へどう分類するか。
- `θ_{B,M}` を M_B の吸収能力・注意・記憶・負荷の関数としてどこまで整理できるか。
- 物理時間・心理時間・記述時間を同じ仮設で扱えるか。
- 夢・集中・退屈・恐怖など、時間感覚が伸縮する現象を M_B / ξ で読めるか。
- RDL_創造論との接続。ξを創造主体にせず、既知閉包不能性から探索・露出・再編・M_B' 化へ接続できるか。
- `動的ξ-design` との接続。ξ を残すだけでなく、時間感覚や動態感をどう設計するか。

*v0.1：初版。動態と時間を、ξ が B / M_B に作用することで観測者に感じられる断面として仮設。時間を ξ と単純同一視せず、F/E/H の差分知覚形式として整理。`整合・跳躍の観測的定義` と `連続と離散` の間を接続する暫定考察として配置。*
