## ■ 0. 問い

文書「平均律と純正律とξ」で次の構造を得た。

> 純正律と平均律の違いは、自然と不自然の違いではない。
> ξをどこに配置するかの違いである。

この構造は音楽固有のものか、それとも音楽はたまたま直観的にわかりやすかっただけで、より広い領域で同じ現象が起きているのか。

本文書は後者の方向で検査する。

> **仮設**：RDL_Coreの関係保存則 ||M_B|| · D[ξ] = 𝒦 は、音楽調律のみならず、他の領域においてもξ配置設計の説明候補として読める。

これを四つの領域――**音楽調律・数学基礎論・計算機表現・幾何学**――で具体的に検査する。

ただし、本文書の目的は四領域を一つの厳密形式に還元することではない。ξ配置設計という操作的視点が**どの範囲まで有効か**を検査することである。対応の強さは領域ごとに異なる（§6.5参照）。

## ■ 1. 中核命題

関係保存則：

```
||M_B|| · D[ξ] = 𝒦
```

意味：

- ある境界Bで整合慣性 ||M_B|| を高めようとすると、ξの拡散 D[ξ] はその積の保存を要求して別の場所へ移動する。
- ξは消えない。配置を変えるだけだ。
- 「最適化」とはξを消す操作ではなく、ξの配置をデザインする操作である。

### ● 中核命題の格上げ（v0.8）

「ξは消えない、配置を変えるだけだ」は、さらに一段深く言い直せる。

> **圧縮されたBは、外部を生成する。**

B内部を圧縮して整合密度を上げると、内部で許される揺らぎ・分岐・曖昧さが減る。収まりきらないξは消滅するのではなく、Bの外側に**ξを担う余白空間**を生成する。

```
B内部を圧縮する
  ↓
関係が高密度化する（||M_B|| ↑）
  ↓
内部で許されるξ可動域が減る（D_B[ξ] ↓）
  ↓
収まりきらないξが、境界の外側に余白空間を生成する（S_out(B,ξ) ↑）
```

ここで重要なのは、**外部は最初から存在する空間ではない**という点である。外部は、圧縮されたBの反作用として反対側に生成される余白である。

したがって中核命題は二段になる：

- **第一段**：ξは消えない、配置を変えるだけだ（§1〜§9 全体）
- **第二段**：ξは外部空間を生成する。圧縮されたBは、外部を生成する（§1.5 で展開）

第二段は単なる補足ではない。「ξが移動する」という受動的な像から、「圧縮が外部を能動的に生成する」という像への転換である。これにより、結晶設計は「閉じる操作」でありながら同時に「次のBを引ける外部を生成する操作」になる（§1.5 参照）。

本命題が音楽以外の領域でも**説明候補として機能する**かを、以下で領域ごとに検査する。

## ■ 1.5 ξ配置設計の二つの極：結晶設計と分散設計

関係保存則 ||M_B|| · D[ξ] = 𝒦 は、設計の二つの極を含意する。

積が一定である以上、片方を上げれば他方は下がる。これは欠陥ではなく、**設計者が選択可能な二つの方向**を意味する。

### ● 前提：D[ξ] の読み方と二つの量

以下では `高 D[ξ]` `低 D[ξ]` という対比表記を用いるが、ここで D[ξ] は**単なる ξ の総量**ではない。

> D[ξ] は、ξが B 内外へどれだけ分散・可動化されているかを示す操作量である。

ξは関係保存則のもとで決して消えない（§1, §3.5 参照）。したがって D[ξ] の増減は「ξ総量の増減」ではなく「ξの可動状態の変化」を指す。

v0.8 では、この D[ξ] を二つの量に分けて読む。

```
D_B[ξ]       = B 内部で ξ が動ける余地（内部可動域）
S_out(B, ξ)  = B の圧縮によって外部に生成された ξ 余白空間
```

両者の関係は次の通り：

- **低 D_B[ξ]** とは、ξの総量が減ったことではない。B内部が圧縮され、ξが内部で動ける余地が減ったことを意味する。
- その**反作用**として、B外部には ξ を担う余白空間 **S_out(B, ξ)** が生成される。

つまり、

```
||M_B|| ↑  →  D_B[ξ] ↓  →  S_out(B, ξ) ↑
```

ξは内部から「消えた」のではなく、外部余白として「生成された」。この読みにより、`低 D[ξ]` を「ξが少ない」と誤読する余地がなくなる。

（注：関係保存則 ||M_B|| · D[ξ] = 𝒦 における D[ξ] は、ここでいう内部可動域 D_B[ξ] に対応する。S_out(B, ξ) は、圧縮の反作用として生成される companion 量であり、その厳密な保存関係は残課題とする。暫定的には、ξ総量を ξ_total として `D_B[ξ] + S_out(B,ξ) ≈ ξ_total`（加法的なξ保存）と、`||M_B|| · D_B[ξ] = 𝒦`（乗法的な整合-可動域トレードオフ）の二つが同時に成り立つ、と読める。§11 参照。）

この前提のもとで、以下の二極を読む。

### ● 結晶設計

```
高 ||M_B|| / 低 D_B[ξ] / 高 S_out(B, ξ)
```

> 結晶設計とは、B内部の関係を圧縮して高密度化することで、内部のξ可動域 D_B[ξ] を縮小し、その反作用としてB外部にξ余白 S_out(B, ξ) を生成する設計である。

- 局所Bの整合慣性を最大化する（内部圧縮）
- 内部のξ可動域が縮小し、内部は結晶のように透明で整合的になる
- 収まりきらないξは消えず、外部にξ余白空間を生成する

ここで強調すべきは、

> **外部は失敗ではない。** B内部を圧縮するからこそ、外が生まれる。外が生まれるからこそ、次のBを引ける。

結晶設計は、閉じる操作でありながら、同時に外部を生成する操作でもある。

**利得**：

- 累積性：内部のξ可動域が小さいから、結果を別の結果の根拠に再利用できる
- 再現性：内部が高密度に整合しているから、誰がやっても同じ結論に到達できる
- 時代/文化超越性：内部結晶が安定だから、時空を越えて持続する
- 計算可能性：内部に曖昧さがないから、機械的に処理できる
- **外部生成性**：圧縮の反作用として外部余白が生まれ、次のBを引く余地が生じる

**代償**：

- 境界面でのξ余白の顕在化（ウルフ五度、ゲーデル文、桁あふれ、強重力場での破綻）
- B移動の困難（転調コスト、体系間翻訳の困難、範囲外でのオーバーフロー）

**例**（内部圧縮 → 外部ξ空間生成）：

- 純正律：主和音内部を圧縮して結晶化 → 外にウルフ五度というξ空間が生成される
- 公理的数学：公理内部を圧縮して証明可能性を高める → 外に独立命題・メタ命題のξ空間が生成される
- 固定小数点：表現範囲内を圧縮して正確にする → 外にオーバーフロー空間が生成される
- 単一公準ユークリッド幾何：平面内を圧縮して整合させる → 外に非ユークリッド的ξ空間が生成される

### ● 分散設計

```
低 ||M_B|| / 高 D_B[ξ] / 低 S_out(B, ξ)
```

> 分散設計とは、B内部を圧縮せずにξを内部に薄く保持することで、内部のξ可動域 D_B[ξ] を高く保ち、外部ξ余白 S_out(B, ξ) の生成を抑える設計である。

- ξを系全域に薄く撒く（内部に保持する）
- 局所Bの整合慣性をやや下げる代わりに、内部可動域を高く保つ
- 内部は完全には閉じないが、外部に余白を生成せず、全域にわたって通行可能になる

結晶設計が「内部圧縮で外部を生成する」のに対し、分散設計は「内部にξを保持して外部生成を抑える」。両者は、ξを**外に出すか内に留めるか**の選択である。

平均律が好例である。純正律が主和音を圧縮してウルフ五度（外部ξ空間）を生成するのに対し、平均律はその ξ を全音程に薄く内在化させ、外部にウルフを生成しない。だからどの調へも均等に移動できる。

**利得**：

- 自由度：B間を低コストで移動できる（外部障壁＝ウルフがない）
- 柔軟性：複数の文脈に対応できる
- 運用性：固定資源（楽器・有限ビット）で広範な対象を扱える
- 統合性：異なる文脈を一つの体系で扱える

**代償**：

- 完全な結晶性の喪失（純正な響きの喪失、厳密値の喪失）
- 局所深度の浅さ（一点に深く沈み込む整合性は得られない）
- 累積性の弱さ（結果がBに依存しがちで再利用が難しい）

**例**：

- 多値論理・ファジー論理・確率的計算
- 平均律
- 浮動小数点（IEEE 754）
- リーマン多様体・一般相対論

### ● 両極の間と外

結晶と分散は両端であり、その間には連続的なスペクトルがある。

- 音楽の中間調律系（ピタゴラス・中全音・ヴェルクマイスター・キルンベルガー）
- 数学のパラ整合論理・部分的形式化
- 計算の区間演算・posit・mixed-precision
- 幾何の微分多様体（局所ユークリッドの貼り合わせ）

中間設計は「結晶でも分散でもない劣った妥協」ではない。**目的に応じて異なる場所にξを配置した、別の設計判断**である。

### ● S_out の二つの配置型：一点濃集と全域分散

S_out(B, ξ) には、量（どれだけ余白が生成されたか）だけでなく、**配置のされ方**という独立した属性がある。少なくとも二つの型を区別できる。

```
一点濃集型 S_out（ウルフ五度型）
  余白が特異点に集中する
  → 大部分は正常に機能し、一点だけが異常になる

全域分散型 S_out（平均律型）
  余白が全域に薄く撒かれる
  → どこも少しずつ不正確だが、特異点はない
```

**ウルフ五度**は前者の典型である。12の純正五度を積み上げて閉じようとすると、コンマがどこか一つの五度に全部溜まり、その五度だけが「使えない一点」になる。残りの五度は正常に響く。

この「一点に異常が濃集する S_out」は、音楽に限らず、結晶設計を選んだ多くの分野に現れる。

| 分野 | 一点濃集型 S_out の例 |
|---|---|
| 音楽 | ウルフ五度 |
| 暦法 | 閏日・閏秒（端数が特定の一日・一秒に濃集） |
| 計算機 | NaN・±Inf・うるう秒の 23:59:60 |
| 数学 | 正多面体の角度欠損（頂点に濃集） |
| 物理 | 重力特異点、結晶の転位・トポロジカル欠陥 |
| 言語 | 不可訳語、不規則動詞（規則化を免れた残余） |
| 制度 | 例外条項、責任の所在不明な境界案件 |

これらに共通するのは、

> 体系を完全に閉じようとした結果、収まりきらない余白が一点に濃集し、そこだけが「使えない／異常な」特異点になる

という構造である。「閉じようとして閉じきれなかった最後のしわ寄せ」が、特定の一点に集まる。

### ● 配置型と設計極の対応

この二つの配置型は、結晶設計／分散設計の二極とちょうど対応する。

```
結晶設計 → 一点濃集型 S_out を生成しやすい
            内部を完全に閉じようとするから、しわ寄せが一点に集まる

分散設計 → 全域分散型 S_out を生成しやすい
            最初から薄く撒くから、特異点ができない
```

純正律（結晶）はウルフ五度（一点濃集）を生成し、平均律（分散）は全音程への微小な丸め（全域分散）を生成する。同じことが各分野で起きている。固定小数点（結晶）はオーバーフロー（範囲外の一点で破断）を、浮動小数点（分散）は全域への相対誤差を生成する。

つまり、

> 「ウルフ五度的なもの」は、結晶設計を選んだ分野に特異的に現れる S_out の形態である。

分散設計を選んだ分野には、ウルフ五度的な「使えない一点」は現れにくく、代わりに「どこも少し甘い」という形で余白が出る。

これにより、S_out には二つの属性軸があることになる。

```
S_out の量    = どれだけ余白が生成されたか
S_out の配置型 = 一点濃集か、全域分散か（＝ウルフ五度性の有無）
```

配置型は、その分野が結晶設計寄りか分散設計寄りかを診断する指標としても使える。ある分野に「使えない特異点」が目立つなら、それは結晶設計が選ばれている兆候である。

### ● 価値中立性

ここで強調すべきは、

> 結晶 vs 分散 は、優劣の問題ではない。

ということ。

歴史的に「平均律は妥協」「IEEE 754は近似」「非ユークリッド幾何は人工」と言われてきたが、これらの解釈は「結晶設計こそ自然」というBに立っているからこそ成立する。逆もまた然りで、「分散設計こそ柔軟で優れている」という解釈は「自由度こそ価値」というBに立っている。

ξ配置設計の視点から見れば、両者は、

- 何を保ちたいか（何を ||M_B|| として強くしたいか）
- 何を捨てられるか（どこに ξ を逃せるか）
- どんな運用が要請されているか（どんなBを移動する必要があるか）

によって**目的に応じて選ばれる**操作論的な判断である。

数学が結晶設計を選ぶのは、累積性・再現性・計算可能性が数学の核心目的だから。
ピアノが平均律を選ぶのは、可演奏性・転調可能性が鍵盤楽器の核心目的だから。
それぞれの目的に対して、それぞれの設計が最適である。

> ξデザインとは、領域の目的との対話である。

これが、以下の四領域検査を通底する視点である。

## ■ 2. 領域I：音楽調律（前提として要約）

詳細は前文書「平均律と純正律とξ」参照。要点のみ：

- **純正律** = 局所B内部の関係密度を高める結晶設計。その反作用として、B外部にウルフ五度・コンマという ξ余白 S_out(B,ξ) が生成される。
- **平均律** = ξをB内部に薄く保持する分散設計。内部可動域 D_B[ξ] を高く保ち外部余白の生成を抑える代わりに、局所和音の結晶性を失う。
- **中間調律系**（ピタゴラス・中全音・ヴェルクマイスター・キルンベルガー）はξ配置の非一様デザイン。
- **合奏** = 複数Bでの異なるM_Bの同時運用。M_B入れ子ネットワークの典型例。結晶設計と分散設計の同時運用ともいえる。

> 音楽調律の問題は、ξ配置設計の問題として読める。

## ■ 3. 領域II：数学基礎論

数学は、ξを境界に押し出して内部を最大限結晶化した設計の、もっとも徹底した例として読める。

### ● ヒルベルトのプログラム

20世紀初頭、ヒルベルトは数学全体を矛盾なく完全に形式化することを目標に掲げた。

- 完全性：すべての真な命題は証明可能
- 無矛盾性：矛盾が導かれない
- 決定可能性：すべての命題は機械的に真偽判定可能

これは RDL 的に読めば、

> 数学領域における結晶設計の極限化

である。あらゆる命題を整合的に位置づけ、未回収関係を残さないM_Bを構築する試み。

### ● ゲーデルの不完全性定理

第一不完全性定理：自然数論を含む十分強い無矛盾な形式体系には、その体系内で証明も反証もできない真な命題が存在する。

第二不完全性定理：そのような体系は、自身の無矛盾性を自分自身では証明できない。

これは関係保存則の数学領域における顕現として読める。

> 形式体系を強くしようとする（||M_B|| を上げる）と、ξ が必ず境界面に染み出す。

ゲーデル文は、純正律におけるウルフ五度と、**RDL的には近い配置構造を持つ**。

- ウルフ五度：純正な五度を積み上げた結果、ξが一点に集中して可視化される。
- ゲーデル文：形式的に整合させた結果、ξが「証明不能な真命題」として可視化される。

両者ともに「ξを消そうとする操作そのものが、ξの存在を可視化する」という構造を持つ。ただし両者は厳密な意味での同型ではない。対象の型（音響的不整合 vs 形式的決定不能性）が異なる。両者は**高次構造での類比**として読むのが妥当である（§6.5参照）。

### ● 独立命題

- **連続体仮説（CH）**：ZF からも ZFC からも独立。証明も反証もできない。選んで足すしかない。
- **選択公理（AC）**：これを採るとバナッハ・タルスキー的な直観破壊が出る。採らないと使える定理が減る。
- **平行線公準**：2000年「自明」とされていたが、独立公理だった（§5参照）。

これらはすべて、

> どの境界 B を選んでも、別のところで ξ が顔を出す

の典型例として読める。ZF（弱い）を選べば未決問題が多くなり、ZFC + 大基数公理（強い）を選べばより大きな独立命題が現れる。ξを消した数学体系はない。**配置を変えた数学体系**があるだけだ。

### ● 構成的数学 vs 古典数学

排中律を認めるか。選択公理を認めるか。

- 古典派：強い定理を得るが、存在証明が「ある場所にあるが場所は不明」になる。
- 構成派：弱い体系で済む代わり、構成できないものは「ない」として扱う。

これは異なる B における異なる M_B である。「正しい数学はどちらか」という問いには意味がなく、用途に応じた選択になる。**音楽の合奏でピアノ（平均律）とヴァイオリン（純正律志向）が別Bで同時に動いているのと近い構造**である。

### ● 計算不可能性

停止問題。チューリングの対角化。形式的にどれだけ整った系でも、その内部での決定不可能な問題が必ず存在する。

これも ||M_B|| を有限に保ったまま ξ を消しきれない構造として読める。

### ● 数学内部の分散設計

数学は主流が結晶設計だが、分散設計の系列も内包している：

- ファジー論理：真偽を連続値で扱う
- 多値論理：真偽の中間状態を許容する
- 確率論理：命題に確率を割り当てる
- ベイズ推論：信念を分布で扱う

これらは「内部にξを薄く撒く」分散設計である。古典論理が扱えない不確実性や曖昧性に対応するために発展した。

数学の主流が結晶設計を選んできたのは、**累積性・再現性・計算可能性**を最優先する目的に対してそれが最適だからであって、結晶設計が「自然」だからではない。

### ● 小結

> 数学は、ξを完璧に境界へ押し出そうとする極限的な結晶設計を選んだ領域である。
> その結果として、内部に類のない結晶性と、境界面での非自明なξ顕在化（ゲーデル文、独立命題）の両方を獲得した。

## ■ 3.5 ξの原型としての無理性

§3で扱った数学基礎論レベルのξ（ゲーデル文、独立命題、計算不可能性）は、メタ的・抽象的な顕現である。

しかし、ξの**もっとも原型的（プロトタイプ的）な顕現**は、これらより遥かに古い。

そして、そのうちのいくつかは音楽調律のξと**構造同型に近い**関係にある。

### ● 歴史的起点：ピタゴラス学派と√2

ピタゴラス学派は「万物は数 = 有理数である」というBで動いていた。整数とその比で世界が記述できる、という哲学的・数学的M_B。

ところが、極めて単純な構成――辺の長さ1の正方形の対角線――が、このB内に収まらないことを彼らは発見した。√2は有理数ではない。

伝説によれば、発見者ヒッパソスは「教義を漏らした」として海に沈められたという。

これは記録に残るおそらく最古の、**ξの顕在化と、それがM_Bを破断させた事例**である。

> 有理数というBの中で「整合させようとした世界」が、
> √2 という形で境界面にξを押し出した。

### ● 有理数Bにおける典型的ξ

ピタゴラスの√2発見以降、人類は多くのξを発見してきた。

- **√2**：B=有理数 における「正方形の対角線」のξ（無理数）
- **π**：B=有理数 における「円周/直径」のξ（無理数、さらに超越数）
- **e**：B=有理数 における「自己微分される指数」のξ（無理数、超越数）
- **log₂(3)**：B=有理数 における「五度関係」のξ（無理数）

これらはすべて、

> 有限の有理数表現というBにおいて、ある自然な比が閉じない

現象として整理できる。

ξは無限に続く小数展開、あるいは無限級数、あるいは無限連続分数として可視化される。

そして、

- 別のB（解析学・幾何学・記号代数）に切り替えれば、これらは閉じる
- π は π という記号で閉じている
- π は無限級数の和として閉じている
- π は「円周/直径」として完全に定義されている

つまり、

> ξの顕在化は B 依存である。
> 有限有理表現というBを引いた瞬間、必ず無限の尾が押し出される。

これは Core 命題「Bを引いてもξは消えず、配置が変わる」の数論領域における顕現である。

### ● 音楽のξは一種類ではない――(a) 無理性ξ と (b) B間不整合ξ

ここで音楽との接続が現れる。ただし、音楽のξは一種類ではない。少なくとも**二つの異なる構造**を区別する必要がある。

#### (a) ピタゴラスコンマ：単一B内の無理性ξ

ピタゴラスコンマは、

```
(3/2)^12 ≠ 2^7
```

から来る。展開すると、

```
3^12 ≠ 2^19
```

これは、**log₂(3) が有理数ではない**ことと等価である。

もし log₂(3) = p/q（p, q は整数）と書けるなら、`2^p = 3^q` となり、12五度=7オクターブが整数倍関係で閉じる。書けない（無理数）からこそ、コンマが残る。

したがって、

> ピタゴラスコンマは、log₂(3) の無理性の音響領域における顕現として読める。

これは §3.5 で扱った「有理数B における無理数のξ」と直接対応する。π・√2 と同系列のξである。

#### (b) シントニックコンマ：複数整数比B間の不整合ξ

シントニックコンマ（81/80）は、構造が異なる。

- 3-limit（素因数2,3だけを使う）系列での長三度: `(3/2)^4 / 2^2 = 81/64`
- 5-limit（素因数5も含む）系列での長三度: `5/4`
- 両者の比: `(81/64) / (5/4) = 81/80`

これは無理数ではない。81/80 は明確な有理数である。

しかし、ξ として顕在化する理由は次のとおり：

> 3-limit 系列で得た E と、5-limit 系列で得た E が、
> 同じ音名 E として同一位置を要求するのに、両者が一致しない。

これは「単一Bにおける無理性の押し出し」ではない。**複数の整数比B（3-limit と 5-limit）を同一の音名空間に重ねたときに生じる、B間の未回収関係**である。

RDL用語で言えば、3-limit M_B と 5-limit M_B が同一の音名ノードに同時にアクセスしようとして衝突する状態であり、**合奏でピアノと歌手が異なるM_Bで同一音を要求する構造**と同型である（§2参照）。シントニックコンマは、M_B入れ子ネットワークの**B間不整合**として読める。

#### 二種類のξの整理

```
Type (a) 単一B内の無理性ξ
  π、√2、e、log₂(3) の無理性
  → ピタゴラスコンマの音響顕現
  → §3.5 で扱う「有理数Bにおける無理数のξ」と同系列

Type (b) 複数B間の不整合ξ
  3-limit M_B と 5-limit M_B の同名音不一致
  → シントニックコンマの音響顕現
  → 合奏での複数B同時運用と同型構造
```

**ウルフ五度** は (a) を一点に集中させた配置である。
**平均律** は主に (a) を全域に均等分散させた配置である（(b) への対応は近似的）。

### ● 配置選択：連続分数と平均律の対応

無理数を「閉じない」と見限るのではなく、**有限予算で配置精度を選ぶ**操作を考える。

π の連続分数展開は、

```
π = [3; 7, 15, 1, 292, 1, 1, 1, 2, 1, 3, 1, 14, 2, ...]
```

であり、その収束分数（=最良の有理近似列）は、

```
3,  22/7,  333/106,  355/113,  103993/33102, ...
```

となる。分母Nを大きく取るほど、近似精度が上がる。

これは「Bに『分母 ≤ N』という制約を課したときの、最良のξ配置」と読める。

音楽で完全に同じ操作が行われている。

- **12平均律**：1オクターブを12等分したB
- **19平均律**：19等分。長三度がより純正に近い
- **31平均律**：中全音律をほぼ正確に再現する
- **53平均律**：ピタゴラス律の比率を**ほぼ完璧に近似する**（Type (a) コンマがほぼ完全に潰れる）

つまり、

> π の連続分数近似 ≈ 平均律の分母選択

両者とも、

> ξを完全に消そうとせず、計算/演奏予算に応じて精度を選ぶ

という**同型の操作**として読める。

53平均律でピタゴラスコンマがほぼ消えるのは、53が log₂(3) の良い有理近似の分母だから、という数論的な事実である。なお、Type (b) のシントニックコンマも同時にほぼ消えるが、これは副次的な結果である（53は 5-limit 比率の近似にも有利な分母）。

### ● 無理性の階層

無理性自体にも階層がある。

- **代数的無理数**（√2、∛2 など）：有限次の有理係数多項式の解として表せる。有理数体に有限拡大を施せば閉じる。
- **超越数**（π、e、log₂(3) など）：いかなる有理係数多項式の解にもならない。代数的拡大体でも閉じない。

これは ξ にも階層があることを意味する：

```
有理数B からはみ出すξ
  ├─ 代数的Bでは閉じるξ（√2、∛2 など）
  └─ 代数的Bからもはみ出すξ（π、e、log₂(3) など）
```

ξは「どこまで強いBに収まるか」という観点で階層化できる。

これは音楽にも示唆がある。Type (a) ξ の中核に **log₂(3) という超越数** がある以上、音楽のピタゴラスコンマは「代数的Bでも閉じないξ」に属する。これは「いかなる平均律分母を選んでも完全には消えない」ことを意味する。

53平均律でほぼ消えるのは、あくまで近似である。log₂(3) が超越数である以上、有限分母の平均律で**正確に**閉じることはありえない。これは数論的に保証された ξ の残存性である。

### ● 小結

> 無理性は ξ のもっとも原型的な顕現であり、
> 音楽調律の Type (a) ξ はこの原型の音響領域における具体例である。
> Type (b) ξ は別の系列、すなわち複数B間の不整合として位置づけられる。

(a) は §3 の Gödel 的「高次構造の類比」よりずっと強い、**構造同型に近い対応**である。
(b) は §2 で言及した合奏（複数B同時運用）と同型構造を持つ。

## ■ 4. 領域III：計算機表現（数値表現）

これは音楽調律ともっとも強い対応を示す例である（§3.5の無理数論とも近い対応を持つ）。

### ● 実数の有限ビット表現

計算機は有限ビットしか持たない。連続な実数を有限ビットで表現するには、必ず誤差（=ξ）が発生する。問題は「ξをどこに配るか」である。

これは §3.5 の「有限有理表現というBにおける無理数のξ」と同じ問題の、工学的な姿である。

### ● 固定小数点 vs 浮動小数点：結晶 vs 分散

**固定小数点**（結晶設計寄り）：

- ある範囲内で均等精度。
- その範囲を超えると桁あふれ・桁落ちで一気に破断する。
- ξを「範囲外」に押し出す設計。
- 利得：範囲内での正確さと再現性。

**浮動小数点（IEEE 754）**（分散設計寄り）：

- 仮数部と指数部に分割。
- 表現可能な数を**対数的に分散**配置。
- 巨大数も微小数も扱えるが、各数値に微小な相対誤差が常に乗る。
- ξを全域に均等分散する設計。
- 利得：広いダイナミックレンジでの運用可能性。

> 固定小数点 = 数の世界の純正律
> IEEE 754 = 数の世界の平均律

この対応は、本文書中もっとも強い対応である。比喩を超えて、**構造同型に近い**と評価できる（§6.5参照）。

なお、**記号計算**（Mathematica、Maple、Sage のような環境）は、結晶設計のさらに極限である。πを `π` のまま保持し、√2 を `√2` のまま保持する。ξを表現から完全に追い出す代わりに、評価コスト（計算時間・メモリ）に押し出している。これは数学の公理結晶設計の計算領域版として読める。

### ● 区間演算・posit

区間演算は、各数値を「ξの帯」として明示的に保持する設計である。誤差を消そうとせず、誤差の範囲を計算結果に含める。これは「ξを記述に持ち込む」アプローチで、結晶でも分散でもない、**ξを可視化する第三の設計**である。

posit（Type III Unum）はIEEE 754とは異なる対数分布を採用する代替案。これも「ξ配置設計の別の選択」として読める。

### ● 小結

数値計算という極めて工学的な領域でも、本質的にやっていることは「ξをどう配るかのデザイン」として読める。固定小数点・浮動小数点・記号計算・区間演算は、いずれも目的に応じたξ配置の異なる選択である。

## ■ 5. 領域IV：幾何学

### ● 平行線公準と非ユークリッド幾何

ユークリッドの『原論』は5つの公準で成立する。最初の4つは直観的に明らかだが、第5公準（平行線公準）は他の4つから証明可能ではないか、と2000年間試みられた。

19世紀、ガウス・ボヤイ・ロバチェフスキーが独立に同じ結論に達した。

> 平行線公準は他の公準から証明できない。
> 選択である。境界Bの設定である。

第5公準を変えると、別の整合的な幾何学が現れる。

- 楕円幾何（リーマン幾何）：平行線は存在しない
- 双曲幾何（ロバチェフスキー幾何）：複数の平行線が存在する

どれも内部的に完全に整合している。どれが「正しい」かではなく、どのBで操作するかの選択である。

### ● 「ユークリッド幾何 = 自然」の錯覚

2000年「ユークリッド幾何が真の幾何である」と信じられてきた。これは、

> 純正律 = 自然

の錯覚と**説明構造において類似する**。両者とも、

- ある特定のBで切り出すと結晶的に美しい
- そのBが他のBより根源的だと感じられる
- しかし、それは観測者のM_Bがそう要請しているにすぎない

### ● 一般相対論

アインシュタインは、物理的時空が非ユークリッド的であることを示した。重力場の中では空間自体が曲がる。

これは「ユークリッド幾何のξは大スケール・強重力場に押し出されていた」と読める。地球規模の人間スケールではユークリッド幾何が極めてよく機能するが、宇宙スケール・恒星近傍ではξが顕在化する。

ユークリッド幾何は、ある B（弱重力・小スケール）における局所近似だったと読める。

### ● 結晶と分散の幾何学的対応

- **単一公準のユークリッド幾何** = 結晶設計：一つの公準系で全空間を統一的に扱う。日常スケールで強い。
- **リーマン多様体・一般相対論** = 分散設計：局所的に異なる幾何構造を許容し、全体は貼り合わせで構成する。広いスケールに対応する。

### ● 小結

> 幾何学にも「絶対的に正しい幾何」はない。
> 境界Bの選択に応じた、異なるM_Bの並立がある。

これは音楽における純正律 vs 平均律 vs 中間調律の並立と**説明構造を共有する**。

## ■ 6.5 同型・類比・相似の区別（v0.3 で導入、v0.4 で更新、v0.5 で維持）

本文書でいう「同じ構造」は、すべてが厳密同型であることを意味しない。
領域間対応には少なくとも三段階がある。

### ● 構造同型に近い対応

**音楽調律 ↔ 数値表現（§4）**

有限資源（音律12音 / 有限ビット）で連続量（音高 / 実数）を離散化する操作。
局所精度を取るか全域精度を取るかの設計判断。
対数的分散がどちらの領域でも実用解として採用されている。

**音楽調律（Type (a)）↔ 数論（無理性レベル）（§3.5）**

音楽の Type (a) ξ（ピタゴラスコンマ・ウルフ五度系）は log₂(3) の無理性の音響顕現であり、π や √2 と同じ「有理数Bにおける無理数のξ」の系列に属する。連続分数による有理近似と、平均律の分母選択は同型の操作。

なお、Type (b) ξ（シントニックコンマ系）は無理性ではなく**複数B間の不整合**から生じるため、数論の無理数論と直接対応はしない。Type (b) は §2 で扱った**合奏（複数B同時運用）と同型構造**を持つ。

### ● 高次構造の類比

**音楽調律 ↔ 数学基礎論（§3、Gödelレベル）**

未回収関係が境界・メタレベルに現れるという**操作の構造**は似るが、対象の型は異なる。

- ウルフ五度は音響的不整合（連続量のうなりとして観測される）
- ゲーデル文は形式的決定不能性（メタ定理として証明される）

両者を「同じ現象」とは言えないが、「ξを消そうとする操作が、ξの存在を可視化する」という**構造のパターンを共有する**。

ここで重要なのは、§3.5で示したように、**音楽↔数学の対応は二つのレベルを持つ**ということ：

- 直接レベル（無理性・有理近似）：Type (a) ξ について構造同型に近い
- メタレベル（Gödel・形式的不完全性）：高次類比

両者は同じ「数学」だが、ξへの関わり方の深さが異なる。

### ● 説明的相似

**音楽調律 ↔ 幾何学（§5）**

「局所近似がスケール外で顕在化するξを持つ」という説明構造は似るが、厳密な対応には追加条件が必要。

- 純正律とユークリッド幾何は、いずれも「ある条件下で結晶的に整合する局所近似」である
- しかし、純正律は単一のB内での整合操作、ユークリッド幾何はB（公準系）自体の選択問題、と層が違う

両者を並べることで読みが深まるが、構造同型を主張するには対応が緩い。**説明としての相似**にとどめる。

### ● 本文書の立場

```
強い対応  ：音楽 ↔ 数値表現（構造同型に近い）
強い対応  ：音楽 Type (a) ↔ 数論・無理性（構造同型に近い）
中程度     ：音楽 Type (b) ↔ 合奏的な複数B運用（同領域内の類比）
中程度     ：音楽 ↔ 数学基礎論（高次構造の類比）
弱い対応   ：音楽 ↔ 幾何（説明的相似）
```

本区分自体は依然として暫定であり、各対応の厳密性精査は構造破壊学的タスクとして残る（§11）。

## ■ 7. 二重の閉じなさ（自己食的構造の領域横断顕現）

各領域で、ξを完全に閉じる体系が存在しない。それだけでなく、

> 「ξは閉じない」を完全に閉じる体系も存在しない。

これは RDL_Core の「𝓜 自体が SILN である」の領域横断顕現として読める。

例：

- **音楽**：「平均律と純正律のどちらが優れているか」という問い自体が、観測者のB（評価軸）に依存する。
- **数学（無理性）**：「π は閉じている／閉じていない」の判定自体が、B（記号系・解析系・有理表現系）に依存する。さらに「ξが代数的Bで閉じるかどうか」自体が階層的に開く。
- **数学（基礎論）**：ゲーデルの不完全性定理それ自体が、ある形式体系（一階述語論理 + 有限的構文）における命題である。別のB（二階論理、無限的構文、非標準論理）では別の表情を持つ。
- **計算**：「IEEE 754が最適か」の判断自体が、用途と評価関数というBに依存する。
- **幾何**：「物理空間はどの幾何か」の判断自体が、観測スケールと精度というBに依存する。
- **設計選択**：「結晶設計と分散設計のどちらが優れているか」という問い自体が、領域の目的というBに依存する（§1.5参照）。

メタレベルに上がっても、ξは閉じない。これが自己食的構造である。

そして本文書も例外ではない。「ξ配置設計は普遍である」という主張自体が、ある B（RDL言語の境界）における命題であり、別のBから見れば別の顔を持つ。

## ■ 8. ξの動態力――両極が生み出すもの

ξを「欠陥」「不完全性」「誤差」として読むのは、特定のBから見たときの解釈である。

ξを「動態の源泉」として読み直すと、別の景色が見える。そして、結晶設計と分散設計の**どちらの設計も**、それぞれ固有の動態を生み出していることがわかる。

### ● 結晶設計が生み出すもの（内部圧縮で外部を生成する動態）

B内部を圧縮して内部ξ可動域を下げることで、結晶構造は次の動態を獲得する：

- **証明の積み上げ**：内部のξ可動域 D_B[ξ] が低いから、定理を別の証明の根拠として安定的に再利用できる。数学が数千年累積できているのはこの動態のおかげ。
- **時代と文化を超えた持続**：ピタゴラスの定理は今でも有効、ユークリッド幾何は地球上のどこでも同じ。
- **機械的再現可能性**：内部でξが自由に動かないから、人間以外の計算機にも処理できる。ソフトウェアと数学の親和性はここから来る。
- **外部余白での新発見**：圧縮の反作用として生成された外部余白 S_out(B,ξ) こそが、新しい数学を生む。√2 の発見が無理数論を生み、π・e の超越性が超越数論を生んだ。ゲーデルの定理が新しい論理学を生み、計算不可能性が計算複雑性理論を生んだ。独立命題という外部余白があるからこそ、新しい公理を採用して別の数学世界が開ける。

> 結晶設計は静的に見えるが、その圧縮が生成する外部余白こそが、領域を最も豊かに駆動する。

### ● 分散設計が生み出すもの（ξを内部に薄く撒く動態）

ξを系全域に分散させることで、分散構造は次の動態を獲得する：

- **転調・進行・流動性**：ξが残るからこそ、次の和音、次の調、次の場面へ動ける。音楽の時間的展開はξの分散があってこそ可能。
- **B移動の容易さ**：ξが均等に薄く撒かれているから、どのBへも均等なコストで移動できる。固定楽器・全調運用・移調を可能にする。
- **柔軟な運用**：適応的精度・mixed-precision・確率的計算といった豊かな計算様式が生まれる。誤差解析という分野自体がξの研究である。
- **異なる文脈の統合**：単一の枠で複数の文脈を扱える。多様体論、ファジー論理、確率モデルなど。

> 分散設計は不完全に見えるが、その不完全性が領域を最も柔軟に駆動する。

### ● 動態の相補性

結晶と分散は、互いに排他的ではなく相補的である。

- 数学は結晶設計を選びつつ、応用領域では浮動小数点（分散）を使う。
- 音楽は平均律（分散）を選びつつ、合奏では純正律(結晶)的な瞬間調整を行う。
- 計算機は浮動小数点と固定小数点を使い分け、必要に応じて記号計算に降りる。
- 幾何は微分多様体として、局所ユークリッド（結晶）と大域非ユークリッド（分散）を貼り合わせる。

これらはRDL_Core の「整合と跳躍の同一性」の異なる顕現として読める。ξが消えないこと、配置可能であること、両極が共存できることが、領域に「次がある」ことを保証している。

### ● 小結

> ξは消すべき欠陥ではなく、領域を動的に保つ源泉として読める。
> 結晶設計と分散設計は、それぞれ異なる動態を生み出す。
> どちらも領域に固有の生命を与えている。

## ■ 9. 結論

「自然 vs 人工」「正しさ vs 妥協」「真理 vs 近似」という素朴な二項対立は、領域を問わず似た型の錯覚として現れる。

- 純正律 vs 平均律
- 有理数のみ vs 無理数を含む実数
- 古典数学 vs 構成数学
- 固定小数点 vs 浮動小数点
- ユークリッド幾何 vs 非ユークリッド幾何

これらは、対応の強さに濃淡はあるが、**ξ配置設計という視点から読むと同じ操作論の異なる顕現として整理できる**。

実際に起きているのは：

> ξ配置設計の連続スペクトルの中で、目的のBに応じて位置を選んでいる。

そして、

> 美しさ・正しさ・自然さの判定自体も B 依存である。

絶対的に「正しい」配置はない。あるのは、ある B に対して有効な配置と、別の B に対して有効な配置の並立である。

特に強調すべきは、結晶設計と分散設計は**優劣の関係ではない**ということ（§1.5）。

- 数学が結晶設計を選ぶのは、累積性・再現性が数学の核心目的だから。
- 音楽が平均律という分散設計を主流とするのは、可演奏性・転調可能性が音楽実践の核心目的だから。
- それぞれの目的に対して、それぞれの設計が最適である。

問うべきは、

> どちらが正しいか

ではなく、

> 今、自分はどのBに立って何をしようとしているか。
> そのために、ξをどこに配置するのが目的に適っているか。

である。

### ● ξ配置設計普遍則（仮）

> **ξ配置設計普遍則（仮）**

### ● ξ-自由度相補則（仮）

§1.5 で導入した結晶設計と分散設計の二極から、次の系を**仮設**する。

> **ξ-自由度相補則（仮）**
> 系のB内部を圧縮する（結晶設計）と、局所深度 ||M_B|| が増し、累積性・再現性・計算可能性が得られる代わりに、内部のξ可動域 D_B[ξ] は下がり、その反作用として外部余白 S_out(B,ξ) が生成される。
> 系のξをB内部に分散保持する（分散設計）と、内部可動域 D_B[ξ] が増し、柔軟性・運用性・統合性が得られる代わりに、局所深度 ||M_B|| は下がり、外部余白 S_out(B,ξ) の生成は抑えられる。
> 両者の積は系のキャパシティ 𝒦 に比例する。
> 「最適化」とは、目的に応じて局所深度と全体自由度のバランスを選ぶことである。

これは関係保存則を「設計の選択肢」として読み直したものであり、ξ配置設計普遍則の系として位置づけられる。

### ● 二系列のξ

v0.4 で明らかになったように、ξには少なくとも二系列がある：

- Type (a) 単一B内の無理性ξ
- Type (b) 複数B間の不整合ξ

両者は同じ「ξ」というラベルで呼ばれるが、生成構造が異なる。普遍則は両者を含む包括的な命題として扱う必要がある。

## ■ 11. 残課題

### ● 11.0 仮設の三軸評価（運用試験）

本文書は多数の仮設を含む（関係保存則、ξ配置設計普遍則、ξ-自由度相補則、各領域対応、S_out 保存関係など）。これらはすべて `(仮)` ラベルを持つが、`(仮)` という単一ラベルは仮設同士の差異を二値に潰してしまう。

実際には、仮設には少なくとも三つの独立な軸がある。

```
重み（weight）  = その仮設が崩れたとき、体系のどれだけが連鎖崩壊するか
                  中核に近いほど高い。末端ほど低い。

温度（temp）    = その仮設が、他の仮設とどれだけ整合しているか
                  整合度が低いほど高温＝不安定。

既知誤差（err） = その仮設が、すでに分かっている不一致をどれだけ抱えているか
                  既知の逆向き現象・反例の量。
```

この三軸は独立である。たとえば「重みは小さいが既知誤差は大きい」仮設（末端の粗いアナロジー）と、「重みは大きいが既知誤差は小さい」仮設（よく整合した中核）は、別の座標を占める。

**設計原則（仮）**：重みと既知誤差は逆相関させたい。中核（高重み）には既知誤差の小さい仮設を置く。既知誤差が大きいのに重みも大きい仮設は、体系の危険信号である。

**これ自体が ξ-design である**：`(仮)` という単一ラベルは、仮設のξを「ある/なし」の二値に圧縮した**結晶設計**である。三軸メタデータは、その潰したξを三次元に展開し直す**明示設計**である（§11 残課題の「第三設計＝明示設計」参照）。RDLが「ξを明示する言語」である以上、自分の仮設のξも明示する、という自己適用にあたる。

なお、三軸を別ラベル（「思弁」など）として体系の外に隔離しないことが重要である。隔離すると「外＝劣ったもの」という階層が生じる。三軸タグは、全仮設を同じ平面に置いたまま座標の違いだけで管理する。

#### 試用：主要仮設のタグ付け

タグ書式：`（仮｜重:* 温:* 誤:*）` （* は 高/中/低 または 大/中/小）

| 仮設 | 重み | 温度 | 既知誤差 | 所在 |
|---|---|---|---|---|
| 関係保存則（RDL_Core） | 高 | 低 | 小 | Core |
| ξ配置設計普遍則 | 中 | 低 | 小 | §10 |
| ξ-自由度相補則 | 中 | 中 | 小 | §10 |
| S_out 保存関係（D_B[ξ]+S_out≈ξ_total） | 中 | 中 | 小 | §1.5, §11 |
| S_out に配置型がある（一点濃集/全域分散） | 中 | 低 | 小 | §1.5 |
| 音楽↔数値表現（構造同型） | 低 | 低 | 小 | §6.5 |
| 音楽↔数論・無理性（構造同型） | 低 | 低 | 小 | §6.5 |
| 音楽↔数学基礎論（高次類比） | 低 | 中 | 小 | §6.5 |
| 音楽↔幾何（説明的相似） | 低 | 中 | 中 | §6.5 |
| 真空エネルギー＝ξ非消滅の署名（姉妹文書） | 低 | 低 | 小 | 動的§4 |
| 宇宙定数問題＝潜在ξと顕在ξのミスマッチ | 低 | 中 | 中 | 動的§4 |
| 真空＝物質圧縮の S_out 総和 | 低 | 高 | 大 | 保留 |

最後の「真空＝S_out総和」は、重みは小さいが温度が高く既知誤差も大きい（圧縮＝重力崩壊と空間生成＝膨張が逆向き現象）。よって本文化せず保留する。これは「思弁だから隔離」ではなく「他の仮設との整合度が低く既知誤差が大きいから保留」という、三軸に基づく判断である。

#### 運用試験としての位置づけ

本節は三軸評価の**運用試験**であり、軸の定義はまだ甘い。実際に何件かタグを付けることで、軸の境界や粒度の問題が見えてくることを期待する。試用が安定したら、独立した枠組み（「仮設という操作」への補遺、または独立小文書「仮設の重み・温度・既知誤差」）への格上げを検討する。

**三軸自体の残課題**：
- 各軸を定性三段（高/中/低）でなく定量化できるか
- 「重み」を依存グラフ上の中心性として測れるか
- 「温度」を他仮設との整合違反数として測れるか
- 「既知誤差」を反例・逆向き現象のカウントとして測れるか
- 三軸が本当に独立か、それとも相関があるか

- **無理性の階層構造との接続**：代数的数 vs 超越数の区別が ξ の「閉じなさの深さ」の階層として読める可能性。log₂(3) が超越数である事実は、音楽のピタゴラスコンマが「いかなる平均律分母でも完全には消えない」という強い保証を与える。

- **中間設計・複数B同時運用の事例収集**：各領域で「中間調律系」「合奏」に相当する事例を集める。
- **メタレベル押し出しの形式化**：ξが領域の内側で消されると、メタレベルや別領域に押し出される。この「押し出し方向」を構造的に記述する。
- **本文書自身のB依存性**：本文書も RDL という B における命題である。別のBから見るとどう見えるか。
- **§6 対応表 Type (b) 行の精査**：各領域における「B間不整合」相当の同定が暫定であり、網羅性と厳密性の検証が必要。
- **S_out(B, ξ) の保存関係の形式化**：v0.8 で導入した「内部可動域 D_B[ξ] と外部余白 S_out(B, ξ)」の二量について、関係保存則との整合を厳密化する必要がある。暫定的には `||M_B|| · D_B[ξ] = 𝒦`（乗法的トレードオフ）と `D_B[ξ] + S_out(B,ξ) ≈ ξ_total`（加法的ξ保存）の二式が同時に成立すると読んでいるが、これが正しいか、S_out の定義をどう操作的に与えるか、ξ_total が領域によらず定義可能かは未検証。とくに「外部は圧縮の反作用として生成される」という存在論的主張を、量的関係としてどう書くかが核心の残課題。
- **外部生成の方向性**：結晶設計は外部を生成するが、その外部が「どの方向に」生成されるかは未整理。純正律はウルフ五度という特定の位置に、公理体系はゲーデル文という特定のメタ位置に外部を生成する。この「生成方向」を構造的に予測できるか。v1.1 で導入した「一点濃集型 S_out」は、生成された余白が**どこに**集まるかの問題であり、この残課題と直結する。一点濃集が起こる位置を予測する理論が立てば、両課題が同時に進む。
- **S_out 配置型の形式化**：v1.1 で「一点濃集型／全域分散型」の二型を導入したが、両者は連続的な中間（複数点への濃集など）を持つか、配置型を定量化する指標（余白分布のエントロピー、ジニ係数的な集中度など）が立てられるか、は未検証。また「結晶設計→一点濃集／分散設計→全域分散」の対応に反例がないかの精査も要る。
- **静的ξ-design と動的ξ-design の区別**：本文書で扱った四領域はすべて**形式領域**であり、ξは静的（一度配置すれば外部介入なしに保持される）として扱われている。一方、**物理領域**では相互作用が時々刻々起こり続けるため、ξの局所押し込めは形式領域のように奇麗にはいかない。
  - 数学の独立命題は時間が経っても独立命題のまま
  - ピタゴラス律のウルフ五度は永遠にウルフ五度のまま
  - IEEE 754 の表現誤差は数値が変わらない限り変わらない
  - 一方、ブラックホールは蒸発し、局所秩序は熱平衡に向かって崩れ、真空からも仮想粒子が湧き出る
  - 物理領域では、保存則 ||M_B|| · D[ξ] = 𝒦 は瞬間的には成立するが、D[ξ] が単調増加する強い傾向（熱力学第二法則）を持つ
  - 結晶設計を維持するには、外部とのξ交換（開放系条件）が必要となる
  - これは形式領域のξ-designとは運用条件が本質的に異なる
  - **本文書は形式領域に範囲を限定し、物理領域は姉妹文書「動的ξ-design――時間・散逸・維持」で扱う**
- **明示設計のデフォルト化（物理領域）**：v0.6 で挙げた「明示設計」（区間演算・誤差バー等）は、物理領域では場・波・確率分布・揺らぎとして主流の表現になっている可能性。これも姉妹文書で扱う。

- **「目的」概念の操作的定義**：v0.5 で「目的に応じた設計」という言い方を多用したが、「目的」自体が B 依存である。この循環をどう扱うか。
- **第三設計（明示設計）の位置づけ**：v0.5 で結晶設計と分散設計の二極を立てたが、§4 で言及した区間演算のような「ξを記述に持ち込む」設計は、いずれの極にも収まらない第三の系譜である可能性がある。
  - **候補例**：区間演算、誤差バー、確率分布、信頼区間、注釈付き翻訳、法の例外条項、創作設定における「未確定領域」、ベイズ的信念分布
  - **特徴**：ξを境界に押し出すのでも全域に分散させるのでもなく、**ξをξとして表示・保持する**設計
  - **RDLとの関係**：RDL言語自体が「ξを消すよりξを明示する」立場であり、この第三設計の系譜に属する
  - **暫定的整理**：
    ```
    結晶設計：ξを境界へ押し出す
    分散設計：ξを全域へ撒く
    明示設計：ξをξとして表示・保持する
    ```
  - **未解決の問い**：明示設計は本当に独立な第三の極なのか、それとも結晶/分散の混合か。明示設計においても D[ξ] と ||M_B|| の関係は保存則を満たすのか、それとも別の保存量を立てる必要があるのか。
  - v0.5 では二極が議論の中心であり、即座に三分類化すると焦点が散る。v0.6 以降で扱う候補。
