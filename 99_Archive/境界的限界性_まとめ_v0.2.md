## ■ 0. この概念自身の身分

境界的限界性を述べる前に、この概念自身がどういう身分のものかを宣言しておく。これを省くと、本書は自分が警告する誤り（存在論的固定）を自分で犯す。

### 0.1 三つの身分のうち、どれか

境界的限界性は、次の三つのうちどれとして主張されるかで意味が変わる。

```text
(a) 世界の存在論的法則
    「世界はそういう性質を持つ」
    → 限界空間（絶対確定できない）が禁じる。採らない。

(b) あらゆる操作の超越論的条件
    「我々が行いうるどんな操作も、必ずそうなる」
    → 世界についてではなく、操作の構造についての主張。採る。

(c) 高重みのM_B（破断もしうる仮設）
    「これは強い仮設だが、絶対法則ではない」
    → 自己適用版。採る。
```

本書は **(b)＋(c)** を採る。境界的限界性は、世界の検証済み性質ではなく、操作の超越論的条件であり、かつそれ自身が格付けされた高重みの仮設である。

### 0.2 自己適用の捻れ

ここで自己言及の捻れが生じる。

「すべての操作はξを残す」という命題自体が、Bを引いて立てた操作である。

```text
この命題が自分を除外する  → 普遍性が崩れる（自己論駁）
この命題が自分を含む      → 境界的限界性自身にξが残る（§4-5 自己根拠不能性そのもの）
```

一貫する閉じ方は後者である。

> **境界的限界性は自分を含む。したがって、外から証明しきれない自己適用的な構造仮説であって、証明済みの絶対法則ではない。証明できないこと自体が、この命題が残すξである。**

これは弱みではない。「あらゆる記述は残余を残す」と言いながら自分だけ除外する体系は、遂行的に自己論駁する（検証原理が自分の検証に落ちて崩れたのと同型)。自分を含めて初めて無撞着になる。

> **自己適用は、しぶしぶ認める弱みではなく、自己論駁を免れるための必要条件である。含まなければ壊れる。含めば立つ。**

### 0.3 記述的限界性への折り返し

境界的限界性は、述べようとすると必ず記述を通る。

```text
存在論的には：記述限界性 ⊂ 境界的限界性（記述限界性は派生形＝子、§6）
操作論的には：我々が掴める境界的限界性は常に既に記述
            → 述べられた境界的限界性は記述限界性の特殊例になる
```

つまり、親（境界的限界性）を語った瞬間、それは記述になり、子（記述限界性）の一事例へ落ちる。連続ラベルが連続でありえないのと同じ捻れである。

### 0.4 LS/RDL自身への適用

当然、境界的限界性はLS/RDL自身にも適用される。

LS/RDLは、Bを引いて立てたM_Bの体系である。だからLS/RDL自身が残余を持ち、その語彙——B, M_B, ξ, EFP, E, H——は、それぞれ限界に晒されたM_Bである。

最も効くのは中心語に当たるとき。「ξ」というラベル自体がM_Bである（記号を与え、式に組み込み、役割を割り振った）。だから ξ-as-label は残存そのものではなく、残存を指すM_Bで、その矢印と残存の差がまた ξ になる。

> **LS/RDLが限界を指すために使う全ての語は、それ自身が限界に晒されたM_Bである。§4-7 の「閉じきらない再帰」を、語彙自身へ適用した姿。**

### 0.5 自爆回避（破断条件）

自己適用には、健全な閉じ方と自爆とがある。

```text
健全：LS/RDLは残余を持つ高重みM_B → 改訂可能・絶対化しない → 安定（限界観照姿勢）
自爆：自己適用 → ならば全Bは等価な恣意 → 何も言えない → 体系が自分を溶かす（相対主義の酸）
```

自爆を避ける鍵は、仮設が **格付けされる** ことである。自己適用はLS/RDLを「改訂可能・非絶対」にするが、「恣意・無価値」にはしない。重み／温度／既知誤差の三軸が、「どのBも真理ではない」と認めたまま、良いBと悪いBを判別する装置になる。

> **自己適用してなお何かが言えるのは、真理を持つからではなく、仮設に勾配があるからである。**

## ■ 1. 一文定義

**境界的限界性とは、対象を扱うために境界Bを仮設した瞬間、操作可能な関係安定M_Bが立つと同時に、M_B化されないものがξとして残るという、操作の超越論的構造である。**

より圧縮すれば、

> **BはM_Bを成立させるが、同時にξを発生させる。**

これが境界的限界性の核である。（その身分は §0 の通り、世界の法則ではなく、自己を含む格付き仮設である。）

## ■ 2. 基本構造

```text
Bを引かない
  → 対象を操作できない
  → 名づけられない
  → 測れない
  → 比較できない

Bを引く
  → M_Bが立つ
  → 操作可能になる
  → しかしBの外・縁・未解像部がξとして残る
```

したがって、限界は単なる能力不足ではない。

**操作可能性そのものが、限界を同時に生む。**

## ■ 3. EFP / F / M_Bとの接続

より精密には、対象は最初からM_Bとして与えられるわけではない。

```text
EFP
  = 解釈すべき何かがある、という最小仮設

既存M_B
  = EFPを読むための慣性・文脈・解釈構造

B
  = 既存M_Bに支えられて仮設される境界

F
  = Bを通してEFPが解釈された結果

E
  = Fと既存M_Bのズレ

H
  = ズレの蓄積
```

### 3.1 EFPの身分注意

EFPは「前B実体」ではない。

「作用束」と名づけた時点で、すでに多と構造を課している。真にB以前のものは「束」とも呼べない。したがってEFPは前B実体ではなく、**最も粗い第一M_B**——「解釈すべき何かがある」という最小仮設——として扱う。

EFPと形而上空間の関係は、次のように置く。

```text
形而上空間 = B以前・B外部・M_B化前を指し示す補助語彙
EFP        = その形而上空間に対して引いた、最初の・最も粗いB
```

つまりEFPは、形而上空間そのものではなく、それへ向けた第一の仮設である。EFPを実在する前B実体として扱うと、限界空間と衝突する。

### 3.2 FとM_B

> **EFPに対して、既存M_Bに依存したBを仮設し、そのBを通して立ち上がる作用解釈がFである。**

M_Bは、EFPそのものではない。  
M_Bは、Fの反復・整合・安定性から仮設される関係安定である。

## ■ 4. なぜξが残るのか

ξが残る理由は、単に「人間が不完全だから」ではない。出所は少なくとも三つの族に分かれる。

### 4.A 射影損失族（切断を通り抜けられない内容）

```text
1. 選択性
   Bは何かを選ぶ操作なので、選ばれないものが残る。

2. 解像度
   Bには粒度があるので、その粒度より細かい差分が残る。

3. 射影性
   M_Bは対象全体ではなく、ある軸への射影なので、落ちた次元が残る。
```

### 4.B 再帰接地欠落族（切断・読解が自分を接地できない）

```text
5. 自己根拠不能性
   B自身が「なぜこのBでよいか」を完全には内部で証明できない。

6. BのM_B依存性
   BはM_Bを立てるが、B自身の選択・妥当性・持続性も既存M_Bに依存する。

7. M_Bの読解依存性
   M_Bは、それをM_Bとして読む別のM_Bに依存する。
```

### 4.C 時間すべり族（指示対象が動く）

```text
4. 時間遅延
   Bを引いた瞬間にも対象・観測者・関係は動くので、差分が残る。
```

### 4.D 過剰決定

三族は独立な出所である。ゆえにξは過剰決定されている——一族を潰しても、他族が残す。

> **ξは、Bの外に残るだけではない。Bを引く構造、M_Bを読む構造、その読解を妥当化する構造のあいだに残る、閉じきらない再帰の残存である（族B）。同時に、射影で落ちた内容（族A）と、対象の運動による差分（族C）でもある。**

## ■ 5. ξとEの違い

ξとEは同じではない。

```text
ξ
  = M_B化されていない残存

E
  = 既存M_Bの予測・慣性・解釈と、実際に立ったFとの差
```

ただし、ξがある以上、Eは常に発生可能である。

さらに、E自体もB媒介である。Eは観測Bを通して測る量であり、測りきれない不一致は再びξへ戻る。

```text
ξ → Eとして顕在化しうる → E測定もBを使う → 測りきれぬ分がξへ戻る
```

つまり ξ と E は一方向ではなく、閉じないループを成す。

> **整合とは、ズレが存在しない状態ではなく、ズレがM_Bを破壊しない範囲に収まっている状態である。**

したがってRDLにおける安定は、静的な一致ではなく、ズレを処理しながら維持される動的状態である。

## ■ 6. 派生形

境界的限界性は、媒体や操作に応じて異なる形で現れる。

```text
観測限界性
  = 観測Bに現れた境界的限界性

記述限界性
  = 記述Bに現れた境界的限界性（§0.3 の通り、本概念自身もここへ折り返す）

文書性の限界
  = 文書媒体Bに現れた境界的限界性

数学的限界性
  = 公理・定義・証明Bに現れた境界的限界性

連続／離散問題
  = 連続らしき未分節性を、操作可能な離散M_Bへ切るときに現れる境界的限界性
```

## ■ 7. 数学との接続

数学は境界的限界性を免れた体系ではない。

むしろ、数学はBを最も厳密に管理する記述体系である。

```text
公理
定義
記号
集合
写像
証明規則
形式体系
```

これらはすべて、高精度に管理されたBである。

したがって数学の限界は、数学の弱さではない。

> **数学は、ξを消す技術ではなく、ξがどこに残るかを最も厳密に示す技術である。**

## ■ 8. 物理・NAMとの接続

物理、とくにNAMスケールでは、多くのξは無視できる。

ただし、これはξが存在しないという意味ではない。

> **NAMとは、ξがM_Bの安定を破壊しない範囲で成立する低負荷近似Bである。**

ξがEとして観測可能になり、Hとして蓄積し始めると、NAMのBは破断する。

### 8.1 Bはξの扱い方で分類できる

「NAMが破断したら別のBへ」では、Bの質の違いを取り逃がす。Bは少なくとも三様にξを扱う。

```text
抑制する
  = NAM。ξを無視できる低負荷近似として切る。

組み込む
  = 量子論・FluctMOD。ξを確率振幅・分布として構造の中心に組み込む。
    （ξを消すのではなく、ξを扱う形式そのものを作る）

再配置する
  = 超電導。ξをある軸（抵抗）から別の軸（位相）へ移す。
    （ある軸からξが消えたように見えるとき、別軸へ移っている）
```

NAMが破断したとき必要になるGR・量子論・統計力学・FluctMODは、単なる「別のB」ではなく、ξを抑制から組み込みへ切り替えたBである。

## ■ 9. T0内での位置

境界的限界性を導入すると、T0はかなり圧縮できる。

```text
限界空間
  = 絶対確定できないという最上位前提

境界的限界性
  = Bを引くことでM_Bが成立するが、同時にξが残るという根本構造
    （自己を含む格付き仮設。§0）

仮設という操作
  = 境界的限界性の中でBを置く唯一の実践形式

文書性の限界
  = 境界的限界性が文書媒体に現れたもの

連続と離散
  = 境界的限界性が連続／離散問題に現れたもの

形而上空間
  = B以前・B外部・M_B化前のものを指し示す補助語彙
```

T0の中核は、次の三段に圧縮できる。

```text
限界空間
  ↓
境界的限界性
  ↓
仮設という操作
```

## ■ 10. 圧縮命題

> **限界空間では、対象を絶対的に確定できない。**  
> **対象を扱うには境界Bを仮設する必要がある。**  
> **Bは一時的な関係安定M_Bを立てるが、同時にM_B化されないものをξとして残す。**  
> **この不可避性が境界的限界性である。**  
> **これは世界の法則ではなく、操作の超越論的条件であり、自分自身にも適用される格付き仮設である。**  
> **したがってRDLの操作は、発見ではなく、仮設・追従・引き直しとして行われる。**
